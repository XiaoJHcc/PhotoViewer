# 星级来源与写回（RATING）

**意图**：星级是用户对一张照片的编辑结果，必须写在照片自己身上，并让相机、外部编辑器与四端读到同一个值。同名组里每个实际存在的来源都是独立的评分事实：不排优先级、不互相遮蔽；sidecar 不存在时不创建，存在时必须一起写。写不进去要说清是哪个来源、失败在哪一步，绝不拿部分成功冒充整组成功。

数值令牌：`color.star.*`、`icon.warning`、`popup.ratingSources.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#rating)，验收状态见 [status.md](../status.md#rating)。

## RATING-01 来源模型：每个实际来源独立 · 必须

- 一次评分作用于同名合并成组后的一张照片。该组的评分来源是**全部实际来源**：
  1. 组内每个文件的内嵌 XMP 位置各算一个来源（有 canonical 包则读，没有记为 `缺失`；按 RATING-06，不为无包来源新建容器结构）；
  2. 每个实际存在的 `<stem>.xmp` 各算一个来源。
- 来源是否存在只看磁盘：不按"该格式通常该不该有 sidecar"推断，也不为缺席的 sidecar 预留来源。sidecar 不存在时，任何读写路径都不得创建它；已存在时必须参与读取与写入。
- 来源之间**没有读取优先级，也没有写入优先级**：不因 sidecar 存在就把它当唯一权威，也不用代表文件的值覆盖其它来源。某个来源缺 Rating 只表示它自己缺，不继承别的来源。
- 代表文件的内嵌 Rating 只用于两种口径：胶片栏与控制栏的星级显示、[FILTER-03](filter.md) 的数字与"以上"筛选。它不用于遮蔽、合并或替代其它来源。
- 来源级状态：

| 状态 | 含义 |
|---|---|
| 缺失 | 来源存在，但没有 XMP 包或包内没有 `xap:Rating` |
| 已评分 | 0–5 |
| 已拒绝 | -1（由外部写入产生） |
| 无效 | 非整数、越界或包无法按语义解析 |
| 冲突 | 同一文件内多份 canonical XMP 的 Rating 不一致；缺 Rating 的那份照常参与比较 |
| 不可读 | 容器结构不识别、读取被拒或 IO 失败；来源存在但无法读取，包内容无法按语义解析则归无效 |

- 组级 `星级冲突`：组内无法给出唯一可信的星级。
  - 只有一个实际来源时：它仅 `缺失` 不构成冲突（表示这张照片从未评分）；它 `无效` 或 `不可读` 仍为冲突（存在一个无法信任的评分）。
  - 存在两个及以上实际来源时：任一来源 `缺失`、`无效` 或 `不可读` 即为冲突，**即使全部来源都缺失**；可读来源取值不同也是冲突。
  - 同一文件内有多份 canonical XMP 时逐份比较；某一份没有 Rating 也参与比较，不能只比较有值的那几份。
  - 该状态同时驱动冲突指示与 [FILTER-03](filter.md) 的"星级冲突"，不得挑一个"看起来正常"的值显示为一致。
- 已拒绝（-1）是独立状态：不并入 0 星，也不当作"缺失"。

## RATING-02 安全写入：结构化定位与最小区间 · 必须

- 只改 canonical XMP 包内的 `xap:Rating`：已有值在原位改写，缺失时按 RATING-06 在包内插入；定位必须**按结构**：容器由格式适配器解析（JPEG APP1 段、HEIF `mime`/`iloc` 项、TIFF IFD0 tag 700、WebP `XMP ` chunk、sidecar 文件本体；PNG 写入不支持），包内按 XML/RDF 结构定位属性或元素。
- **禁止启发式定位**：不得用正则、字符串搜索、全文扫描或"第一次出现"来定位 XMP 包与 Rating；同一结构出现多份且无法唯一确定目标时，按不支持处理。
- **结构定位不是安全证明**：它只确定要改哪个区间；"非目标数据不受影响"必须由区间边界、区间外字节不变与写后回读共同证明。
- **区间不得与容器内其它数据重叠或共享**：写入区间（含必须同步的段长、RIFF 长度、tag count/offset、`iloc` 偏移与长度等记账字段）不得与同一容器里的其它段、项、extent、IFD 条目或其它来源的数据相交，也不得改写被其它数据引用的共享范围（同一 extent 被多个项引用、多个索引指向同一段等）。无法证明独占时按不支持处理。
- 写入区间取**最小**：只覆盖 Rating 值字节、紧邻的合法 XML 空白与必须同步的容器记账字段。不重排、不规范化、不重写整个包，其它字节保持原样。
- 长度优先等长。**唯一允许的变长是 Rating 附近的局部空白吸收**（例如 `-1` 与 `0`–`5` 互换时的位数差）：只在这段局部范围内吞吐空白，不移动远端内容；远端 padding 移位、受控追加、整文件重写/原子替换都不支持，按 `Unsupported` 处理。
- 安全模式在写入前比对目标字节与修订（revision）；被外部修改则放弃本次写入。
- 写入后回读 `xap:Rating` 做语义校验，核对容器记账字段，并确认编辑区间之外的包字节未变；校验失败按回执恢复原内容。
- **无法证明非目标数据安全**（结构不唯一、偏移不能证明、区间与其它数据重叠或共享、校验无法维护、需要移动远端内容或扩容）时返回 `Unsupported`，整组在首次修改前失败。
- **区分"无包"与"有包缺 Rating"**：无 canonical XMP 包（含 JPEG 无 APP1、TIFF/ARW 无 tag 700、HEIF 无 XMP mime 项、PNG/WebP 无 XMP chunk）时不新建或插入容器结构，按 `Unsupported` 处理；已有 canonical 包但缺 `xap:Rating` 时，仅在包结构唯一且空白足够容纳插入值时于包内插入 `xap:Rating`，否则同样 `Unsupported`。都不以"写 sidecar 成功"代替。

## RATING-03 全来源事务：先预检，后写入 · 必须

- **预检全部来源**：读取与严格解析、状态判定、写入区间定位、区间独占性、容器能力（等长 / Rating 附近局部空白吸收）、**真实随机读写能力**（能否取得可定位的读写句柄，而不是只看权限位或可写标记）、安全模式字节与修订比对。任一来源不能安全完成，就在**首次修改前**整组失败，不产生半写。
- **`NoChange` 也要有证据**：同值判定来自本次对每个来源的实际读取与严格解析，不以缓存、列表快照或上次回执推定；任一来源读不出或解析不成立时，不能算作"已是目标值"。
- 写入顺序固定：代表文件内嵌 → 其余文件内嵌（按文件格式优先级）→ 每个实际存在的 sidecar。顺序只用于确定性与补偿，不代表任何来源更权威。
- 写入中失败：
  - 安全模式开启：按逆序用回执补偿已写来源，补偿后逐来源回读校验；
  - 安全模式关闭：停止后续写入，已写来源保持磁盘真值，不假装整组一致。
- **写后确认覆盖全部来源与来源集合**：逐来源回读确认目标值（`NoChange` 则确认既有值），并确认本次预检的组内来源集合仍然成立（sidecar 未消失、未多出新的来源、内嵌包位置未被替换）。集合在写入期间发生变化时，不把本次结果当作整组成功，按磁盘真值报告。
- 结果：`Applied` / `NoChange` / `Superseded` / `RolledBack` / `Partial` / `Canceled`。
  - `Applied`：全部来源写入并通过校验；`NoChange`：全部来源本来已是目标值，未发生任何物理修改。两者都算成功（`IsApplied`），都可回填内存、刷新筛选与更新数据库副本。
  - `Partial`：补偿未全部成功，必须逐来源重读磁盘真值并按 RATING-01 的冲突口径展示。
- **不承诺跨文件断电原子**：一次评分在断电、强杀或卷断开后可能留下来源不一致；重启后按磁盘真值呈现冲突，并在下次评分时由全来源写入收敛。
- 同组写入串行。快速连按只让尚未开始物理写入的旧请求作废（latest-wins）；已经开始写入的请求不中途取消，完整走完或回滚。取消只在首次物理修改前生效。
- 全部来源已是目标值时返回 `NoChange`，不做任何物理写入：不创建 sidecar、不重写文件、不改变文件长度。

## RATING-04 冲突指示与星级弹窗条目 · 必须

- 组级星级冲突（RATING-01）时，胶片栏卡片的 0 号位置与星级控件的 0 号槽位由清零叉换成**红色警示三角**（`icon.warning`，颜色 `color.star.conflict`）。非冲突时仍是清零叉。
- 三角沿用原 0 号槽位的几何与命中区，不改变布局、不缩小相邻星。点击三角只打开星级弹窗，不写入评分；未提供星级弹窗的端，三角点击不动作、不写值，也不以直接写值等其它交互替代弹窗。
- 星级弹窗是星级控件的复用入口（RATING-07）：控制栏的紧凑态胶囊与卡片长按都用它，冲突来源不再有独立的浮窗入口。弹窗一律朝主图内侧展开，入口贴近窗口边缘时整体平移，不越出窗口被裁切。
- **条目格式**：非冲突时只有一个条目——该照片的文件名，放得下时在文件名后附拍摄时间，下方是星排；冲突时按来源逐条列出、纵向排列并以分隔线分隔，每条自带文件名，不另加头部或说明行，也不把多来源横排撑宽弹窗。
- 条目内边距、条目与分隔线间距、信息行与星排间距、长名换行行距、分隔线高度、类型标签水平内边距与圆角、文件名/元信息字号、展开空间余量与贴边距离取 `popup.ratingSources.*`（`entryPadding` / `entrySpacing` / `labelGap` / `metaLineGap` / `dividerHeight` / `badgePaddingX` / `badgeCornerRadius` / `nameFontSize` / `metaFontSize` / `arrowMargin` / `edgeMargin`；见 [tokens.json](../tokens.json)），弹窗内容内边距取 `popup.padding`，规则不复述数值；信息行高为 16（纯排版布局值，非令牌），长名换行后第二行另加 `metaLineGap`。弹层材质、字体族与边缘外形可按平台原生，字号与排版仍取令牌，不由任一端实现反推。
- 非冲突条目不显示来源标签；冲突时条目以标签标明内嵌格式（如 ARW / HIF）或 XMP sidecar，并带标签式背景。文件名无法与标签、状态同排容纳时独占首行，标签与状态移到第二行；文件名不得超过弹窗内容宽，超出时保留首尾、中间省略。
- 每个条目的星排是该来源自己的一组 0–5，0 号为清零叉、1–5 为星，按实际值点亮。星排只负责展示各自真值，不代表可以分别写入。
- 点击任意条目（含非冲突条目）的星或清零叉，都把同一值写入**全部实际来源**（RATING-03）；不存在只写当前条目的操作，也不因打开弹窗而新增 sidecar。
- 写入后按磁盘真值刷新**全部条目**，包括不是发起写入的那一条；弹窗外部的来源变化经刷新后同样反映到所有条目。
- **只有写入成功且刷新后目标组冲突已经解除时才关闭弹窗**；写入失败，或写入返回成功但冲突仍存在等异常情况，都保留弹窗并显示刷新后的各来源状态。不得仅凭写入回执在冲突尚未解除时关闭。
- 入口槽位被移除（如关闭评分显示）、入口被隐藏、锚点因布局重排/列表替换/滚动而移动、或入口滚出可视区时关闭弹窗；刷新失败不因状态未更新而关闭，保留弹窗并显示可读失败。
- `Esc` 关闭弹窗；切图、当前照片因筛选重算而改变时关闭。再次打开按最新来源状态重建内容，并按本次入口重新确定锚点与展开方向。
- 卡片没有独立的评分菜单：卡片长按与指针辅助点按都打开本条的星级弹窗（MENU-05、FILM-05）。

## RATING-05 状态投影与训练快照 · 必须

- 星级显示取代表文件内嵌 Rating 的点亮星数（FILM-05、RATING-07）。已拒绝（-1）不点亮任何星，也不提供 -1 的设置入口；清零叉写 0，不写 -1。-1 的专用呈现属未定义项（见下方"边界"），不借用 0 星语义。
- 筛选取值与命中条件见 [FILTER-03](filter.md)，只读代表文件内嵌 Rating，不读取其它来源。
- 训练快照：DatasetBuilder 只消费实际选用的文件，不读代表值、不读不参与训练的伴侣或 sidecar。
  - 只有该文件内部一致且为有效 `1`–`5` 时才写 Rating 快照；
  - `0`、`-1`、`缺失`、`冲突`、`无效`、`不可读` 都不写快照，保持缺失，不任选一个值，也不因其它伴侣或 sidecar 的取值伪造、覆盖或清零；
  - 快照写入不改变来源状态，也不构成写回。
- 数据库副本只在 `Applied` 或 `NoChange` 后用代表文件指纹更新（[architecture](../architecture.md) §5.3）；它不是产品行为真源。

**边界（未定义）**：-1 的专用图标/文案、按来源逐项设置不同值、弹窗内的来源排序与可访问性细节，不定义，实现时不自行发明。

## RATING-06 支持边界 · 必须

真实可用的范围：

| 范围 | 内容 |
|---|---|
| sidecar | 实际存在的 `<stem>.xmp`（canonical 包可解析）读写；不存在不创建 |
| JPEG | 标准单份 canonical APP1 XMP（已有包） |
| HEIF 家族 | HEIC / HEIF / HIF / AVIF 的标准 `mime` XMP 项、单 extent、`iloc` 可定位 |
| TIFF 家族 | TIFF / ARW / DNG 的 IFD0 tag 700 canonical 包 |
| 包内缺 Rating | 已有 canonical XMP 但缺 `xap:Rating`：结构唯一且空白足够时于包内插入；否则 `Unsupported` |
| 写入方式 | 等长原位、Rating 附近局部空白吸收；远端 padding 移位、受控追加、整文件重写不支持 |

以下结构**不支持**，遇到时返回 `Unsupported`，整组在首次修改前失败：

- 无 canonical XMP 包（JPEG 无 APP1、TIFF/ARW 无 tag 700、HEIF 无 XMP mime 项、PNG/WebP 无 XMP chunk）：不新建或插入容器结构，不写 sidecar 顶替。
- JPEG：非标准 APP1、多份 canonical APP1、EXIF/Photoshop/extended XMP 混用导致目标不唯一。
- HEIF：`idat`、多 extent、多个 XML/RDF 项、无 XMP mime 项、长度不定或无法证明范围。
- TIFF：tag 700 不在 IFD0、位于子 IFD、重复 tag 700、BigTIFF、无 tag 700 需新增条目。
- PNG：写入不支持（含标准 `iTXt`；必须维护容器级 CRC 事务）；`tEXt`/`zTXt`、压缩或多 `iTXt` 同属不支持。
- WebP：多个 `XMP ` chunk、需要新建 chunk 的非标准布局。
- CR3 等以 HEIF 容器承载但结构超出上表的 RAW。
- 其它专有 RAW（CR2 / NEF / RAF / ORF / RW2 / SRW）：不按扩展名假定可写，按实际结构预检，不能证明即失败。
- 文件系统与存储能力：符号链接/硬链接形态、跨卷替换、云 Provider 不可定位句柄、写中断电恢复。按平台能力如实失败，不假成功（见 [platforms](../platforms.md)）。

不支持时不提供"尽力写一部分"：这些来源若在组内实际存在，整组按预检失败处理，不跳过该来源只写其它来源；不写任何来源、不建 sidecar、不用别的来源的成功掩盖失败，按 STATE-03 说明对象与原因。

## RATING-07 星级控件与星级弹窗 · 必须

- 只有一个自定义星级控件，用在三处：手机竖屏底部行、手机横屏控制栏（EXIF 块之下的剩余长度）、宽形态控制栏（SHELL-08、SHELL-09、TOOLBAR-03）。三处的语义、写回与状态一致，只有可用主轴长度不同。
- 两种状态按可用主轴长度切换：长度不小于展开态固有长度时用**展开态**——完整 0–5，点选取值，可在星排上拖动增减；否则用**紧凑态**——短胶囊，点按或长按后朝主图内侧弹出完整星排，沿星排滑动选择、抬手提交。切换阈值就是展开态的固有长度，不另设数值，也不为放不下而压缩星距。
- **星级弹窗是可复用的入口**：控制栏胶囊与卡片长按（FILM-05）都打开它，弹出方向一律朝主图内侧。条目格式按 RATING-04：非冲突时一个条目（文件名，放得下时附拍摄时间，加星排），冲突时按来源逐条列出、不另加头部。
- 一次手势最多写回一次：滑动过程只预览、不落盘；滑回原值或取消不写；写回成功之后控件才显示新值（PRIN-02、RATING-03）。
- 冲突时 0 号槽位是警示三角，点它打开星级弹窗（RATING-04）；弹窗内任一条目点值都整组写入，写入成功且冲突解除才关闭。
- 无当前照片时控件禁用，但保留几何与命中区，不隐藏（TOOLBAR-03、TOOLBAR-09）。

**几何与令牌**

- 控件交叉轴取 `shell.glass.button.size`。展开态固有长度 = 6 × `rating.control.slot` + 2 × `rating.control.endInset`，沿槽位主轴居中；紧凑态铺满槽位主轴，宽形态控制栏里放不下展开态时取 `rating.compact.minLength`。手机横屏控制栏先为 EXIF 块保住紧凑态最短长度、再把余下长度给星排，EXIF 按整项裁掉末尾项（SHELL-09、TOOLBAR-05）。字形取 `rating.control.glyph.fontSize` / `rating.control.clearGlyph.fontSize`（展开态）与 `rating.compact.glyph.fontSize`（紧凑态）。
- 紧凑态内容是沿胶囊均匀分布的五颗星，冲突时最前加警示三角（与展开态 0 号格同位）：首末字形中心落在胶囊两端半圆的圆心（距端点 `shell.glass.button.size` 的一半），其间等距，步长不超过 `rating.control.slot`；胶囊短时步长随之缩小、字形允许叠压，不另设最小间距。横排三角与 1 号星在左，竖排在下。
- 叠压次序：警示三角在最上，其后 1 号星在 2 号星之上，依次到 5 号星在最下（点亮的星因此总在未点亮的之上）。下层字形被上层字形实心轮廓盖住的部分降为半透明并向外羽化，空心星的线条不在上层星内部交叉；不叠压时没有附加效果。
- 控件胶囊在展开态与紧凑态都按平台交互式玻璃响应按压（放大、回弹、高亮），星排与星簇随玻璃一同缩放，并与相邻玻璃控件按 SHELL-12 融合；展开态被按住的格另按 `motion.rating.press.scale` 放大。
- 弹窗星排每格 `rating.popup.slot`，可用空间不足时按六格均分收窄，不小于 `rating.popup.minSlot`；字形 `rating.popup.glyph.fontSize` / `rating.popup.clearGlyph.fontSize`；与入口相距 `rating.popup.gap`，圆角 `rating.popup.cornerRadius`，整体夹在窗口安全区内缩 `popup.ratingSources.edgeMargin` 的范围里。竖排控件打开的非冲突弹窗宽 `rating.popup.columnWidth`，文件名与拍摄时间各占一行，下方是竖排星列（5→0 自上而下）；冲突来源条目恒为横排星排。

**展开方向**（一律朝主图内侧）：

| 入口 | 手机竖屏 | 手机横屏 | 宽形态行布局 | 宽形态列布局 |
|---|---|---|---|---|
| 星级控件 | 上 | 刘海在左向左，刘海在右向右 | 上 | 左 |
| 卡片 | 上 | 刘海在左向右，刘海在右向左 | 下 | 右 |

**手势**

- 展开态：按下即预览按下的格，沿星排拖动预览跟随，抬手提交；越过两端夹到 0 / 5；手指在交叉轴越出星排 `rating.gesture.cancelSlop` 即进入取消区，预览回到原值，抬手不写。
- 紧凑态与卡片长按：起手即打开星级弹窗；手指越过 `rating.gesture.tapSlop` 之前不预览，之后按手指在弹窗星排主轴上的投影取值，手指不必移进弹窗；抬手提交。未越过阈值就抬手视为点按，弹窗保持打开，再点弹窗里的星提交。交叉轴越出"入口远端到弹窗远端"一带外加 `rating.gesture.cancelSlop` 即取消，抬手不写并收起弹窗。冲突时只打开来源条目，不做滑动选择。
- 冲突时落在 1–5 的提交即使等于当前显示值也写入（同值写入消解冲突）；落在警示三角只打开来源条目。
- 提交后控件以"待确认"外观显示提交值，写回成功由真值接管；失败回到真值并按 STATE-03 提示，不静默回滚。

**关闭与反馈**

- 弹窗在以下情况关闭：写入成功且冲突解除（RATING-04）、点按弹窗外部（该次点按只用于关闭）、`Esc`、切图或当前照片因筛选重算改变、入口被隐藏/移除/移动（布局重排、旋转、列表重载或滚动）。
- 预览每跨一档给一次选择触感，提交给一次轻冲击触感；被按住的格放大到 `motion.rating.press.scale`；弹窗打开 `motion.rating.popup.open`、关闭 `motion.rating.popup.close`。开启减少动态效果时不缩放，只淡入淡出。
- 指针悬停逐格高亮（紧凑态整胶囊高亮）；读屏把控件作为可调节元素，增减各写回一次，紧凑态与冲突时激活即打开弹窗。
- 手机形态关闭"显示评分"时控件隐藏、槽位保留；宽形态整组移除（TOOLBAR-03）。
