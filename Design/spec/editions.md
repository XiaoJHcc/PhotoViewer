# 发行版本（EDITION）

**意图**：用同一份选片核心提供两个边界清楚的离线产品：`PhotoViewer` 标准版不包含 DINO，`PhotoViewer AI` 内置完整 DINO。标准版保留所有不依赖 DINO 的浏览、评分与 CV 诊断能力，而不是在 AI 版界面上留下空入口、错误占位或“缺少模型”状态。

版本能力是构建期事实，不是运行时设置。各模块中未特别说明的 DINO、相似聚类与组合诊断规则描述 AI 版；标准版的差异以本文件为准。包体、原生依赖和发布矩阵见 [分发包体积优化计划](../../Plans/distribution-package-size-optimization-plan.md)。

## EDITION-01 版本能力与功能保留 · 必须

| 能力 | 标准版 `PhotoViewer` | AI 版 `PhotoViewer AI` |
|---|---|---|
| 浏览、解码、色彩、缩放、雾天增强 | 保留 | 保留 |
| 胶片栏、筛选、排序、评分写回、EXIF、照片数据统计 | 保留，既有平台边界不变 | 保留 |
| 对焦点/中心细节与直方图 | 保留 | 保留 |
| CV 锐度、抖动拖影、刚体拟合与缩略图“抖”徽标 | 保留 | 保留 |
| DINO CLS、patch token、PCA-RGB、Cosine | 不包含 | 完整保留 |
| 相似聚类与批量特征提取 | 不包含 | 完整保留 |
| DINO 模型、ONNX Runtime、DirectML 与推理后端 | 不包含 | 内置并离线可用 |
| 在线模型下载 | 不提供 | 本发行路线不提供 |

- 标准版不得注册或启动 DINO 提取、相似度计算、DINO 批量索引、模型校验或推理后端配置；不得因启动、切图、打开分析栏或工具页产生这些任务。
- 标准版保留 CV 提取、CV 派生计算、指纹分组和只读数据库能力。实现共享这些能力时不得反向引入 ONNX 或 DINO 索引器。
- AI 版既有功能不因双版本而删减。除本文件规定的 DINO/CV 即时计算开关拆分外，其交互与数据契约保持现状。
- 两个版本都不增加版本促销、升级提示、联网下载或功能说明控件；标准版界面不解释“缺少 AI”。
- 产品显示名标准版为 `PhotoViewer`、AI 版为 `PhotoViewer AI`（空格），用于窗口标题与菜单、macOS `.app` 目录名与 DMG 卷名、`CFBundleName` / `CFBundleDisplayName`、Android `android:label`、Windows 版本资源 `ProductName`。横线只属于打包命名：`release/packages/<PhotoViewer|PhotoViewer-AI>-<版本>-<平台后缀>`、Windows 程序集/EXE 名与 TestFlight `.xcarchive` 名。界面与包身份不得再用 `PhotoViewer-AI` 作显示名。

## EDITION-02 入口与主屏构成 · 必须

| 位置 | 标准版 | AI 版 |
|---|---|---|
| 筛选条 | 排序方式、排序方向、星级筛选、计数，共四项 | 另有末位「相似聚类」开关，共五项 |
| 相似面板 | 不创建、不占位、不计算 | 按 SIM 规则显示与工作 |
| 分析栏 | 对焦点（有数据时）、中心、直方图、锐度、抖动拖影 | 另有 DINO PCA、Cosine x,y，顺序见 ANALYSIS-01 |
| 设置 AI 页 | 仅「分析诊断」组的「即时计算 CV」一个开关 | 相似聚类参数、即时计算 DINO、即时计算 CV，以及可用平台的特征数据库入口 |
| 诊断工具 | 「CV 诊断」 | 「DINO 诊断」 |
| macOS 工具菜单 | EXIF 详情…、CV 诊断… | EXIF 详情…、DINO 诊断… |
| 清除特征数据库 | 不显示入口 | 按 SETTINGS-10 与平台差异提供 |

- 移除入口必须同时移除其空槽、分隔、占位和关联任务。筛选条按实际四项重新整组居中；列布局在计数后不留开关高度。
- 手机形态（SHELL-07）下两个版本都不显示相似聚类入口：筛选控件恒为单一胶囊、不含该开关，面板不展开也不计算；切回宽形态后按 FILTER-09 保存的状态恢复。
- 标准版分析栏瓦片数为 4 或 5，AI 版为 6 或 7；均按 ANALYSIS-03 的实际 `n` 重算等边长，不留 DINO 空框。
- 标准版不显示相似聚类的空态、未提取计数、提取按钮、进度或失败文案，也不显示 DINO 模型缺失、下载、初始化或推理失败状态。
- 栏位显隐命令、控制栏命令目录与既有快捷键不因版本改变；相似聚类原本就没有默认快捷键，不为标准版新增替代命令。
- Web 参考壳必须能分别表达两个版本的入口和几何，用于同一规则的差分验收；版本模拟只属于参考壳验收，不是产品内运行时切换入口。

## EDITION-03 分析栏与独立即时计算门控 · 必须

- 「即时计算 DINO」与「即时计算 CV」是两个独立设置，默认均关闭，只控制**分析栏**对当前展示图的现算。它们不控制相似聚类、显式批量提取或诊断工具页；这些入口按各自的显式请求规则工作。
- 只读库始终按能力分别进行：已有 DINO 结果可显示时不因 DINO 即时计算关闭而隐藏；已有 CV 结果可显示时不因 CV 即时计算关闭而隐藏。标准版只读取和派生 CV，不读取 DINO patch。
- DINO 开关只门控 PCA-RGB 与 Cosine 所需的现算；CV 开关只门控锐度与抖动拖影所需的现算。任一侧关闭时，该侧缺失结果保持「未提取」，不得随另一侧的计算顺带生成。
- 原片未提取回退与雾天增强重算都按上述能力分别调度。两侧同时开启可以共享同一份展示图解码，但不得合并成无法独立启停的计算开关；一侧失败不影响另一侧已有结果或独立失败状态。
- 「计算中…」只出现在实际现算的能力瓦片上。不得因只计算 CV 就让 DINO 瓦片显示计算中，反之亦然；细节预览与直方图继续执行自身规则。
- 标准版的诊断准星只在锐度与抖动拖影两张瓦片间共享。点按只移动准星，不建立 cosine 参考点、不重算热力图；切图、空白点按和隐藏面板仍按 ANALYSIS-08 处理。
- 分析栏隐藏即取消全部在途现算。标准版不得出现后台 DINO 任务，也不得把 CV 现算扩展为全文件夹批量索引。

## EDITION-04 CV 诊断工具与导航 · 必须

- 标准版保留诊断工具的非 DINO 内容，页名与直达菜单名为「CV 诊断」，不得整页删除，也不得继续叫「DINO 诊断」。
- 标准版瓦片固定为原图缩略图、锐度、抖动拖影，共三张；保留同一行的三列几何、刚体拟合整宽文本、原图压暗与矢量叠加。不得留下 PCA/Cosine 空格、说明文字或参考点坐标。
- 三张瓦片共享准星；点按只移动准星，空白清除，切图清空。标准版没有 cosine 参考点及其重置行为。
- 进入 CV 诊断页是对当前照片的一次显式 CV 请求：先读库，缺失时现算；只进本页内存结果，不写特征数据库。离开页面或关闭工具窗口立即取消，遵守 TOOLS-06 的页面生命周期。
- CV 诊断页不受「即时计算 CV」开关限制；该开关只约束分析栏。无照片、解码失败和计算失败沿用 TOOLS-06 的真实状态，不显示 DINO 或模型错误。
- 工具顺序在原 DINO 位置替换为 CV 诊断：EXIF 详情、CV 诊断、照片数据统计（仅 Windows）。macOS 无可用 EXIF 时落到 CV 诊断；Windows 仍落到照片数据统计；iOS/iPadOS 与 Android 仍回分组列表。
- AI 版继续使用 DINO 诊断的五瓦片、参考点 cosine 与既有导航回退，不因标准版规则改成三瓦片。

## EDITION-05 计算、缓存与数据库边界 · 必须

- 标准版只允许两条 CV 数据来源：只读既有数据库，以及分析栏或 CV 诊断页对当前照片的显式/已授权现算。现算产物只进进程缓存，不写 `photos.cv_grid`，不因此补齐整个文件夹或批量更新缩略图徽标。
- 缩略图“抖”徽标继续只读既有 CV 数据，不解码、不推理。未入库照片保持无判定；不得为了生成徽标在标准版后台启动批量 CV 提取。
- 标准版不得因无 DINO 能力或版本切换而删除、重建或清空照片数据库。既有 `photo_features`、`photo_patches` 与 CV 数据原样保留，但 DINO 数据不得在标准版中触发派生计算或任务；通用数据库损坏或版本处理若需重建，必须与 AI 版遵循同一规则，不得特别清除 DINO 表。
- 标准版不注册 DINO 缓存、ONNX session 或相关内存客户端；CV 分析缓存、抖动判定缓存与既有内存压力回收继续有效。
- 两个产品的任务与后台提取状态各自独立；标准版不得接管或恢复 AI 版的批量提取，AI 版只按自身未提取统计决定工作，不假定另一产品的任务已经执行或完成。
- 标准版不得因数据库中已有 DINO 特征而显示相似聚类、PCA 或 Cosine；数据保留不等于能力入口保留。

## EDITION-06 设置与视图状态边界 · 必须

- 两个产品是并列应用，不提供产品内切换，也不以覆盖安装或启动另一产品完成数据迁移。历史数据迁移属于发布执行任务，不改变下列长期边界。
- iOS/iPadOS 与 Android 的设置、视图状态、数据库、缓存和日志全部位于各自应用沙盒；不得使用共享 UID、跨包私有目录访问或相同应用 ID 复用状态。
- Windows 与 macOS 通过显式的产品族共享区复用通用设置和可复用分析数据。共享范围只包括文件格式、布局、控制栏、快捷键、EXIF、评分、通用预览与缓存设置，以及逐项登记的共有界面状态和 CV 特征；不依赖相同包身份获得共享。
- 相似聚类参数、即时计算 DINO、相似面板状态只归 AI 版读写。标准版不需要通过保留不可见 AI 字段维持兼容，也不得读取这些字段后恢复相似入口或排队任务。即时计算 CV 属于通用设置。
- 窗口位置、当前会话、临时任务、后台提取状态、日志、崩溃报告、诊断文件、单实例键、激活目标和更新状态均为各产品私有。
- 原组合字段 `AnalysisImmediateCompute` 升级为即时计算 DINO 的持久化值，新增独立的即时计算 CV 字段。AI 版读取不含 CV 字段的既有 schema 2 文档时，CV 初值继承原组合值；文档一旦含独立 CV 字段，两者完全独立读写。此继承只属于该字段的兼容规则，不改变 SETTINGS-14 的版本策略。
- 桌面共享配置必须具备 schema 版本、原子写入、跨进程锁或字段级合并和外部变更响应，禁止双开时用最后关闭者覆盖整份 JSON。共享 SQLite 使用 WAL、忙等待和迁移锁；只有 AI 版可以读取、写入或清理 DINO 数据，标准版不得删除、重建或清空共享库中的 AI 数据。

## EDITION-07 双产品验收 · 必须

- 四端分别验收两个实际构建变体，不能以 AI 版隐藏控件或共享代码检查代替标准版产物验收。八条发布轨道均扫描实际包身份、平台、架构、版本、签名、模型和托管/原生推理依赖；扫描器必须拒绝两版互换应用 ID。
- 两版在同一设备并存安装，分别启动、更新和卸载且互不影响；Windows 与 macOS 同时运行，同版二次激活只转发给同版主实例，跨版不转发。
- 标准版首次启动且无数据库：CV 关闭时诊断显示「未提取」；CV 开启且分析栏可见时只计算当前照片；隐藏或快速切图取消；CV 工具页可显式计算；全程无 DINO 任务、无网络请求、无特征库写入。
- 桌面两版同时修改通用设置时不丢字段、不整档回退，另一进程能按设计看到变更；AI 专属设置、窗口会话、日志和后台任务不进入另一产品。共享数据库并发读写与迁移可重复执行，标准版不能生成或清理 DINO 数据。
- AI 版四种 DINO/CV 开关组合分别验证：只开启一侧时另一侧不现算；只读缓存不受开关影响；雾天增强、取消与失败状态同样独立。
- 两版都检查筛选条实际项数、分析栏实际瓦片数、诊断工具页与 macOS 无 EXIF 回退；标准版不得残留空槽、死按钮、空分组或 DINO 文案。
- 浏览、解码、评分写回、EXIF、设置与工具页既有验收在标准版全部通过；AI 版继续通过既有 DINO、相似聚类和五瓦片诊断验收。

## EDITION-08 产品身份与发布轨道 · 必须

| 维度 | 标准版 | AI 版 |
|---|---|---|
| 内部产品键 | `photoviewer.standard` | `photoviewer.ai` |
| 全平台应用 ID | `cc.xiaojh.PhotoViewer` | `cc.xiaojh.PhotoViewer.AI` |
| 分发文件名前缀 | `PhotoViewer` | `PhotoViewer-AI` |

- 应用 ID 只区分产品，不添加平台、架构、渠道或构建号后缀；macOS 不使用 `.Mac`。非公开 Debug 包如需与正式包并存，可统一使用 `<应用ID>.Debug`，但不进入公开发行矩阵。
- 外部构建入口统一为 `PhotoViewerEdition=standard|ai`；DINO 编译能力、依赖和资产由 edition 派生，禁止把 `PhotoViewerEnableDino` 作为另一套手工身份输入。
- Windows 主发布形态为独立签名 MSIX；macOS 为独立签名、公证的 DMG；iOS/iPadOS 使用两个 App Store Connect App 与独立 TestFlight/App Store 轨道；Android Play 渠道使用 AAB，直接分发使用签名 APK。便携 EXE 与本地 IPA 只是附加或验收载体，不形成第三套身份。
- 八条轨道的输出、还原资产和中间目录完全隔离。每份产物生成包含产品键、实际包 ID、edition、平台、渠道、架构、版本、构建号、签名信息与 SHA-256 的机器可读清单，不能只从构建参数推断身份。
- 各产品、各商店的构建号独立递增；两个产品可以使用相同版本号和构建号，不要求跨 edition 避让。
