# 筛选条（FILTER）

**意图**：用排序键、方向与星级条件把当前文件集收窄到可快速翻看的一组。筛选不改变主图、不抢列表位置、不隐式触发特征提取。

数值令牌：`filter.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#filter)，验收状态见 [status.md](../status.md#filter)。

## FILTER-01 组成与统一业务语义 · 必须

筛选条位于文件栏顶部：列布局纵排，行布局独占文件栏顶部一整行、胶片带在其下方。前三项收在同一个筛选控件里，第四项仅 AI 版提供（EDITION-02）：

| 项目 | 含义 |
|---|---|
| 排序方式 | 文件名 / 拍摄时间 / 文件大小 |
| 排序方向 | 升序 / 降序 |
| 星级筛选 | 9 个选项，「全部」之外可多选，见 FILTER-03 |
| 相似聚类开关（仅 AI 版） | 面板显隐，见 FILTER-06 |

- 移动端宽形态固定为「筛选 / 更多」两段合体；桌面宽形态为三段合体（排序 / 方向 / 星级各一段），三段放不下时改用单一胶囊；手机竖屏为单一圆按钮，横屏为「筛选 / 更多」合体中的筛选段（FILTER-07、FILTER-08）。
- 选项名称、取值、组内顺序、默认值与应用时机一致；选择立即写入共享筛选状态并重算列表，不设「应用」按钮或二次确认。标准版移除相似聚类开关，不留空槽。
- 筛选条随文件栏整体显示/隐藏，没有独立的筛选条显隐开关；手机横屏例外见 SHELL-09。
- 空列表或单项列表仍可更改筛选。

## FILTER-02 排序键与方向 · 必须

- 三种键：文件名（含扩展名）、拍摄时间（共享照片日期，EXIF 缺失或不可读时取文件修改时间）、文件大小（字节）。
- 不提供按评分排序；不得以星级、相似度或抖动状态暗自改变默认顺序。
- 方向只作用于当前键：换键保留方向，换方向保留键；默认拍摄时间 + 升序。
- 同键值的项保持原文件顺序（稳定排序），四端结果一致，不因平台排序 API 或异步加载打乱。
- 文件名比较使用同一序数规则（忽略大小写、不随系统区域设置变化），不取合并后的显示名或本地化日期/大小文本。
- 排序只重排当前筛选结果，不改变成员、不切换当前照片、不滚动列表（[FILM-01](film.md)）。文件夹可以先用已有元数据呈现，排序数据在后台补齐后批量重排；不重新解码、不清空已加载内容。
- 同名组按代表文件排序。合并显示名 = 代表文件名 + `(` + 隐藏伴侣的格式名按格式优先级以 `/` 连接 + `)`，如 `DSC01234.JPG(RAW/HEIF)`。

## FILTER-03 星级筛选取值 · 必须

| 取值（固定顺序） | 命中条件 |
|---|---|
| 全部（默认） | 不限条件 |
| 无星级 | 代表文件内嵌 Rating 缺失或为 0 |
| 一星 / 二星 / 三星 / 四星 / 五星 | 代表文件内嵌 Rating 恰好等于该星级 |
| 已拒绝 | 代表文件内嵌 Rating 为 -1 |
| 星级冲突 | 按 RATING-01 判定为冲突的组 |

- 除「全部」外的八个条件可独立点选、取消并按并集命中，例如三星 + 四星 + 五星。点「全部」清空条件；取消最后一个条件也回到「全部」。只有无条件时才勾选「全部」。
- 代表为 -1、无效或不可读时不命中数字档或「无星级」。冲突独立于代表评分，不改写代表值或数字档结果（[RATING-01](rating.md)）。
- 以当前内存星级判定；评分写回成功后（[RATING-03](rating.md)）才改变结果，写回失败不改星级、不筛掉。筛选不修改评分，也不切换当前照片。
- 「星级冲突」与「已拒绝」始终可选；同名合并关闭时不比较伴侣，但单文件评分来源的冲突仍可命中。
- -1 只由外部写入产生；UI 不提供 -1 星级入口，也不把 -1 归一化为 0（RATING-05）。
- 当前照片因改星落出筛选时按 FILM-06 暂留；因用户改筛选而落出时见 FILTER-05。
- **应当**：「显示评分」只影响评分控件与星级渲染，不隐藏或禁用星级筛选。

## FILTER-04 筛选结果计数 · 必须

- 筛选控件及菜单不显示照片计数，也不为计数预留空间。相似聚类自身的未提取计数不属于本条。
- 业务计数取当前列表的卡片数（同名组或改星暂留项各算一张），不因排序或相似聚类面板显隐而变化。

## FILTER-05 筛选/排序与当前照片、列表位置 · 必须

- 任何筛选或排序操作都不改变主图身份、不触发切图、不主动滚动胶片栏（[FILM-01](film.md)）。
- 重算列表保留用户滚动偏移，只夹到新的合法范围；不得回到顶部。
- 当前照片被新筛选排除时：主图继续显示它，胶片栏没有当前项高亮；此后「上一张/下一张」以当前照片在重算前列表中的索引为参照，落到新列表中最近的前/后项，不得从列表首尾重新开始。
- 当前照片仍在结果中时，只按 FILTER-02 改变其列表位置，主图与缩放状态不变。
- 同名合并后当前项若是隐藏伴侣，映射到同组代表卡片；仍视为同一张照片，不算筛选改变照片。
- 筛选重算不取消当前照片的加载/解码，不触发 AI 或 CV 计算（[SCOPE-01](scope.md)）。

## FILTER-06 相似聚类开关 · 必须

本条仅适用于 AI 版；标准版不创建该开关，也不读取或写入 AI 版私有的展开状态（EDITION-02/06）。

- 开关位于筛选条末项：宽形态行布局紧随筛选控件，列布局在控件下方；打开即展开相似面板，关闭即收起；状态写入视图状态并在下次启动恢复（FILTER-09）。
- 打开时按当前照片计算相似项，关闭时取消在途计算；开关本身不改变排序、星级筛选、当前照片或列表顺序。
- 面板只在「开关打开且文件栏可见」时工作；文件栏隐藏时开关不可达、面板不显示也不计算，开关状态保留。
- 初次呈现（启动恢复、文件栏重新显示、布局重建）时开关勾选态与面板状态一致：开关打开且文件栏可见即显示面板并按当前照片计算一次；开关关闭即不显示、不计算。文件栏隐藏时只保留逻辑开关值，不显示、不计算、不排队。
- 相似候选集合取自当前筛选结果；排序不改变候选集合，筛选变化会触发重算（[similarity](similarity.md)、[SCOPE-01](scope.md)）。
- 开关只由筛选条控件触发，没有默认快捷键；不抢占主图手势或滚轮。
- 开关必须清楚表达选中与未选中。占位取 `filter.toggle.*`；原生按钮可按 TOOLBAR-10 使用系统状态外观，由同一控件配置管理背景、轮廓与高亮。自绘药丸四态取 `color.filter.toggle.*`：未勾选常态透明底 + 描边 / 未勾选悬停 `hover` 底、`hover.border`、`hover.foreground` / 勾选 `checked.*` / 勾选悬停 `checked.hover.*`。Android 版开关是主屏玻璃控件之一，与圆按钮、合体共用 TOOLBAR-10 的玻璃配方与版本分级；玻璃只承担材质，选中与未选中仍由上述颜色与文字状态表达，不因玻璃而减弱。

## FILTER-07 布局与显隐 · 必须

令牌：`filter.margin`（10）、`shell.filter.leadingInset`（42，仅 macOS 列布局）。

- 移动端宽形态的筛选/更多合体与大档卡片外框同宽（96），两段各 48，行、列布局共用这一宽度；两段以筛选图标 `filter.entry` 与更多图标 `filter.more` 表达（平台系统图标集按 platforms.md 登记）。
- 列布局：移动端的合体与胶片卡片外框落在同一条内容末端锚点（SHELL-01、FILM-07）；AI 版相似聚类开关独立、同宽，以同一末端对齐、在合体下方隔 `shell.glass.group.gap`。无遮挡时列宽仍为 116。桌面宽形态的筛选控件总宽等于胶片栏卡片列宽并整组水平居中，三段放不下时改用单一胶囊；AI 版开关在其下方隔同一间距、同宽。首控件顶部让位只有 macOS 取 `shell.filter.leadingInset`（42 = 标题栏高 32 + `filter.margin` 10），避开盖住文件栏的标题栏与交通灯；移动端列布局取该列自身位置的顶部遮挡（iPad 窗口控件带、Android 系统栏）加一份 `filter.margin`。
- 行布局：移动端合体与 AI 版开关按自然宽紧随（开关隔 `shell.glass.group.gap`），整组在安全内容区内居中；桌面宽形态三段合体按内容自然宽度排布，不按胶片栏宽度拉伸，交叉轴居中，AI 版开关隔同一间距紧随，整组超出安全内容区时改用单一胶囊。
- 宽形态筛选控件与相似聚类开关高 `shell.glass.button.size`；行布局筛选条主轴 = 控件高 + 2 × `filter.margin`。
- Android 的筛选控件与相似聚类开关按 TOOLBAR-10 的玻璃按钮配方呈现，筛选入口的玻璃透出其下滚过的胶片卡片；API 33 及以上卡片经折射可见，API 31–32 只透过模糊与表面色，API 24–30 使用正式色层外观。玻璃不改变入口宽度、分段、命中区与滚动宿主。
- 手机形态无相似聚类开关（EDITION-02）。筛选入口竖屏为圆按钮，横屏为筛选/更多 88 合体，关闭胶片栏也不拆分（SHELL-09）；入口边长 `shell.glass.button.size`。
- 组内不换行、不压缩段宽。仅当整组自然宽度超出安全内容区时，Android 从前导 `filter.margin` 起排并允许横向滚动。
- 宽形态文件栏隐藏时筛选控件与胶片栏一起消失，空间并入适应区（SHELL-11）；重新显示时恢复原选择，不重建状态。
- 行/列切换、窗口缩放只重排控件，不重算筛选、不改变当前照片。

## FILTER-08 菜单交互 · 应当

- 自绘筛选控件：圆角 `dropdown.cornerRadius`、底 `color.dropdown.background`（悬停 `.hover`、按下 `.pressed`）、1 点描边 `color.dropdown.border`（悬停 `.hover`）、文字 `dropdown.fontSize` 左内边距 `dropdown.paddingLeft`、右侧 `common.chevronDown` 边长 `dropdown.chevron.size`、距右 `dropdown.chevron.rightInset`、色 `color.dropdown.chevron`。弹层贴在入口正下方并以入口水平居中（最小宽 = 入口宽，越界向内夹取，下方不足翻到上方），外观同 MENU-03 自绘弹层；项左右内边距 `dropdown.item.paddingX`；当前项在左侧勾选列画 `common.check`，悬停 / 按下整行用 `color.menu.item.hover/pressed`，不用强调色整行铺底。
- 三段合体各开一组菜单；单一入口打开三个内联分组。排序键与方向单选、星级多选；移动端更多段另开主图菜单（MENU-08）。不隐藏当前不可能命中的选项；勾选只表示真实选择，入口标题不参与勾选。
- 点选立即应用；应当就地更新勾选、保持展开及菜单内滚动和焦点。若现用原生菜单没有公开的保留能力，允许系统在点选后收起或重定位，并登记差异，不拦截系统派发、不重新弹出、不为此更换控件。无关变更不主动关闭；入口移动、隐藏或移除时可关闭或按平台能力重定位。
- 菜单项应当用既有控件的公开图标能力配语义图标；允许已登记的原生字形差异。图标不替代文案或勾选。
- 桌面支持键盘打开、上下选择、回车确认与 Esc 关闭，焦点回到原控件；触屏用平台菜单手势。菜单打开期间照片快捷键不生效（[INPUT-01](input.md)）。
- 控件的悬停、按下、禁用与焦点状态不得导致布局抖动、残留旧态或裁切；原生菜单可用系统状态色与轻量动效。命中区不小于可见几何；触屏入口不小于 44×44（SHELL-10）。
- 桌面分段入口显示当前值；星级有多个条件时可显示「多选」，读屏名称包含完整条件。移动端及手机的筛选入口以图标表达，当前选项在菜单内显示。相似聚类开关的展开/收起状态以可见外观表达。
- Android 的筛选下拉在主窗口内的玻璃面板上呈现，面板透出其下的照片、栏位与玻璃按钮；材质取 `popup.glass.android.*`（API 33 及以上完整，API 31–32 无折射与着色器高光，API 24–30 为正式色层外观），形状取 `dropdown.cornerRadius` 的 G2 圆角。打开时铺一层覆盖全窗的透明拦截层：点面板外只关闭下拉、该次点按不穿透；返回键按既有顺序关闭；读屏与输入焦点按 SHELL-12 的模态规则处理。出入场只做淡入淡出，时长取系统 `config_shortAnimTime`，减少动态效果时直接到位。面板位置、最小宽、夹取与翻转、项高、勾选列、悬停/按下状态、点选后保持展开与键盘语义均不变。

## FILTER-09 持久化与作用域 · 应当

- AI 版相似聚类开关经 `IViewStateStore` 持久化并跨启动恢复；标准版不读取、写入或据其恢复面板和计算（EDITION-06）。
- 排序键、方向与星级筛选属于当前会话：切换文件夹或进入单图模式保留；重启回到拍摄时间 / 升序 / 全部，不写入设置。
- 影响列表成员的设置（文件格式启用、同名合并）在关闭设置后立即重算列表，不重置排序与星级筛选。
- 筛选条几何由布局与令牌决定，不单独持久化。

## FILTER-10 空结果与刷新 · 必须

- 结果为空：胶片栏留空（[FILM-05](film.md)），筛选控件保持可用并显示用户选择，不自动放宽条件、不自动改星级。
- 文件夹为空、格式全部禁用与筛选无命中共用同一空状态；不弹模态，不报错误提示。
- 文件夹重载、显式打开刷新（OPEN-08）、外部元数据变化与批量写库后，筛选与排序照旧生效；当前照片的落出/映射按 FILTER-05 处理。
- 重算不产生重复卡片、不短暂显示旧列表；解码失败的文件仍参与筛选。
- 筛选本身没有错误态；文件或目录不可访问属于 [open](open.md) 与 [state](state.md)。
