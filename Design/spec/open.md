# 打开（OPEN）

**意图**：任何把照片带进来的方式——选择器、外部打开、拖入、命令行/分享——都收敛成同一次打开：目标成为当前照片，同目录成为可浏览列表；拿不到目录时至少让用户看到这一张；打开不修改用户的筛选、排序、缩放与列表位置。

数值令牌：本模块无独立数值；定位动效归 `motion.film.*`（FILM-02），初始缩放归 IMAGE。平台实现与差异见 [platforms.md](../platforms.md#open)，验收状态见 [status.md](../status.md#open)。

## OPEN-01 入口与统一流程 · 必须

| 入口 | 结果 |
|---|---|
| 打开文件…（桌面） | 文件选择器；选中文件进入其父目录并成为当前照片 |
| 打开文件夹… | 目录选择器；进入文件夹模式，按 OPEN-04 选首图 |
| 空首屏点击 | 桌面打开文件选择器，触屏打开文件夹选择器（平台可用入口不同） |
| 外部打开（Finder/资源管理器「打开方式」、Dock/任务栏、分享、Intent、命令行） | 文件进父目录；文件夹进文件夹模式（OPEN-06） |
| 拖入窗口 | 与外部打开同语义（OPEN-07） |

- 所有入口进入同一共享打开流程，不各自维护一套状态；外部请求早于界面就绪时排队，就绪后执行，不丢弃。
- 取消选择器、拖入取消或投递无效项：不改变当前照片、列表、缩放与筛选。
- 一次请求含多项时只取一个目标：按投递顺序取首个可打开项（受支持图片或文件夹），其余忽略；不得一次打开多个文件夹。
- 打开是可复用命令：桌面必须能改绑定到快捷键，触屏必须有菜单或空态点击入口；选择器失败要留下可见原因，不得静默无响应。
- 选择器、菜单、空态与错误提示都要有键盘/触屏等价路径，失败文本可见；不依赖拖入作为唯一入口。

## OPEN-02 打开文件夹与枚举 · 必须

- 只收当前启用的文件格式；点号开头的隐藏文件排除。启用格式与同名合并规则取设置（SETTINGS-06）。
- 同名合并按格式优先级取代表文件作为一张卡片；被合并的伴侣文件不单独入列表，评分写回仍同步（FILM-05/06）。
- 打开新文件夹替换旧列表与窗口标题（窗口元数据，主屏不显示文件夹名）；上一批照片不得作为可点卡片残留（缩略图缓存可复用，但列表身份必须属于新目录）。
- 枚举顺序：先让指定目标上屏 → 枚举并重建列表 → 后台补 EXIF、星级与尺寸。后续阶段不得改掉已确定的当前照片；计数随列表增长。
- 空文件夹：列表为空、计数为 0、主图进入空态；不报错，也不自动打开别的目录。
- 无权限、目录已删除或枚举中途失败：给出可读错误并尽量保留打开前的照片与列表；不得停在没有终点的加载态。

## OPEN-03 打开文件与单图模式 · 必须

- 打开文件先尝试进入父文件夹并加载同目录，目标成为当前；随后按 OPEN-04 的首图规则只在其未被指定时生效。
- 父目录为空，或父目录不可访问、枚举被拒/失败（沙箱、单文件授权、SAF 单文件、分享进来的一次性 URL）时进入**单图模式**：列表只有这一张，窗口标题为文件名。
- 单图模式仍完整可用：主图、EXIF、评分写回、增强、工具与快捷键都照常；不显示伪造的上一张/下一张，不把单图包装成有邻居的列表。
- 单图模式不新增独立状态标记；以 1 张卡片承担，界面不另写「单图模式」。
- 目标已在当前目录的模型中：只切换选中，不重载目录；不在模型中则补入列表后选中。
- 目标扩展名未启用或不是图片：忽略并保持现状，不弹错误对话框；目标扩展名受支持但解码失败时仍作为当前照片，按 STATE-02 显示错误。
- 打开成功不保证可写；评分写回失败按 STATE-03 提示，不在打开阶段用权限对话框阻断。

## OPEN-04 首图与目标选择 · 必须

- 无指定目标打开文件夹：当前照片 = 筛选后列表首项，即同名合并后的代表文件（按格式优先级）；筛选结果为空时回退枚举首项所属同名合并组的代表文件。
- 指定目标：目标优先。即使它不满足当前星级筛选，也作为当前照片显示；列表仍按筛选结果，不为其放宽条件（FILM-06 的暂留只针对改星）。
- 首图选择不阻塞列表枚举；首图尚未上屏时显示载入/空态，不得显示上一批照片冒充。
- 打开不改变排序、星级筛选、文件格式设置与相似聚类开关；这些条件只影响列表构成与首图。
- 首图与列表身份一致：主图、卡片高亮、控制栏 EXIF 都取同一张（同名合并时取代表文件）；目标不在筛选结果时没有卡片高亮，也不加「不在筛选结果」标记，但仍作为当前照片。

## OPEN-05 打开后的定位 · 必须

- 显式打开默认把当前项定位到列表中心（FILM-01/02）；调用方明确声明“不定位”时除外。
- 定位在列表与布局就绪后执行；外部打开非首张必须最终停在目标附近，不得停在列表头部（允许收敛式补做）。
- 打开流程本身不额外制造定位请求：枚举补齐、EXIF/星级到达、筛选刷新都不触发定位（FILM-01）。
- 定位动画随时可被用户点选、滚动或拖动滚动条接管（FILM-03）；打开后立刻点选，用户位置胜出。
- 显式打开（文件、文件夹、外部打开、拖入）开始一段新的观片：主图回到适应态，不沿用上一批照片的倍率与对焦跟随。批内切图的缩放保持见 IMAGE-02。

## OPEN-06 外部打开 · 必须

| 来源 | 投递形态 |
|---|---|
| 系统文件关联 /「打开方式」/ Dock、任务栏 | 文件 URL 或路径 |
| 系统分享 / Android `ACTION_VIEW`、`SEND`、`SEND_MULTIPLE` | 文件 URL（可多项） |
| 命令行 / 启动参数 / iOS openURL、scene 连接 | 文件或文件夹 URL |

- 全部经共享外部打开服务进入 OPEN-01 流程；不绕过格式设置与筛选，不新建第二个主窗口。
- 应用未就绪时排队；已在前台时就地替换当前照片或文件夹，窗口前置。
- 同一目标重复外部打开是幂等的：只重新选中，不重置评分、EXIF、缩放或面板状态。
- 不支持的类型、无法读取的 URL 或空批次：忽略并保持现状；不得弹错误对话框或清空当前照片。
- 需要保留访问权限（安全作用域书签、SAF 持久授权）以便后续评分写回；授权丢失按打开失败处理（OPEN-02），不呈现虚假可写。

## OPEN-07 拖入 · 必须

- 拖入区域是整个主窗口内容区（标题栏按钮与菜单除外）；文件与文件夹都可接收，拖动经过时显示拷贝指示。
- 与外部打开同语义：文件进父目录并选中，文件夹进文件夹模式；多项按 OPEN-01 取首个可打开项。
- 拖动经过不切换照片、不预解码、不触发 DINO/CV；松手才执行打开（SCOPE-02）。
- 拖入取消、拖入不可读项或不支持类型：不改变任何状态，不留下悬停高亮。
- 平台不支持拖入时，空态与提示不得出现“拖拽到此处”的暗示（差异见 [platforms.md](../platforms.md#open)）。

## OPEN-08 并发、中断与重入 · 必须

- 打开可重入：后发起的打开取代先前未完成的枚举与解码，旧结果不得写入列表或主图（代际作废）。
- 打开期间切图、改筛选、开关栏位不取消打开；但用户显式选择优先于打开流程后续阶段选出的“首图”。
- 同一文件夹重复打开视为刷新：重新枚举但以当前照片为首选目标，不清缩略图缓存；目标已不在新列表时按 OPEN-04 取首项。
- 打开失败或中断：清理半成品列表，回到失败前状态或空态；不得残留“正在加载”或半张列表。
- 关闭窗口/退出时取消在途打开与解码，不写评级、不弹窗、不阻塞退出。

## OPEN-09 打开后的派生状态 · 必须

- 打开完成后：控制栏 EXIF 随当前照片刷新；分析栏按新当前图重新路由（仅可见时）；相似面板按新锚点重算（仅展开且文件栏可见）；抖动徽标只读库回填；工具页跟随当前照片。
- 这些派生工作全部让位主图上屏，不因打开触发 DINO/CV 推理（SCOPE-02）；面板不可见时不做。
- 单图模式或空列表下，依赖列表的面板显示各自空态，不报错、不显示上一批结果。
- 打开不改变栏位显隐、布局模式、缩放预设与快捷键绑定。
