# 控制栏（TOOLBAR）

**意图**：控制栏把"这张照片是什么参数、它是几星、接下来做什么"放在观片区旁边的一行或一列里：EXIF 摘要用于确认拍摄参数，评分直接写回该照片组的全部实际来源（各文件内嵌与已有 sidecar），命令按钮是最常用操作的可点入口。三个分组各自完整、顺序稳定；用户改的设置立刻反映到按钮上；空间不够时整组换行，而不是把一组拆散。

数值令牌：`toolbar.*`、`color.toolbar.*`、`color.star.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#toolbar)，验收状态见 [status.md](../status.md#toolbar)。

## TOOLBAR-01 三个分组完整、顺序固定 · 必须

- **宽形态**：控制栏只由三个整体分组构成，顺序固定为 **EXIF 摘要 → 评分 → 命令**；不因空间不足重排、不摊平成长列、不把评分星拆到两处。用户可以关掉某个分组或调整组内项目，但不能改分组顺序。
- 分组内容来自共享设置：EXIF 项显隐与顺序、评分显隐、命令显隐与顺序。壳不维护第二份硬编码的工具栏配置。
- **手机形态**：控制栏按 SHELL-08、SHELL-09 排布，在可选命令槽中按 SETTINGS-08 显示零至三个命令；关闭「显示评分」按 TOOLBAR-03 移除评分槽。EXIF 块在手机形态另由手机形态的 EXIF 开关与 EXIF 显示项共同决定（SHELL-12），宽形态仍只随 EXIF 显示项出现。
- 宽形态空分组（无启用项、评分关闭、无显示命令）整组移除且不占组距；手机槽位见 SHELL-08、SHELL-09。
- EXIF 块的标签与值必须可区分（字号、字重、色阶），完整内容可查看（TOOLBAR-05）；不能只留一个居中数字。
- 评分控件不得因空间不足被拆开或压缩：桌面端恒为展开态，宽形态换行只发生在组与组之间（TOOLBAR-08）；移动端宽形态与手机形态由星级控件自行降到紧凑态（RATING-07）。

## TOOLBAR-02 几何、换行与居中 · 必须

| 元素 | 令牌 | 当前值 |
|---|---|---|
| 流式文档主轴外边距 | `toolbar.padding` | 10 |
| 组间距 / 行（列）距 | `toolbar.group.spacing` | 10 |
| EXIF 块每项 | `toolbar.exif.item.width` × 块高（横排）/ `toolbar.exif.item.width` × `toolbar.exif.item.height`（竖排） | 52 × 44 / 52 × 36 |
| EXIF 块内边距 / 项距 | `toolbar.exif.padding` / `toolbar.exif.item.spacing` | 6 / 2；手机横屏的无衬底变体内边距为 0 |
| EXIF 块高（横排） | `shell.glass.button.size` | 44 |
| 星级控件 | 按自身固有长度占位 | 见 RATING-07；手机横屏控制栏不少于 `rating.compact.minLength` |
| 命令按钮 | `shell.glass.button.size` | 44 × 44 |
| 命令按钮间距 | `toolbar.command.spacing` | 8 |
| EXIF 块圆角 | `toolbar.exif.cornerRadius` | 12；无衬底变体不绘制块背景与圆角 |

- 行布局（控制栏在底行）主轴为宽，三组沿宽排成一行；列布局（控制栏在右列）主轴为高，三组沿高排列。方向随布局切换，不按照片横竖改变。
- 分组主轴长度：EXIF 块 = 2 × 内边距 + 项数 × 项宽（竖排为项高）+ （n−1）× 项距；评分按星级控件自身长度；命令组 = 按钮数 × 边长 + （n−1）× 按钮间距，不留组内边距。组与组之间 `toolbar.group.spacing`（10），文档主轴外边距 `toolbar.padding`（10）；共同工具区的交叉轴外边距与纵列居中取 SHELL-12，EXIF 块、星级控件与命令组保持同一中轴。
- 放不下时**整组**换到下一行/列：可用主轴扣掉两侧外边距后，若本行已有组且再加本组会超长，则本组另起一行。单组超长时不拆组（TOOLBAR-08）。
- 手机形态控制栏不换行/列也不滚动：槽位随有效选项占位（SHELL-08、SHELL-09），长度不足时由星级控件降到紧凑态（RATING-07），其余槽位不压缩、不重叠；容量与封顶见 SHELL-09。
- 每行/列在主轴上居中：起点 = `max(toolbar.padding, (可用主轴 − 行长) / 2)`；行长超过可用主轴时从 `toolbar.padding` 起排，不裁切、不重叠。
- 同一行/列的组在交叉轴拉伸到该行最大交叉轴长度，组内子控件在交叉轴居中；拉伸不改变子控件尺寸。
- 方形子控件保持方形，不因文字长度、名称本地化或原生控件内边距变形；星级控件保持自身固有比例（RATING-07）。
- 工具区的外边界分隔线与背景条件见 SHELL-12；栏底色沿用窗口分区口径（SHELL）。

## TOOLBAR-03 评分组：星级控件 · 必须

- 评分组就是星级控件（RATING-07），不再是一排独立按钮：宽形态控制栏、手机竖屏底部行、手机横屏控制栏（EXIF 块之下的剩余长度）三处用的是同一个控件。桌面端恒为展开态；移动端按可用主轴长度切换展开态 / 紧凑态。
- 点击第 n 星把**当前照片所属组的全部实际来源**写成 n 星，点击 0 号清零叉写成 0 星；不做第二次点击取消（取消走清零叉）。0 号与 1–5 的顺序随方向：行布局自左向右 0→5，列布局自上而下 5→0（0 号在底端），同一行/列内不得出现两种方向。
- 星色取代表文件内嵌 Rating：`rating ≥ n` 的星点亮 `color.star.on`（#FFD214），其余为空心 `color.star.off`（#808080）；清零叉用中性 `color.star.clear`（#666666），不随评分点亮。点亮的星取实心 `rating.starFilled`（`icon.fontSolid`），未点亮取描边 `rating.star`，清零叉取 `rating.clear`。已拒绝（-1）不点亮任何星，也不提供 -1 的设置入口。
- 组级星级冲突时（[RATING-01](rating.md)），0 号槽位换成红色警示三角 `rating.warning` + `color.star.conflict`，槽位几何与命中区不变；点击三角只打开星级弹窗（[RATING-04](rating.md)），由弹窗内的星写入全部来源，三角本身不写值。非冲突时 0 号仍是清零叉。
- 点星只改评分：不切图、不改变当前照片身份、不抢胶片栏位置（PRIN-02、FILM-06）。评分对象是当前照片，不取鼠标悬停的卡片。
- 写回失败时星级保持原值，并给出状态提示（停留 `motion.status.toast.duration`，4000；见 [state](state.md)）；冲突指示与星级弹窗按 [RATING-03](rating.md)、[RATING-04](rating.md) 刷新，不得先点亮再静默回滚，也不得显示虚假成功。
- 无照片时整个控件禁用：保留几何可见，但不可点。禁用按 TOOLBAR-10：自绘控件保持底色、描边与尺寸，只降内容强调；原生控件可用系统禁用外观（系统色），但仍须清楚可辨，不得用 `Opacity≈0.1` 近似隐藏，也不得改变尺寸或布局。
- 宽形态关闭评分显示后整组移除，命令组前移，不留空条（SETTINGS-09）。手机形态也把评分从测量与槽位移除：横屏释放的长度交给 EXIF 并按剩余内容重新居中，竖屏只移除评分槽、上下张与可选命令组位置不变；无照片与禁用态保留几何。

## TOOLBAR-04 命令组：显隐、顺序、图标与提示 · 必须

- 宽形态：内容 = 设置中"在控制栏显示"的命令，按用户排序；壳不写死第二份命令列表，也不因按钮少而补占位按钮。手机形态按 SETTINGS-08 取生效命令，按顺序并列在同一个胶囊内（竖屏从左到右，横屏从上到下）。每段是独立可聚焦、可点按、带读屏名称的动作按钮；不使用表达互斥选择的分段控件。零项移除整组，一项为圆形，两至三项共用胶囊。
- 宽形态命令圆按钮 `shell.glass.button.size`（44）见方，间距 `toolbar.command.spacing`（8）；手机形态胶囊内段间无额外间距，每段尺寸取 `shell.phone.command.size`。两者图标字号均取 `toolbar.command.glyph.fontSize`（18）；按钮尺寸不随名称或文字长度拉宽。
- 命令图标按 `Design/icons.json` 的 `command.*` 语义选取，Web 取 `icon.font` 的 `icon.command.*` 码位；具体资源映射不在本文重复登记，平台映射、光学尺寸、随包资产与完整性规则见 [ICON](icons.md)。图标居中绘制于命令按钮内，颜色取 `color.text.primary`（自绘禁用按 TOOLBAR-10 降内容强调；原生控件按 TOOLBAR-10 使用系统禁用外观）。
- 桌面悬停提示包含**命令名 + 实际主/次绑定**，格式 `命令名（主 / 次）`，按键用可读键名（数字键 `2`、符号键 `;` `=` `` ` `` 等），不得出现 `D2`、`Oem3` 这类枚举名；未设置的槽省略，主次相同只显示一次，两个槽都未设置时只显示命令名，不能出现"未设置"字样，不使用点号分隔命令名与绑定。移动端的命令读屏名称使用同一文案。绑定改变后提示立即更新。提示相对指针偏移 `tooltip.offset.x` / `tooltip.offset.y`，超过宿主时向内夹取；等待 `motion.tooltip.delay`，从一个提示连续划到下一个控件时改为 `motion.tooltip.chainDelay`。直接触控没有悬停；连接键鼠外设后可在宽形态的设置页查看与编辑绑定（INPUT-13）。四端都不做长按浮层。
- 评分快捷命令（`SetRating0`–`SetRating5`）显示在命令组时，1–5 为**星形内叠数字**：实心 `rating.starFilled` 星形按 `toolbar.command.glyph.fontSize` 画在按钮中心，数字 `toolbar.rating.digit.fontSize`（9）半粗、取按钮底色，叠在星形中心；0 为清零叉 `rating.clear`。0 星与 1–5 星必须可辨。图标字体无法叠字的平台可以只画数字（0=叉），须登记为平台差异。
- 当前壳未实现、或按 SCOPE-01 未开放的命令不生成按钮，也不显示禁用死按钮。
- 无照片时除"打开文件"外全部禁用。
- 命令点击与键盘快捷键执行同一条命令（同一命令 ID、同一语义），按钮不复制业务逻辑。
- 不要求开关型命令（分析栏、雾天增强）的按钮常驻开启态；开启态以面板可见性与菜单勾选为准（可以）。

## TOOLBAR-05 EXIF 摘要：内容、格式与更新 · 必须

- 内容 = 设置启用的 EXIF 项，按设置顺序；默认光圈、快门、ISO、等效焦距。
- EXIF 摘要是一个整块（几何见 TOOLBAR-02），块内按设置顺序排各项：横排（上下布局控制栏与手机竖屏顶行）是深色半透明圆角矩形，项沿宽排开；竖排（宽形态左右布局控制栏与手机横屏控制栏）一律取无衬底变体——没有块的模糊衬底与块内边距，只剩自上而下的项目与项距，直接放在控制栏背景上。无衬底纵排仍有透明宽度容器，最大为 `toolbar.exif.item.width`（52，且不超过按钮与两侧边距之和 64），与同列按钮和星级控件同轴，不被文字内容继续撑大，不加额外内外边距；文字超宽时在容器内尾部截断，不以项目固有宽撑大控制栏。每项上为标签 `toolbar.exif.label.fontSize`（10）次要色，下为值 `toolbar.exif.value.fontSize`（12）半粗主色，两者居中、尾部截断，标签不得与值同字号同色。有衬底的块被槽位压短时各项等分缩窄，不丢项；无衬底变体只按整项显示，放不下的末尾项裁掉，被裁的项仍可点整块进入 EXIF 详情查看（TOOLBAR-06）。小字号下半粗与常规难以区分的平台可以取加粗（TOOLBAR-05@win）。
- 值按摄影习惯格式化：光圈 `f/2.8`（至多 1 位小数、去尾零）；快门 <1 s 且接近 1/n（偏差 ≤2%）写 `1/250`，否则写小数秒（至多 2 位，`0.3s`），≥1 s 写 `2s`、`1s`、`1.5s`；ISO 整数；焦距 `14mm`、`10.5mm`（至多 1 位小数、去尾零）；曝光补偿 `+0.7 EV`；拍摄时间摘要 `yyyy-MM-dd HH:mm`（完整值见悬停提示）；缺失值显示 `--`，不留空块、不猜测、不用别的字段顶替。
- 完整值必须可查看：桌面悬停提示 `标签 · 值`；触屏没有悬停，完整值由整组点击进入的 EXIF 详情承担（TOOLBAR-06）。
- 切图后不得残留上一张照片的 EXIF 值：先显示占位或新值，EXIF 异步就绪后再更新；更新只改文本，不改变分组数量与几何。
- 无照片时保留已启用项的标签并显示 `--`，块数与布局不变。

## TOOLBAR-06 EXIF 组整体打开工具 · 必须

- 整个 EXIF 组（含块间留白）是一个点击目标，不逐块各自为政；四端点击都必须直接进入工具窗口的 EXIF 详情，不经过工具首页。与主图菜单「工具…」共用同一单例，但导航意图不同：EXIF 入口明确选择详情，已打开其他工具页时也切到 EXIF；菜单入口只前置已打开的窗口并保留当前页。无可用 EXIF 时按 TOOLS-02 回退。
- 组为空（无启用项）时没有命中区域，也不显示"可点但无反应"的状态。
- 命中区域不侵入评分组；桌面悬停给出可点提示（光标或 tooltip）。
- 打开工具不改变当前照片、评分或筛选；工具窗口的承载方式与内容规则见 [tools](tools.md)。

## TOOLBAR-07 设置变更即时重建 · 必须

- 设置一旦生效（工作副本关闭回写后，见 [settings](settings.md)），控制栏立即按新配置重建，不重启、不切图、不丢当前照片与评分。
- 重建幂等：旧分组先移出视图树再释放；重建后分组数 = 生效组数，控件不重叠、不重复、不残留旧按钮。
- 允许只重建受影响的部分（同轮刷新可合并），但结果必须与按设置全量重建一致。
- 重建按新几何重算控制栏主轴长度，适应区随之让位或收回（SHELL-01、SHELL-11）。
- 重建不得改变当前照片、评分值、胶片栏位置或工具窗口状态；只改控制栏自身内容与尺寸。

## TOOLBAR-08 空间不足与溢出 · 必须

- 单个分组永不拆开、永不压缩、永不省略子控件；宽形态只允许整组换行/换列并保留用户完整命令配置，手机形态始终单列、不换列也不滚动（SHELL-08、SHELL-09）。手机横屏控制栏的长度不足由星级降到紧凑态与 EXIF 只显示整项吸收（TOOLBAR-02、TOOLBAR-05）。
- **换行优先于滚动**（宽形态）：只要各组能靠整组换行/换列容纳在可用主轴内，就必须换行/换列，不得以滚动条代替换行。
- 某个组本身超过整条主轴可用长度时，宽形态控制栏沿主轴可滚动（溢出时才显示滚动指示器），内容不被裁切或叠压。
- 滚动位置属于用户：普通重建不主动回到起点；换向或显隐后按最新几何约束到合法范围。
- 宽形态四端都必须有滚动宿主：文档尺寸不超过可用主轴时不显示滚动条，超出时才可滚。

## TOOLBAR-09 无照片与空控制栏 · 必须

- 无当前照片：EXIF 显示 `--`，评分与照片相关命令禁用，"打开文件"仍可用；控制栏整体不因此消失，避免布局跳动。
- 三个分组都为空时，控制栏文档只保留按所在区域规则计算的外边距（TOOLBAR-02、SHELL-12），不显示空按钮、空条或占位文字。
- 控制栏是否显示仍由用户的栏位开关决定，不因分组为空自动隐藏（SHELL）。
- 空态与禁用态不改变分组顺序、几何与命中区域边界。

## TOOLBAR-10 视觉与反馈 · 应当

- 以 iOS 27 系列原生玻璃按钮在栏上的常态底色为颜色参照，在纯黑、50% 灰、纯白衬底上按 SHELL-12 的采样与折中口径比较；iOS 直接使用系统材质，不设叠加 alpha。macOS 的原生玻璃染白；Web 保留背景模糊并叠白，Android 用 Material 按钮底色叠白。先定栏底，再只调平台对应的 `shell.glass.button.tint.opacity`，颜色固定为 `color.toolbar.button.tint`（纯白）：主屏圆按钮、合体胶囊、星级胶囊与相似聚类开关共用这一值。Windows 只替换主屏控件的常态填充，不改变原生亚克力背衬、描边或悬停、按下、禁用、焦点与开关选中样式。
- 圆按钮与合体按钮按 SHELL-12 用平台原生按钮材质与系统状态外观。Web 的桌面宽形态继续参照 macOS 的按钮形状、材质层次与状态反馈，颜色按本条单独校准。本条的自绘底色、描边与圆角只约束自绘部分。EXIF 块是深色半透明圆角矩形（圆角 `toolbar.exif.cornerRadius`），有平台深色模糊材质时取该材质，没有时取 `color.toolbar.block.background`（#222222）；星级控件的胶囊按 RATING-07 取平台原生按钮材质，自绘平台与命令圆按钮取同一按钮材质；自绘命令圆按钮常态只绘制按钮材质，不画描边；圆角 `toolbar.cornerRadius`（6）只由控件自身一层裁切产生，不叠卡中卡双层圆角，也不把自绘圆角与系统按钮 bezel 或系统描边裁切叠加成二次裁角。
- 评分星形字号 `toolbar.rating.glyph.fontSize`（16），0 号清零叉 `toolbar.rating.clearGlyph.fontSize`（12），冲突警示三角 `rating.warning` 取 `toolbar.rating.glyph.fontSize`（16）并占同一 0 号槽位（`color.star.conflict`）；星形不因槽位小而缩小到不可辨，换成三角不改变槽位几何与命中区。
- 每个小控件有常态、悬停、按下、禁用、焦点五态。任何状态切换都不得引起布局抖动、残留旧态或裁切内容：不改尺寸与占位、不缩放、不绘制到父容器之外；焦点用可见焦点环或描边表达，本身不被裁切。
- 自绘控件按令牌绘制状态色，只改底色、描边与前景色，不加过渡动画，避免连续划过按钮时闪烁。原生控件可以使用系统状态色与轻量状态动效（L4），但占位、命中区与令牌几何一致。
- 常态/悬停/按下：
  - 命令按钮：悬停 `color.toolbar.command.hover.background`（#3D3D3D）+ 描边 `color.toolbar.command.hover.border`（#666666），按下 `color.toolbar.command.pressed.background`（#2A2A2A）；描边只在指针进入后出现，与 macOS 按钮的悬停边框同一出现方式。
  - 评分按钮：常态与禁用均为透明底；悬停与按下在槽位内画一个内切正圆（直径取槽位短边，不越出槽位），与原生平台逐格的系统正圆悬停同形。槽位在星级胶囊内时正圆取容器内状态层 `color.menu.item.hover` / `.pressed`（叠加在胶囊材质上）；评分按钮直接排在栏位上时取 `color.toolbar.rating.hover.background`（#333333）与 `color.toolbar.rating.pressed.background`（#3A3A3A）。
  - 胶囊容器内的分段（筛选合体与单胶囊、手机合体按钮）：悬停与按下的状态层随段形——在段内按同心圆角内缩，端段与胶囊同为半圆端，填 `color.menu.item.hover` / `.pressed`，不画直角或小圆角矩形。
  - 相似聚类开关：未选中悬停 `color.filter.toggle.hover`（#333333）/文字 `color.filter.toggle.hover.foreground`（#CCCCCC）；选中悬停底色 `color.filter.toggle.checked.hover.background`（#26477A）、文字 `color.filter.toggle.checked.hover.foreground`（#CFE0F5）。任何状态都不得让文字回落到黑色。
- 自绘控件禁用**不换底色、不换描边、不改尺寸**，只把内容（字形/文字）降到 `color.toolbar.disabled.content.alpha`（0.42）；不得用 `Opacity≈0.1` 近似隐藏。原生控件可用系统禁用外观（系统色），但必须仍清楚可辨、尺寸与占位不变，不得近似隐藏。无照片时评分组与照片相关命令呈禁用态，"打开文件"仍可用。
- 焦点态取系统焦点色或平台焦点描边；焦点环不改变几何、不被父容器裁切，鼠标点击不强制留下常驻焦点环。
- 控件保持方形实际绘制区域（`shell.glass.button.size`，44），原生按钮边框不得只画出扁条。
- 小型控件（下拉、菜单、tooltip）外观可以走平台原生，但占位尺寸必须与 TOOLBAR-02 / FILTER 的几何一致；有原生控件的平台不另画一套下拉。没有原生下拉、菜单与 tooltip、只能自绘的平台，这三类弹出控件按旧壳 Avalonia Fluent 深色外观（`dropdown.*`、`popup.*`、`menu.*`、`tooltip.*`）绘制（README §3）。
- 观片环境固定深色，语义色取平台（PRIN-08、PRIN-09）。

## TOOLBAR-11 焦点与键盘 · 必须

- 焦点顺序 = 视觉顺序：EXIF 组 → 评分 0–5 → 命令顺序；平台焦点模型可到达，Enter/Space（或平台等价键）触发。
- 文本输入或快捷键录制控件获焦时不派发控制栏命令快捷键（INPUT-01）。
- 焦点指示可见（TOOLBAR-10）；移动焦点只改变指示，不改变布局，也不执行命令。

## TOOLBAR-12 开关型命令的按钮态 · 可以

- 分析栏、雾天增强等开关命令可以在按钮上表达开启态（按下态或强调色）；表达时四端一致，或登记为平台差异。
- 未表达时按钮保持同一外观，用户以面板是否可见和菜单勾选判断当前状态，按钮不得显示与真实状态矛盾的态。
