# 上下文菜单（MENU）

**意图**：不离开观片位置就能切换栏位与雾天增强、进入工具与设置；菜单只复用已有命令与共享状态，不引入第二份状态，也不改变当前照片与列表位置。

数值令牌：原生菜单的几何由平台控件决定；自绘菜单（Web、Android）取 `popup.*`、`menu.*`（旧壳 Avalonia Fluent 深色外观）。平台实现与差异见 [platforms.md](../platforms.md#menu)，验收状态见 [status.md](../status.md#menu)。

## MENU-01 主图菜单的项、顺序与分组 · 必须

主图菜单（桌面右键、触屏长按）是窗口级入口。四组按固定顺序排列，组间分隔，组内不重排；项集合不随照片与筛选增删，形态差异只有下表标注的手机形态 EXIF 项与 platforms.md 已登记的条目。

| 组 | 项 | 类型 | 执行 |
|---|---|---|---|
| 打开 | 打开文件… | 命令 | 选择单张照片（[open](open.md)）；触屏平台无此项 |
| | 打开文件夹… | 命令 | 选择目录并载入（[open](open.md)） |
| 栏位 | 胶片栏 | 勾选 | 文件栏显隐（[shell](shell.md)） |
| | 分析栏 | 勾选 | 分析栏显隐（[analysis](analysis.md)） |
| | 控制栏 | 勾选 | 控制栏显隐（[shell](shell.md)） |
| | EXIF | 勾选 | 手机形态 EXIF 显隐（[shell](shell.md)）；只有手机形态出现 |
| 预览 | 雾天增强 | 勾选 | 雾天增强会话开关（[image](image.md)） |
| 窗口 | 工具… | 命令 | 打开工具窗口（[tools](tools.md)） |
| | 设置… | 命令 | 打开设置（[settings](settings.md)） |

- 只有手机形态在栏位组末尾多一项「EXIF」，用于控制手机形态的 EXIF 块（SHELL-08、SHELL-09），与栏位开关一样持久化（SHELL-04）；宽形态、桌面菜单与 macOS 系统菜单不含此项，宽形态控制栏的 EXIF 块仍只随 EXIF 显示项出现（TOOLBAR-05）。
- 不重复放置相似聚类开关（由筛选条承担，[similarity](similarity.md)）、布局模式、全屏与缩放命令；这些分别属于筛选条、设置与窗口/命令。
- 不提供重命名、删除、移动到废纸篓等破坏性项。
- **必须**：macOS 在系统菜单栏提供应用、文件、显示、工具、操作五个菜单，动作与按钮、快捷键走同一共享命令入口：

| 系统菜单 | 项（顺序固定） |
|---|---|
| PhotoViewer（应用菜单） | 设置…、分割线、退出 PhotoViewer |
| 文件 | 打开文件…、打开文件夹… |
| 显示 | 胶片栏、分析栏、控制栏、分割线、雾天增强 |
| 工具 | AI 版：EXIF 详情…、DINO 诊断…；标准版：EXIF 详情…、CV 诊断…（EDITION-02/04） |
| 操作 | 设置中的全部控制命令，顺序与设置一致 |

- 显示菜单只含胶片栏、分析栏、控制栏三个开关，一个分割线，以及雾天增强；不得放布局模式、全屏、缩放、相似聚类或工具项，也不得改变本表的项集合；手机形态的「EXIF」项只出现在触屏菜单，不进入 macOS 系统菜单。应用菜单不放「工具…」，文件菜单只含两条打开命令。
- 工具菜单的两项都打开同一个工具窗口并直达目标页，不新增工具实例；普通「工具…」入口仍保留已打开窗口的当前页。操作菜单不受控制栏显隐影响，隐藏在控制栏中的命令也必须保留。
- 触屏没有「打开文件…」项，其余项与顺序四端相同（手机形态按上表多一项「EXIF」）；见 platforms.md（OPEN-01@ios、OPEN-01@android）。

## MENU-02 勾选与执行语义 · 必须

- 每次弹出按当前共享状态重建勾选（栏位显隐取布局状态，雾天增强取当前会话开关），不沿用上一次的勾选结果。
- 菜单展开期间状态被快捷键、设置回写等改动时不追改已显示的勾选；下一次弹出即为最新，不缓存。
- 选择即关闭菜单，动作与按钮、快捷键走同一命令入口；改星、写回、定位、布局重排只发生一次。
- 菜单动作不改变当前照片、不发起列表定位、不打断在途缩放与加载（[film](film.md) FILM-01）。
- 栏位显隐的持久化随 [shell](shell.md)；雾天增强为会话态，不写入设置，重启后回到关闭。

## MENU-03 弹出、命中与收回 · 必须

- 触发：桌面在主图区右键；触屏长按只在主图区弹主图菜单。原生视图层级把窗口级菜单继承到其他分区时可以接受（桌面无卡片菜单），但触屏长按卡片必须打开星级弹窗（MENU-05、RATING-07），不得弹主图菜单。
- 不触发：左键单击与双击、捏合、已开始滚动的滚轮；长按起手后移动超过拖动阈值转为平移，不弹菜单。
- 位置：以触点为锚（桌面为指针，触屏为手指），整体夹在窗口内，触屏夹在屏幕安全区内，边缘不小于一个原生弹层边距；可用高度不足时菜单内部滚动，不裁掉任何项。
- 收回：选择项、点击菜单外、Esc、触屏返回键均关闭菜单；关闭动作不穿透到底层照片（不翻页、不缩放、不改评分）。
- 菜单已展开时不叠加弹出第二个菜单；拖入文件、切换栏位导致主图区重建时先关闭菜单。
- 菜单展开期间暂停照片全局快捷键（与文本输入、录制控件同一守卫，[input](input.md) INPUT-01），关闭后恢复；菜单内部的方向键、回车、Esc 由菜单消费。
- **应当**：使用平台原生菜单控件；自绘实现须登记为平台差异，并同样满足本条的定位、勾选与键盘要求（MENU-03@android、MENU-03@web）。
- 自绘菜单外观：弹层底 `color.popup.background`、1 点描边 `color.popup.border`、圆角 `popup.cornerRadius`、上下内边距 `popup.padding`、无阴影、最小宽 `menu.minWidth`；项高 `menu.item.height`、左右内边距 `menu.item.paddingX`、字号 `menu.item.fontSize`，悬停/按下整行直角高亮 `color.menu.item.hover/pressed`，文字不变色；勾选标记 `icon.check` 占左侧 `menu.check.size` 列、字号 `menu.check.fontSize`（菜单内有任一勾选项时所有项让出该列）；命令图标位于勾选列右侧，占 `menu.icon.size` 列、字号 `menu.icon.fontSize`，与文本间距 `menu.icon.gap`；快捷键右对齐、`color.menu.shortcut`；分隔线 `color.menu.separator` 1 点、左右内缩 `menu.separator.inset`；禁用文字 `color.menu.foreground.disabled`。右键菜单左上角对齐指针；下拉弹层以按钮宽为最小宽，不取 `menu.minWidth`。
- 平台差异见 platforms.md（MENU-03@android）。

## MENU-04 弹出不改变观片布局 · 必须

- 长按弹出时主图不抬升、不缩小、不位移，菜单锚在触点；不得用整块主图作为弹出预览。
- 卡片打开星级弹窗（MENU-05）时不抬升卡片、不改变卡片几何与胶片栏滚动偏移，当前项也不变。
- 菜单收起后主图位置与弹出前一致；弹层期间主图继续渲染与响应尺寸变化，不冻结、不降级。
- 平台差异见 platforms.md（MENU-04@ios）。

## MENU-05 卡片入口：没有卡片菜单 · 必须

- 卡片没有上下文菜单，也不提供任何卡片级菜单项集合。触屏长按卡片、指针辅助点按（含右键）卡片，都打开星级弹窗（RATING-07），不弹主图菜单。
- 星级弹窗的条目格式按 RATING-04：完整文件名，放得下时附拍摄时间，冲突时按来源逐条列出。这也是触屏查看完整文件名的入口。
- 长按不得在抬起时被点选消费——不因弹出弹窗而切换主图；弹窗不改变卡片几何、胶片栏滚动偏移与当前项。
- 弹窗内点值整组写入（RATING-01/03），写回失败见 [state](state.md)。
- 平台差异见 platforms.md（MENU-05@ios、MENU-05@android）。

## MENU-06 文案、标点与快捷键 · 必须

- 文案固定：打开文件…、打开文件夹…、胶片栏、分析栏、控制栏、雾天增强、工具…、设置…；沿用分区名，不使用"缩略图栏"等别名。macOS 系统菜单栏沿用同一文案，应用菜单另有「退出 PhotoViewer」，工具菜单另有「EXIF 详情…」与当前版本的「DINO 诊断… / CV 诊断…」，操作菜单使用设置中的命令名称。
- 打开窗口或选择器的项带省略号（…），纯开关项不带；省略号前不留空格，也不使用"..."。
- **可以**：有用户主/次绑定的项显示当前绑定（平台原生快捷键列），无绑定不显示；绑定修改后下一次弹出即为新值；菜单内不改写或录制绑定（[input](input.md)）。
- 触屏平台不显示快捷键列。主图菜单与 macOS 系统菜单栏的命令项必须显示前置图标，勾选项也保留图标；打开文件=文档、打开文件夹=文件夹、胶片栏=照片组、分析栏=分析网格、控制栏=滑杆、雾天增强=对比度半圆、工具=工具、设置=齿轮，退出=电源，操作菜单沿用 TOOLBAR-04 的命令图标。字形使用各端已登记的平台图标集，同一项语义不得变化。
- **应当**：菜单用平台原生菜单控件，键盘可完成选择与取消；勾选不只靠颜色或图标表达。

## MENU-07 不可用项、空态与并发 · 应当

- 没有当前照片时，打开与栏位项照常可用；雾天增强置灰不可用；工具…与当前版本的 DINO/CV 诊断…可打开空态，EXIF 详情…按共享 EXIF 可用性置灰；操作菜单只保留「打开文件」可用，其余照片操作立即置灰，不等待图像加载通知。macOS 必须关闭 NSMenu 自动启用，并在菜单显示前同步业务可用性；首次及后续打开均不得出现先启用、后禁用的过渡。
- 空筛选结果、全部照片不可解码时菜单仍可弹出，项集合不变，不根据列表内容推断可用性。
- 选择器被取消、写回失败、外部打开失败不改变菜单本身的状态；提示归 [state](state.md)。
- 打开菜单后系统弹窗、模态页、窗口失活或应用进入后台时关闭菜单，不残留浮层，也不在恢复前台时自动重弹。

## MENU-08 更多按钮 · 必须

- 手机形态的「更多」按钮（SHELL-08、SHELL-09）打开一份菜单，内容与顺序等于主图长按菜单（MENU-01），取同一份共享目录，不在第二处维护项集合；两者对同一状态给出同一勾选，并同样在栏位组末尾含「EXIF」勾选项（宽形态菜单不含此项）。
- 每次打开按当前共享状态重建勾选（MENU-02），不缓存上一次结果；EXIF 项的勾选取手机形态 EXIF 开关，默认开，EXIF 显示项为空时勾选仍按开关显示，只是不出现 EXIF 块（SHELL-12）。
- 位置、收回、键盘语义与禁用规则同 MENU-03；展开期间暂停照片快捷键（INPUT-01）。
- 栏位显隐、雾天增强、工具与设置都经同一命令入口执行，按钮不复制业务逻辑。
