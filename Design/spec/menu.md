# 上下文菜单（MENU）

**意图**：不离开观片位置就能切换栏位与预览模式、进入工具与设置；菜单只复用已有命令与共享状态，不引入第二份状态，也不改变当前照片与列表位置。

数值令牌：无跨端菜单几何（弹层尺寸、行高与边距由平台原生控件决定，自绘触屏菜单的数值登记在平台差异）。平台实现与差异见 [platforms.md](../platforms.md#menu)，验收状态见 [status.md](../status.md#menu)。

## MENU-01 主图菜单的项、顺序与分组 · 必须

主图菜单（桌面右键、触屏长按）是窗口级入口。四组按固定顺序排列，组间分隔，组内不重排；项集合不随照片、筛选或布局增删，平台差异仅限下表标注与 platforms.md 已登记的条目。

| 组 | 项 | 类型 | 执行 |
|---|---|---|---|
| 打开 | 打开文件… | 命令 | 选择单张照片（[open](open.md)）；触屏平台无此项 |
| | 打开文件夹… | 命令 | 选择目录并载入（[open](open.md)） |
| 栏位 | 胶片栏 | 勾选 | 文件栏显隐（[shell](shell.md)） |
| | 分析栏 | 勾选 | 分析栏显隐（[analysis](analysis.md)） |
| | 控制栏 | 勾选 | 控制栏显隐（[shell](shell.md)） |
| 预览 | 增强 | 勾选 | 增强预览会话开关（[image](image.md)） |
| 窗口 | 工具… | 命令 | 打开工具窗口（[tools](tools.md)） |
| | 设置… | 命令 | 打开设置（[settings](settings.md)） |

- 不重复放置相似聚类开关（由筛选条承担，[similarity](similarity.md)）、布局模式、全屏与缩放命令；这些分别属于筛选条、设置与窗口/命令。
- 不提供重命名、删除、移动到废纸篓等破坏性项。
- **可以**：桌面平台在系统菜单栏另设文件/显示菜单；项与勾选语义须与主图菜单一致并走同一命令入口，不得改变本表的项集合。
- 平台差异见 platforms.md（menu-01@ios / menu-01@android）。

## MENU-02 勾选与执行语义 · 必须

- 每次弹出按当前共享状态重建勾选（栏位显隐取布局状态，增强取当前会话开关），不沿用上一次的勾选结果。
- 菜单展开期间状态被快捷键、设置回写等改动时不追改已显示的勾选；下一次弹出即为最新，不缓存。
- 选择即关闭菜单，动作与按钮、快捷键走同一命令入口；改星、写回、定位、布局重排只发生一次。
- 菜单动作不改变当前照片、不发起列表定位、不打断在途缩放与加载（[film](film.md) FILM-01）。
- 栏位显隐的持久化随 [shell](shell.md)；增强为会话态，不写入设置，重启后回到关闭。

## MENU-03 弹出、命中与收回 · 必须

- 触发：桌面在主图区右键；触屏长按只在主图区弹主图菜单。原生视图层级把窗口级菜单继承到其他分区时可以接受（桌面无卡片菜单），但触屏长按卡片必须走卡片菜单（MENU-05），不得弹主图菜单。
- 不触发：左键单击与双击、捏合、已开始滚动的滚轮；长按起手后移动超过拖动阈值转为平移，不弹菜单。
- 位置：以触点为锚（桌面为指针，触屏为手指），整体夹在窗口内，触屏夹在屏幕安全区内，边缘不小于一个原生弹层边距；可用高度不足时菜单内部滚动，不裁掉任何项。
- 收回：选择项、点击菜单外、Esc、触屏返回键均关闭菜单；关闭动作不穿透到底层照片（不翻页、不缩放、不改评分）。
- 菜单已展开时不叠加弹出第二个菜单；拖入文件、切换栏位导致主图区重建时先关闭菜单。
- 菜单展开期间暂停照片全局快捷键（与文本输入、录制控件同一守卫，[input](input.md) INPUT-01），关闭后恢复；菜单内部的方向键、回车、Esc 由菜单消费。
- **应当**：使用平台原生菜单控件；自绘实现须登记为平台差异，并同样满足本条的定位、勾选、键盘与无障碍要求（menu-03@android）。
- 平台差异见 platforms.md（menu-03@android）。

## MENU-04 弹出不改变观片布局 · 必须

- 长按弹出时主图不抬升、不缩小、不位移，菜单锚在触点；不得用整块主图作为弹出预览。
- 卡片菜单可保留系统的抬升反馈，但不得改变胶片栏卡片几何、滚动偏移与当前项。
- 菜单收起后主图位置与弹出前一致；弹层期间主图继续渲染与响应尺寸变化，不冻结、不降级。
- 平台差异见 platforms.md（menu-04@ios）。

## MENU-05 卡片菜单 · 必须

- 触发：触屏长按卡片（含触控板/鼠标辅助点按）。桌面不建卡片菜单，完整名与时间用悬停提示、评分用卡片星级按钮，触控目标见 [film](film.md) FILM-05。
- 标题一行承载完整文件名与拍摄时间，时间格式 `yyyy-MM-dd HH:mm:ss zzz`（与桌面悬停提示一致）；无拍摄时间只显示文件名。标题不可点击。
- 唯一命令为评分 0–5：0 显示"无星级"且在首位，其后为"N 星"；当前星级勾选（无星级时勾选 0）。结构可用子菜单或同组六项，顺序固定。
- 执行后只改该卡片评分：不切换主图、不定位列表、不选中父卡片；写回失败见 [state](state.md)，菜单已关闭且不显示虚假星级。
- 长按不得在抬起时被点选消费——不因弹出菜单而切换主图。
- 菜单是触屏的补充命中入口，不替代卡片星级按钮。
- 平台差异见 platforms.md（menu-05@ios / menu-05@android）。

## MENU-06 文案、标点与快捷键 · 必须

- 文案固定：打开文件…、打开文件夹…、胶片栏、分析栏、控制栏、增强、工具…、设置…；沿用分区名，不使用"缩略图栏"等别名。
- 打开窗口或选择器的项带省略号（…），纯开关项不带；省略号前不留空格，也不使用"..."。
- **应当**：有用户主/次绑定的项显示当前绑定（平台原生快捷键列），无绑定不显示；绑定修改后下一次弹出即为新值；菜单内不改写或录制绑定（[input](input.md)）。
- 触屏平台不显示快捷键列；图标是否使用由平台决定，同一项在各平台的图标含义应一致。
- **应当**：菜单提供系统菜单语义（名称与勾选态可朗读），键盘可完成选择与取消；勾选不只靠颜色或图标表达。

## MENU-07 不可用项、空态与并发 · 应当

- 没有当前照片时，打开与栏位项照常可用；增强置灰不可用；工具…可打开但显示空态，不弹错误。
- 空筛选结果、全部照片不可解码时菜单仍可弹出，项集合不变，不根据列表内容推断可用性。
- 选择器被取消、写回失败、外部打开失败不改变菜单本身的状态；提示归 [state](state.md)。
- 打开菜单后系统弹窗、模态页、窗口失活或应用进入后台时关闭菜单，不残留浮层，也不在恢复前台时自动重弹。
