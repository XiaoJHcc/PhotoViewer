# 图标

数值令牌：`icon.*`（Web 参考壳）、各控件的 glyph 字号与尺寸（见 [tokens.json](../tokens.json)）。三端语义与资产映射见 [icons.json](../icons.json)，平台实现见 [platforms.md](../platforms.md#icons)。

## ICON-01 语义清单 · 必须

- 图标按业务语义登记，不以字体码位、英文资源名或某个平台的造型作为跨端契约。每个条目包含稳定语义 ID、中文名称、用途分组，以及 Apple / Windows / Android 的映射。
- 同一语义在各入口复用同一 ID；同概念但表达不同状态的条目分别登记，例如描边星与实心星、筛选数字圆与评分快捷命令、筛选冲突与评分冲突。
- 新增需要图标的命令、菜单、筛选、设置或工具入口时，必须先登记语义 ID 并补齐三端映射，再实现平台界面。设置文档只保存命令 ID，不保存图标或字体码位。
- 图标不参与命令能否执行的判定；缺少图标是展示与验收错误，不得改变输入命令表。

## ICON-02 平台图标族 · 必须

- Apple 使用系统 SF Symbols；Windows 使用 Fluent UI System Icons Regular / Filled；Android 使用 Material Symbols Rounded。Web 参考壳使用 `icon.font` / `icon.fontSolid` 的 uicons 子集。
- Windows 与 Android 的字体由 `Design/icons.json` 固定上游提交，生成只含已登记码位的随包资产。不得依赖设备已安装字体、在线字体服务、OEM 系统 drawable 或另一图标族的运行时回退。
- Android 固定 `wght=400`、`GRAD=0`、`opsz=24`；`FILL` 只取条目登记的 0 或 1。Windows 的 Regular / Filled 同样由条目确定，不自行换族或混用 Light。
- Windows 自绘窗口按钮保留系统 Segoe Fluent Icons / MDL2 回退链，属于窗口 chrome，不进入业务图标映射。应用图标、调试 DocumentsProvider 的系统缩略图也不属于本条。

## ICON-03 语义与视觉 · 必须

- 四端语义必须一致，轮廓不要求跨平台相同；同一平台内必须保持同一图标族、圆角、字重、填充和视觉尺寸规则。不得用含义无关或需要猜测的图标填补空位。
- 打开文件使用文件夹，主图菜单的打开单个文件使用文档；上一张/下一张使用单向箭头；交换使用双向箭头；缩放适应使用向外双对角箭头；放大/缩小使用纯加号/减号；雾天增强使用与明暗调整语义一致的半圆或平台增强符号；EXIF 使用照片信息或文档信息，不复用控制栏滑杆。
- 筛选的 1–5 星使用对应数字圆，不得五项共用同一个无数字星形。评分快捷命令仍按 TOOLBAR-04 使用实心星内叠数字；普通星排的点亮与未点亮分别使用实心星与描边星。
- 图标颜色、着色状态、命中区、布局尺寸和读屏规则仍归所属模块。换图标不得改变控件结构、入口数量、命令行为或几何令牌。

## ICON-04 生成与完整性 · 必须

- `Design/icons.json` 是三端映射、生成码位表、随包字体子集和对比报告的唯一数据源。生成产物不得手改；上游版本升级必须显式修改固定提交并重新生成、重新目视全部变化项。
- `python3 Tools/generate-icons.py --check` 校验生成码位表、字体摘要和全部码位覆盖。缺失语义、未知上游图标名、缺字体、缺码位或产物漂移均为失败，不允许静默使用默认图标。
- 字体许可证随资产保留。生成与检查不访问用户照片，不写用户设置。

## ICON-05 对比与验收 · 必须

- `python3 Tools/generate-icons.py --refresh` 重新取得固定上游并生成全部资产；普通生成复用已入库字体。报告默认写入 `artifacts/acceptance/icon-catalog/index.html`，按语义逐行并列 Apple 实际系统渲染、Windows 与 Android 的随包字形，展示 18 / 24 点两档及资源名。
- 对比检查语义、视觉粗细、墨迹面积、圆角、填充配对和视觉中心；不要求三端轮廓或 SVG 外框完全相同。原生控件截图仍需核对基线、着色、禁用态、光栅化和居中，资产对比页不能替代真屏验收。
- Windows 至少覆盖主图菜单、筛选、控制栏、胶片卡片、评分来源浮窗、设置与工具分类；Android 另覆盖手机胶囊、设置排序行和星级弹窗。截图与报告写入隔离验收目录，不作为产品 UI。
