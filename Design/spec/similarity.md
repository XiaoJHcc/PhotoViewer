# 相似聚类面板（SIM）

**意图**：回答"这张照片还有哪些同批的相似照片"，让用户不丢失去向地跳到候选；面板只读库里已有的结果，计算只发生在用户打开面板时。

数值令牌：`sim.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#sim)，验收状态见 [status.md](../status.md#sim)。

## SIM-01 面板开合与三态 · 必须

- 面板由筛选条末位「相似聚类」开关显隐；开关勾选态就是共享的展开状态，随设置跨会话持久化。开关外观可以原生，位置（紧随计数之后）与勾选语义必须一致。
- 面板属于文件栏：文件栏隐藏时不占位、不计算、不报错，勾选态保留；文件栏重新显示后按当前照片重算并展开。
- 开合面板不改变当前照片、不改主图缩放、不主动定位任何列表。关闭只取消在途的相似度计算，不删除已入库特征与已算结果；批量提取不因面板关闭而中断（SIM-03）。
- 面板主体有三态，动作区（未提取计数、按钮、进度）独立于三态存在：

| 面板状态 | 判据 | 主体 |
|---|---|---|
| 空 | 无相似项 | 居中占位文案（两种，见 SIM-02） |
| 列表 | 有相似项 | 卡片列表，分数降序 |
| 提取中 | 正在批量提取 | 列表保持不变；按钮位置换成进度 |

- 三态与动作区只由共享状态决定，视图不得自行推断"库里没有结果"之类的结论；同一判据在四个平台必须给出同一显示。

## SIM-02 空态文案与未提取计数 · 必须

- 两种空态互斥：存在未提取照片 → 「尚未提取特征」；全部已入库但仍无相似项 → 「无相似照片」。不得同时出现，也不得用同一句糊过去。
- 空态把文案与动作区整体居中（间距 `sim.empty.spacing`（8），四周 `sim.empty.margin`（4）），文字颜色 `color.sim.placeholder`（#555555）。空态不重复显示「N 张未提取」数字，只有按钮；列表态才在动作区显示「N 张未提取」（`color.sim.caption`，#777777）。
- 未提取按指纹组统计：同一次曝光的 RAW/JPG/HEIF 同名文件只算一张；DINO CLS、patch、CV grid 任一缺失，或缺拍摄时间的孤立文件，都计入未提取。
- 未提取数在打开面板、切换文件夹、筛选变化、提取完成后更新；统计不阻塞浏览，结果到达后才改变占位文案与按钮显隐，统计本身可重复调用而不叠加全量扫描。
- 无当前照片或空文件夹按「无相似照片」空态显示，不报错、不显示动作区。

## SIM-03 提取入口与进度 · 必须

- 同一动作、两种文案：没有相似项时「提取全部」，已有相似项时「补齐全部」。二者都批量处理整个当前文件夹，只写特征库，不改当前照片、不改评分。
- 按钮 `sim.action.width`×`sim.action.height`（90×28），圆角 `sim.action.cornerRadius`（6），底色 `color.sim.action.background`（#2A2A2A）、悬停 `sim.action.hover`（#3A3A3A）、描边 `color.sim.action.border`（#555555）、文字 `color.sim.action.foreground`（#CCCCCC）；宽度固定为卡片宽，不随文案变化撑宽面板。
- 提取中按钮隐藏，同一位置换成进度条：已完成 / 总数；总数未知时用不定态；进度按指纹组推进，不按文件张数。提取中重复触发无效。
- 提取不因关闭面板、切换文件夹或继续浏览而中断；完成后立即刷新未提取计数，并在面板仍可见时按当前锚点重算列表（不需要切图）。
- 提取是长任务，不阻塞主图切图、评分与滚动；进度变化只更新动作区，不重建列表。

## SIM-04 卡片第二行：相似度与柱状条 · 必须

- 面板卡片复用胶片栏卡片（FILM-05），只把第二行由拍摄时间换成相似度：百分比文本 + 柱状占比条。文件名、缩略图、当前项描边、评分星仍按卡片规则。
- 百分比为分数四舍五入到整数（如「93%」）。柱状条宽度取卡片照片宽 `film.thumb.size`（80），底槽 `color.film.card.secondLine.track`（#444444），填充 `color.film.card.secondLine.fill`（#991E90FF）。
- 占比 = `clamp((分数 − sim.score.lowerBound（0.75）) / (1 − sim.score.lowerBound), 0, 1)`：75% 以下为空、100% 满格。它只拉开高分段的视觉差异，不改变显示百分比，也不是"已提取比例"。
- 分数文本压在柱状条之上居中，在底槽与填充两种背景上都必须可读；分数只以数字 + 条双通道表达，不依赖条长推断。
- 相似项的缩略图走与胶片栏同一加载队列（高优先级），卡片身份与几何不等缩略图与分数；分数到达即显示，不等待缩略图。

## SIM-05 点选切图与双高亮 · 必须

- 点击相似项卡片切换主图，主图身份（显示项）变为被点项；胶片栏的锚点高亮留在原照片，两处高亮同时可见（面板取显示身份，胶片栏取锚点身份）。
- 点选不主动滚动胶片栏，也不重排面板列表：面板仍然是原锚点的邻居，被点中的卡片在面板内高亮。
- 点击已在显示的项无动作：不重新加载、不重算、不刷新列表。
- 只有胶片栏的正常切图（点选卡片、上一张/下一张、打开文件或文件夹、外部打开）更新锚点并触发一次新的相似计算；面板内点选与面板内改星都不更新锚点。
- 面板关闭后重新打开，锚点回到当前照片，面板以主图为中心重算。

## SIM-06 计算时机与取消 · 必须

- 唯一触发集：面板可见（展开且文件栏可见）时的打开、锚点切换、候选池变化（筛选、排序、换文件夹）、阈值或数量上限变化。面板不可见时不推理、不解码、不读库；切图本身不触发（SCOPE-01）。
- 打开面板立即按当前照片算一次并统计未提取，不等用户先操作。
- 新计算取消旧计算，最后一次生效；面板关闭或文件栏隐藏立即取消在途计算，之后切图不产生任务。
- 计算中保留上一次结果，直到新结果落地（不闪空态、不清空列表）；新结果到达后整体替换。
- 候选缺特征不触发推理，只计入未提取；面板不为了"凑满列表"去补算候选。

## SIM-07 让位几何与列表 · 必须

- 列布局：面板接在 116 宽文件栏右侧，文件栏整体加宽，主图让出等宽空间；面板宽 `sim.panel.width`（110，卡片 96 + 列表内边距 8 + 两侧描边 2），不小于 `sim.panel.minWidth`（106）。
- 行布局：从胶片栏右侧切出一段。宽度 = `clamp(卡片数 × 96 + sim.list.padding（8） + 2 × sim.panel.border.width（1）, sim.panel.minWidth（106）, 可用宽度 × sim.panel.maxWidthRatio（0.5）) + sim.panel.margin（4）`；可用宽度一半小于最小宽时以可用宽度一半为准（宁可窄，也不挤占主图）。项目数变化（尤其相似项从无到有）必须重算，否则停靠的动作区会把列表挤成零宽。
- 面板交叉轴：列布局 = 面板宽；行布局 = 内容高（卡片 144 + 上下内边距 15 + 两侧描边 2），不小于 `sim.panel.minHeight`（154），空态按内容自然高。外观：底色 `color.sim.panel.background`（#1E1E1E）、1 点描边 `color.sim.panel.border`（#404040）、圆角 `sim.panel.cornerRadius`（6）。
- 收起后分区几何逐项还原到展开前状态，不留空槽、不改变当前照片与主图缩放。让位只改分区宽度：胶片栏偏移只被夹到新宽度内的合法范围，不主动居中。
- 列表单轴排列：行布局横排、横向滚动；列布局竖排、纵向滚动。顺序严格等于分数降序；普通鼠标滚轮在行布局里滚横向列表，与 FILM-04 同口径。
- **应当**：列表整体替换后回到起点（最高分在首）；列表内容不变（改星、缩略图就绪）时不抢用户滚动位置。窄屏手机的入口与几何按平台差异处理，见 platforms.md（SIM-07@android）。

## SIM-08 结果集合：阈值、数量与排序 · 必须

- 候选池 = 当前文件夹经筛选与同名合并后的列表；面板不越过筛选（改星级筛选会改变候选集合，见 SIM-06）。
- 排除自身与同指纹项（同次曝光的 RAW/JPG/HEIF 伴侣），列表里不得出现 100% 的"自己"。
- 只收分数 ≥ 默认 0.85（可调范围 0.75–0.95，`SettingsModel`）的项；按分数降序，同分时拍摄时间更近的优先；最多 8 项（可调范围 1–32，`SettingsModel`）。
- 阈值与数量是用户设置（设置页 AI 分类），改动后立即按当前锚点重算并合并连续拖动，不要求重新打开面板；面板内不提供临时的阈值控件。
- 候选只读库：已入库但缺特征的照片不会以任何估算分数出现，未提取计数负责告知还差多少。

## SIM-09 面板内评分与筛选连续性 · 必须

- 面板卡片的星级按钮只改该照片评分：不切主图、不选中卡片、不触发导航；写回与同名同步走与胶片栏同一路径，失败时可见（见 [state](state.md)）。
- 改星成功后按同一锚点重算：该项若落出当前筛选，就从面板消失；锚点不变。
- 锚点自身被改星并落出筛选时，相似列表仍以锚点为基准，直到用户在胶片栏正常切图；不得因为锚点不在筛选结果里就把面板清空。
- 评分不改变分数、不重排未受影响的项；面板的展开状态与勾选态不受评分影响。

## SIM-10 失败与不可用状态 · 必须

- 提取失败：错误文案与当前状态同时可见（空态在按钮下方，列表态在动作区），按钮恢复可再次触发；已成功写入的特征立即体现在列表与计数里，不回滚已完成的组。
- 相似度计算失败或取消：保留上一次结果，不切成空态、不弹模态框；连续失败不堆积提示。
- 错误文案是可换行的短句（当前颜色 `color.sim.error`，最大宽度 120），不遮挡卡片与按钮，不用颜色单独传达。
- 无相似功能可用（无当前照片、文件栏隐藏、特征库为空）时只显示空态与入口，不显示点了没反应的死控件；不可用时不同时显示进度或提取按钮。
- 退出与强退不损坏已入库特征；下次打开按未提取数继续，不出现"已提取但列表空"的自相矛盾状态。

## SIM-11 无障碍与输入等价 · 应当

- 开关有可读名称「相似聚类」与可读的勾选态；按钮名称即文案（提取全部 / 补齐全部）；「N 张未提取」是状态文本，不是按钮或仅靠颜色表达。
- 面板列表可用鼠标滚轮、触控板滚动与触屏拖动；键盘聚焦面板时可滚动列表，退出后焦点回到触发入口。
- 卡片评分在触屏上命中区不足时由卡片上下文菜单补足（见 [menu](menu.md)）；悬停不得表达选中态，选中态只表达"主图身份"。
- 提取与计算过程对读屏可见：进度以文本（已完成 / 总数）表达，提取中与完成不依赖动画。
