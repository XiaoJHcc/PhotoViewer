# 胶片栏（FILM）

**意图**：用一条可滚动的照片列表快速定位照片、看清每张的状态并直接评分；列表位置属于用户，只有用户明确"去某张"时才由程序滚动。

数值令牌：`film.*`、`motion.film.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#film)，验收状态见 [status.md](../status.md#film)。

## FILM-01 选中与定位分离 · 必须

改变当前照片负责主图与高亮；只有**显式定位请求**负责滚动。不得订阅所有当前照片变化无条件居中，也不得在列表重载时无条件居中。

| 操作 | 切换当前照片 | 主动定位 | 说明 |
|---|---|---|---|
| 点选卡片（鼠标/触摸） | 是 | 否 | 保持用户正在浏览的列表位置 |
| 上一张 / 下一张（按钮、快捷键、绑定的离散滚轮、适应态轻扫） | 是 | 是 | 每个入口都走同一导航命令并发出定位请求；到端点不环绕、不发新请求 |
| 切换上一张（Exchange） | 是 | 否 | 只恢复上一张，不等同于"上一张"；同时更新胶片栏锚点 |
| 打开新目标（文件、文件夹、外部打开、拖入、命令行） | 是 | 是 | 重新枚举目标目录并完整刷新元数据；当前目标见下一行（OPEN-08） |
| 重复拖入或外部激活当前目录/当前照片 | 否 | 否 | 全量刷新（OPEN-08）；保留视口，当前照片已不存在时按 OPEN-04 取首项 |
| 排序、筛选刷新 | 否 | 否 | 只更新列表，不抢用户位置 |
| 评分引起的列表刷新 | 否 | 否 | 暂留规则见 FILM-06 |
| 手动滚动列表 | 否 | 否 | — |
| 普通窗口尺寸变化 | 否 | 否 | 只把偏移约束到合法范围 |
| 缩略图、EXIF、缓存状态就绪 | 否 | 否 | 只刷新卡片内容 |

上一张/下一张的参照：主图照片在当前列表中时以它为准（含相似面板点选后的主图），否则按 FILTER-05 以锚点在重算前列表中的位置为准。

## FILM-02 定位几何与动效 · 必须

- 沿列表主轴把当前卡片中心移到视口中心；横向列表只改 X，纵向只改 Y。不得只做"确保可见"。
- 内容长度 = 前导内边距 + 卡片数 × 卡片长度 + 尾随内边距（`film.list.pad*`）。内容短于视口时：横向列表整段在视口内居中（`film.list.padLeft` 为首项起点下限），纵向列表自顶边起排。
- 目标偏移 = `卡片起点 + (卡片长度 − 视口长度) / 2`，夹到 `[0, max(0, 内容长度 − 视口长度)]`。首尾允许不居中；短列表不制造空白强行居中。
- 动画时长 `motion.film.scroll.duration`，缓动 `motion.film.scroll.easing`（三次缓出 `1 − (1 − t)³`）；距离小于 1 逻辑点不播放。
- 主图立即切换，不被动画阻塞。
- 新请求取消旧动画，从**当前显示位置**接续，最后一次请求生效；不回跳到旧起点。
- 当前项不在筛选结果中、列表为空、栏位隐藏或视图关闭时不启动定位。布局就绪后按真实卡片几何计算；虚拟化不能成为不定位的理由。
- 动画经过的可见卡片照常加载缩略图。

## FILM-03 用户接管与减少动态效果 · 必须

- 用户点选卡片、滚动列表、拖动滚动条或触摸列表时，撤销尚未执行的定位请求和正在播放的动画，位置交还用户。
- 列表替换、方向变化、栏位隐藏、视图关闭时废弃旧目标；下一次显式请求按最新几何重新计算。
- 系统开启减少动态效果时直接定位到终点，触发条件不变。

## FILM-04 方向、顺序与滚轮 · 必须

- 行布局为横向单行，列布局为纵向单列；屏幕顺序严格等于筛选后的业务顺序。
- 方向随布局切换；自动布局按窗口内容区方向，不按照片横竖。
- 普通鼠标纵向滚轮在横向胶片栏上滚动列表，不触发主图翻页；触控板惯性保留。
- **应当**：重新显示胶片栏、切换列表方向时显式定位当前项（视同一次 FILM-02 请求）；普通尺寸变化与列表刷新不属于此列。

## FILM-05 卡片内容与命中区域 · 必须

卡片为竖向矩形（`film.card.*`），内含方形照片区（`film.thumb.size`），照片按原比例适应留边、不拉伸，方形不随控件原生化变形。

卡片内部节点坐标相对内层占位面（`film.card.surface.*`，在外框内缩 `film.card.inset`）：

| 节点 | 位置与尺寸 |
|---|---|
| 照片区 | 左上 `film.card.thumb.inset`（5），边长 `film.thumb.size`（80） |
| 文件名 | 水平居中、宽 `film.card.name.width`（86），y = `film.card.name.y`（89），行高 `film.card.name.height`（12） |
| 第二行 | 水平居中、宽 `film.card.secondLine.width`（80），y = `film.card.secondLine.y`（103），行高 `film.card.secondLine.height`（11） |
| 星级行 | y = `film.card.star.y`（116），六个 `film.card.star.size`（14）见方按钮无间距、在内层宽内居中 |
| 抖动徽标 | 照片区右下角内缩 `film.card.badge.inset`（2），边长 `film.card.badge.size`（16） |

| 元素 | 规则 |
|---|---|
| 当前项 | 卡片外框高亮（`color.film.card.currentBorder`，#0A84FF，四端同值），身份取"当前照片"，不取"鼠标所在" |
| 主图已缓存 | 照片区内一圈淡色细边（`color.film.card.cachedBorder`），只表示主图全分辨率已缓存，与当前项独立；必须四边完整可见，压在缩略图之上 |
| 文件名 | 显示同名合并后的代表名（格式见 FILTER-02）；`film.card.name.fontSize` 半粗、`color.film.card.name`；尾部截断，完整名可查看（桌面 tooltip，触屏卡片菜单标题） |
| 第二行 | 拍摄时间 `MM-dd HH:mm`（照片当地时间）：取共享照片日期，EXIF 缺失时回退文件时间；`film.card.secondLine.fontSize` 粗体、`color.film.card.name`；完整时间 `yyyy-MM-dd HH:mm:ss zzz` 可查看；相似面板中改为相似度（见 SIM） |
| 评分 | 0–5 星，字号 `film.card.star.fontSize`，点亮为金色实心 `icon.starFilled`、未点亮为灰色描边 `icon.star`（`color.star.*`），有独立清零叉（`icon.clear`，字形 `film.card.clearGlyph.size`，`color.star.clear`）；星级显示取代表文件内嵌 Rating，点星改该卡片所属组的全部实际来源（RATING-01/03）；已拒绝（-1）不点亮任何星。点星不选中父卡片 |
| 抖动徽标 | 仅判定为抖动时在照片区右下角显示橙色"抖"（`film.card.badge.*`、`color.film.shakeBadge`）；未分析不显示，不推断为正常 |
| 加载与失败 | 卡片身份与几何不等解码；缩略图与日期异步补齐；未就绪与解码失败显示 `icon.photoPlaceholder`（字号 `film.card.placeholderGlyph.fontSize`、`color.text.secondary`）；解码失败的卡片仍可选为主图，不显示伪造图像 |
| 无筛选结果 | 列表区留空，不显示占位文字（计数 `共 0 张` 已表达结果）；保留筛选控件，不自动改用户条件 |

## FILM-06 评分与筛选的连续性 · 必须

- 评分写回成功（全部实际来源写入并校验为 `Applied`，或全部同值为 `NoChange`）后更新内存与筛选。
- 当前照片因改星不再符合筛选时**暂留**在列表中，切走后再移除；暂留项计入计数，列表与计数一致。
- 评分操作不改变当前主图身份。
- 写回失败或补偿不完整时可见提示（见 [state](state.md)），星级保持原值；按磁盘真实来源状态显示冲突，不把部分成功当作整组成功（[RATING-01](rating.md)、[RATING-03](rating.md)）。
- 代表文件内嵌、伴侣内嵌与每个已存在的 sidecar 随组统一写入；sidecar 不存在时不创建（RATING-01/03）。
- 外部应用改了星级或增删 sidecar 后，按 OPEN-08 的刷新重新读取。写入与同名同步流程见 [architecture](../architecture.md) §5.3。
