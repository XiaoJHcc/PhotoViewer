# 窗口外壳（SHELL）

**意图**：主图优先占据空间，栏位只在用户要求时让位；窗口装饰、拖动区与栏位显隐不得夺走照片、筛选或列表的操作。

数值令牌：`shell.*`、`film.band.height`、`motion.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md)，验收状态见 [status.md](../status.md)。

## SHELL-01 布局模式、分区与栏位显隐 · 必须
- 三种布局模式：行布局（文件栏在上、控制栏在下）、列布局（文件栏在左、控制栏在右）、自动。自动只看窗口内容区宽高比（宽 > 高取列布局），随尺寸与旋转重算，不依据照片横竖；手动模式不因尺寸改变，窗口比例如与模式不符仍按所选模式排布。
- 分区与几何：

| 分区 | 列布局 | 行布局 | 显隐 |
|---|---|---|---|
| 文件栏 | 左列，内容宽 `shell.filebar.content.width`（116）+ `shell.divider.thickness`（1）分隔线 | 顶行：筛选条 + 胶片栏带 `film.band.height`（159）+ `shell.divider.thickness`（1）分隔线 | 可隐藏 |
| 相似面板 | 扩宽文件栏 | 从胶片栏右侧切出 | 随筛选条开关 |
| 主图 | 剩余空间 | 剩余空间 | 恒显示 |
| 分析栏 | 主图右侧 | 主图下方 | 菜单/命令 |
| 控制栏 | 右列，按内容测量 | 底行，按内容测量 | 可隐藏 |

- 文件栏与控制栏可独立显隐，分析栏由菜单/命令开关；隐藏即主轴归零、分隔线消失，空间全部还给主图，不留最小占位；主图不得被任何栏位压到零。
- 显隐与换向不改变当前照片、筛选条件、列表位置与缩放状态；重新显示胶片栏或换向时显式定位当前项（FILM-04）；布局切换只重排，不重建视图、不重载照片。
- 切换布局或换向会废弃正在播放的胶片栏定位并取消排队请求，下一次显式定位按新几何重算（FILM-03）；切换本身不播放布局过渡动画。
- 相似面板在列布局扩宽文件栏、行布局从胶片栏右侧切出；116 仍是文件栏内容宽基准，筛选条不因面板出现而改变三下拉的占位与居中。
- 方形元素（照片区、方形按钮、瓦片）不因原生控件或文字长度拉长（PRIN-03）；栏位隐藏时其命令仍可用，恢复后回到原状态。

## SHELL-02 标题栏、拖动区与标题栏双击 · 必须
- 除下述行布局窄宽度回退外，桌面主窗口内容延伸至窗口顶边；标题栏是浮在内容之上的覆盖层，不占布局高度，高 `shell.titlebar.height`（32）。指针进入顶边热区 `shell.titlebar.hotzone.height`（50）才显示，移出热区、离开窗口、窗口失焦或应用切换即收起；不可见时零命中区域、顶部不可拖动。显隐不播放过渡动画（SHELL-06）。
- 标题栏由标题文字、拖动区与窗口按钮组成。标题文字单行、不参与命中（属于拖动区），放不下时尾部截断，可用宽度不足时隐藏；字体与颜色取平台标题栏文字样式（Windows `CaptionTextBlockStyle`，macOS `titleBarFont`）。Windows 标题格式为 `文件夹名 - 文件名 - PhotoViewer`；无文件时只显示 `PhotoViewer`，文件夹段与文件段同名时不重复，应用名固定保留在末段；macOS 显示窗口标题（当前文件名，无文件为 `PhotoViewer`）。标题文字同时写入系统窗口标题，供任务栏、窗口菜单与调度中心读取。
- 跨度、显隐与背景随布局：

| 状态 | Windows | macOS |
|---|---|---|
| 列布局，文件栏可见 | 从文件栏右缘（含相似面板扩宽与分隔线）到窗口右缘，不盖文件栏；深色亚克力 | 全窗口宽，盖住文件栏；毛玻璃 |
| 行布局，文件栏可见且宽度足够 | 全窗口宽悬停覆盖层，无背景；中间挖空筛选条可点控件的水平范围（全标题栏高），其余部位都是拖动区 | 同左 |
| 行布局，文件栏可见且宽度不足 | 窗口顶边独立通栏，常态显示并占 32 点布局高度；文件栏整体下移；深色亚克力，不挖空 | 窗口顶边独立通栏，常态显示并占 32 点布局高度；文件栏整体下移；毛玻璃，不挖空 |
| 文件栏隐藏（任一布局，含行布局关闭顶部胶片栏） | 全窗口宽悬停覆盖层；深色亚克力，不挖空 | 全窗口宽悬停覆盖层；毛玻璃，不挖空 |

- 文件栏隐藏时筛选条也随容器隐藏，因此不再有筛选挖空；两种桌面平台都必须显示完整的全宽材质标题栏，macOS 不得沿用行布局文件栏可见时的无背景分段形态。
- 行布局窄宽度回退按实际几何判定，不设固定窗口宽度阈值：取得筛选条全部可点控件的联合水平范围，以及平台窗口控制器的实际占用范围（Windows 四个自绘按钮、macOS 系统交通灯）；任一窗口控制器若无法在不覆盖筛选挖空的情况下落位，即进入回退。不得压缩筛选控件、缩小或移动窗口控制器，也不得让二者重叠；标题文字先按既有规则截断或隐藏，不参与回退判定。
- 回退时标题栏位于整个文件栏上方，筛选条、胶片栏与行布局相似面板保持原有尺寸和相对顺序并整体下移，主图让出这 32 点高度。标题栏不依赖顶边热区，指针移出、离开窗口或窗口失焦后仍保持可见与可拖动；不再设置筛选挖空，除窗口控制器外的完整通栏均为拖动区。宽度恢复到控制器与筛选挖空不再相交时，回到悬停覆盖层并释放布局高度；形态切换不播放过渡动画，不改变当前照片、筛选条件、列表位置与缩放状态。全屏时不保留该常驻布局行，仍按各平台既有全屏标题栏规则处理。
- 背景材质只用平台原生定义（Windows 应用内亚克力、macOS 标题栏毛玻璃，均为深色）；覆盖在主图上时必须真实模糊其下方照片，不得退化为回退纯色，不同绘制区段相接处取值一致、不出现色缝。不建附属窗口或表层模拟：独立弹层窗口会盖住系统窗口描边与圆角，拖动、最大化动画也不跟随。材质选型与 Windows 主图区段的交换链内绘制见 platforms.md（SHELL-02@win）。
- 标题文字位置：Windows 左缘距标题栏左缘 `shell.titlebar.title.leftInset`（12），垂直居中；macOS 左缘距最右一个交通灯右缘 12，垂直中线对齐交通灯中线。行布局悬停覆盖层的标题文字止于筛选挖空左缘前 12；窄宽度常驻栏没有筛选挖空，Windows 标题文字止于窗口按钮组前 12，macOS 止于窗口右缘前 12。
- 需要自绘窗口按钮的平台（Windows）去掉系统标题栏，保留系统边框、缩放边缘与圆角；右上角按钮从左到右为全屏、最小化、最大化、关闭，紧贴窗口顶边与右缘、按钮间无间距，外框 `shell.titlebar.button.width`（46）× 标题栏高、无圆角，字形 `shell.titlebar.button.glyphSize`（10）；关闭按钮悬停/按下取 `color.titlebar.close.hover` / `color.titlebar.close.pressed` 且字形转白。字形、提示与读屏名随窗口态切换：最大化 ↔ 还原（最大化态）、全屏 ↔ 退出全屏（全屏态）。行布局无背景时按钮同样只画字形与状态底。字形码位与状态画刷见 platforms.md（SHELL-02@win）。
- Windows 拖动区登记为系统 caption 非客户区，只在标题栏可见时登记，排除窗口按钮与筛选挖空；拖动、双击、拖到屏幕边缘贴靠均由系统处理，不手动发 `HTCAPTION`、不自绘拖动。全屏态标题栏照常悬停显示以便退出全屏，但不登记拖动区，双击留给主图。自绘最大化按钮不提供系统贴靠布局浮层（SHELL-02@win）。
- macOS 交通灯保持系统位置、外观与常显行为，不移动、不重绘；进入系统全屏后自绘标题栏不显示，顶部交给系统。列布局文件栏首控件顶边让位 `shell.filter.leadingInset`（42 = 标题栏高 32 + `filter.margin` 10），避开标题栏与交通灯；Windows 列布局标题栏不盖文件栏，筛选条沿用自身排布。
- 拖动区不得覆盖筛选控件、栏位开关、窗口按钮、交通灯或照片/胶片栏手势；拖动区本身不拦截滚轮、右键与键盘。
- macOS 拖动区内双击按系统“双击标题栏”偏好执行：系统取值为最大化（Zoom/Fill）、最小化、不动作，缺省最大化/缩放；执行后吞掉事件，不落到主图；偏好改变即时生效。判定按落点是否在拖动区内，不依赖鼠标先悬停预热。Windows 双击由系统 caption 处理。
- 全屏无拖动区时不接管双击，留给主图。
- 系统窗口命中优先于内容：系统标题栏、交通灯、拖动区、缩放边缘与系统 resize 区域先于主图空态点击处理；壳不得用任意固定边缘像素猜测系统缩放区，主图只响应自身实际视口内未被这些区域占用的有效点击（INPUT-03、INPUT-10）。
- 触屏平台无窗口装饰与标题栏双击：iOS 隐藏状态栏，设置与栏位显隐由主图长按菜单承担；Android 用系统栏与 insets。若未来显示状态栏，布局按真实安全区自动让位，不写死隐藏。见 platforms.md（SHELL-02@ios、SHELL-02@android）。

## SHELL-03 全屏、窗口尺寸与最小尺寸 · 必须
- 桌面提供系统全屏（系统按钮、菜单或自绘全屏按钮）；进出全屏沿用当前布局与栏位显隐，不重建视图、不重载照片，不改变当前照片、缩放与列表位置；退出回到进入前的窗口帧，不落在最大化态。
- 桌面默认窗口 `shell.window.default.width`（1200）×`shell.window.default.height`（850），最小 `shell.window.min.width`（560）×`shell.window.min.height`（480）；最小尺寸按逻辑点，不随系统文字缩放放大（文字缩放只影响内容排版，溢出按 TOOLBAR-08 滚动）。最小尺寸下布局仍合法，主图不小于 1 点，栏位可继续隐藏。
- 触屏平台不设固定默认/最小窗口尺寸，由系统窗口、分屏或 Stage Manager 决定；不提供全屏入口，系统栏隐藏由平台负责；布局按实际尺寸计算，不套用桌面最小值。
- 最大化、还原、全屏、退出全屏往返后，栏位比例、当前照片、缩放与列表位置不变；最大化不是全屏，全屏不是最大化。
- 设置与工具窗口使用各自的窗口形态与最小尺寸，不受主窗口尺寸规则约束（见 SETTINGS、TOOLS）；主窗口关闭时先关闭这些窗口。

## SHELL-04 窗口与栏位状态持久化 · 应当
- 应当跨会话恢复：布局模式、桌面窗口位置与尺寸、全屏态、文件栏/控制栏显隐；恢复时把窗口帧夹到当前可用屏幕，屏幕移除、分辨率或缩放变化后不得落在屏幕外。
- 恢复顺序：先应用布局模式与栏位显隐，再恢复窗口帧，最后恢复全屏；避免启动后二次布局与可见闪烁。
- 不持久化：排序与星级筛选、当前照片、列表滚动位置、缩放与雾天增强开关（均为会话状态）。相似聚类面板展开状态属于视图状态，经 `IViewStateStore` 跨会话保留，不进设置文档（SIM-01）。
- 首次启动、存储损坏或越界值：回退默认尺寸与全显示，不阻塞启动、不覆盖用户设置、不写回损坏值。

| 状态 | 持久化 | 说明 |
|---|---|---|
| 布局模式 | 是 | 设置 JSON |
| 窗口帧 / 全屏 | 桌面应当 | 平台偏好存储 |
| 文件栏 / 控制栏显隐 | 是 | 平台偏好存储（四端） |
| 相似聚类面板展开 | 是 | `IViewStateStore`（视图状态，不进设置 JSON） |
| 排序 / 星级筛选 | 否 | 会话状态 |
| 当前照片 / 列表滚动位置 | 否 | 会话状态 |
| 缩放 / 雾天增强开关 | 否 | 会话状态 |

- 四端都把文件栏/控制栏显隐写入平台偏好存储（键名沿用 `PhotoViewer.Native.ShowFilm` / `ShowControls`，不进设置 JSON）；分析栏仍为会话态。窗口帧：macOS 用 frame autosave，其余平台能恢复则恢复，不能则按上一条夹取后使用默认帧。见 platforms.md（SHELL-04@mac、SHELL-04@ios）。

## SHELL-05 跨屏与显示环境变化 · 应当
- 窗口移到不同缩放的显示器、系统缩放变化、旋转或分屏尺寸变化时，重算逻辑尺寸与物理倍率；按 IMAGE-03 保持同一图像点居中与同一相对倍率，不重读文件、不回到适应态。
- 显示色域、显示器配置文件或系统色彩管理状态变化时，保持源工作空间与图像缓存不变，只更新输出转换与表面标签，不重新解码。系统负责显示器转换时不再叠加应用端显示器 ICC；系统未管理时按当前显示器配置文件转换，无可用配置文件则按 sRGB 回退。主图、导航图、缩略图与细节预览必须各自具有明确的色彩解释，不把原色编码值直接重贴另一色域标签。观片环境保持深色（PRIN-09），不随系统亮/暗切换。本条只约束主窗口；设置与工具窗口的外观归 SETTINGS-03 / TOOLS-01。
- 跨屏或系统缩放引起的窗口尺寸变化属于普通 resize：胶片栏只把偏移约束到合法范围，不重新定位当前项（FILM-01）；主图按 IMAGE-03 重建，正在播放的定位/缩放动画按新视口收敛或取消，不让旧坐标继续推进。
- 平台无法提供真实物理倍率或广色域表面时如实降级并登记，不把逻辑点 100% 冒充物理 100%，也不宣称已管理色彩（SCOPE-02）。

## SHELL-06 窗口级输入边界 · 应当
- 自绘窗口按钮（最小化、最大化/还原、全屏、关闭）必须能用指针、触屏与键盘触发，并有悬停提示；拖动区只负责拖动窗口，不承载命令，也不截获窗口级按钮的点击。
- 布局切换、全屏切换与拖动区显隐本身不新增过渡动画；系统开启减少动态效果时同样直接到位，布局数学与命中区域不变。
- 触屏上用长按菜单承担窗口级入口，不要求用户点中隐藏热区；可点击的窗口级控件触控目标不小于 44 pt，纯展示的标题文本不参与命中。
- 窗口帧恢复失败不阻塞主流程：按 SHELL-04 把帧夹到当前可用屏幕并保持可用布局，不弹模态；不新增「全屏失败」提示（系统全屏接口无失败回报）。
