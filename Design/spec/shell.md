# 窗口外壳（SHELL）

**意图**：主图优先占据空间，栏位只在用户要求时让位；窗口装饰、拖动区与栏位显隐不得夺走照片、筛选或列表的操作。

数值令牌：`shell.*`、`film.band.height`、`motion.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md)，验收状态见 [status.md](../status.md)。

## SHELL-01 布局模式、分区与栏位显隐 · 必须
- 三种布局模式：行布局（文件栏在上、控制栏在下）、列布局（文件栏在左、控制栏在右）、自动。自动只看窗口内容区宽高比（宽 > 高取列布局），随尺寸与旋转重算，不依据照片横竖；手动模式不因尺寸改变，窗口比例如与模式不符仍按所选模式排布。
- 分区与几何：

| 分区 | 列布局 | 行布局 | 显隐 |
|---|---|---|---|
| 文件栏 | 左列，内容宽 `shell.filebar.content.width`（116）+ `shell.divider.thickness`（1）分隔线 | 顶行：筛选条 + 胶片栏带 `film.band.height`（159）+ `shell.divider.thickness`（1）分隔线 | 可隐藏 |
| 相似面板 | 扩宽文件栏 | 从胶片栏右侧切出 | 随筛选条开关 |
| 主图 | 剩余空间 | 剩余空间 | 恒显示 |
| 分析栏 | 主图右侧 | 主图下方 | 菜单/命令 |
| 控制栏 | 右列，按内容测量 | 底行，按内容测量 | 可隐藏 |

- 文件栏与控制栏可独立显隐，分析栏由菜单/命令开关；隐藏即主轴归零、分隔线消失，空间全部还给主图，不留最小占位；主图不得被任何栏位压到零。
- 显隐与换向不改变当前照片、筛选条件、列表位置与缩放状态；重新显示胶片栏或换向时显式定位当前项（FILM-04）；布局切换只重排，不重建视图、不重载照片。
- 切换布局或换向会废弃正在播放的胶片栏定位并取消排队请求，下一次显式定位按新几何重算（FILM-03）；切换本身不播放布局过渡动画。
- 相似面板在列布局扩宽文件栏、行布局从胶片栏右侧切出；116 仍是文件栏内容宽基准，筛选条不因面板出现而改变三下拉的占位与居中。
- 方形元素（照片区、方形按钮、瓦片）不因原生控件或文字长度拉长（PRIN-03）；栏位隐藏时其命令仍可用，恢复后回到原状态。

## SHELL-02 隐藏式标题栏、拖动区与标题栏双击 · 必须
- 桌面壳内容延伸至窗口顶边，没有独立占高的标题条、常驻文件名条或操作工具条；系统移动、最小化、最大化/缩放、关闭与系统全屏能力保留；标题文本只作窗口元数据，不承载当前文件名或操作入口。
- 顶边热区 `shell.titlebar.hotzone.height`（50）内指针进入才显露拖动区，移出、窗口失焦或应用切换即收起；macOS 拖动区高度行/列取 `shell.dragzone.row.height`（44）/`shell.dragzone.column.height`（24），Windows 跟随可见标题栏高 `shell.titlebar.height`（48）。
- 拖动区不得覆盖筛选控件、栏位开关、标题栏按钮或照片/胶片栏手势；不可见时零命中区域；拖动区本身不拦截滚轮、右键与键盘。
- 有系统交通灯的平台让筛选控件局部避让（macOS 列布局前导 34）；iPad 行布局五项整组在安全内容区内居中；Android 手机行布局从内容前导边 + `filter.margin` 起排；Windows 筛选条沿用其自身原生排布，不因此改写三下拉的占位与居中（FILTER-07@win、FILTER-07@android）。
- 拖动区内双击按系统“双击标题栏”偏好执行：系统取值为最大化（Zoom/Fill）、最小化、不动作，缺省最大化/缩放；执行后吞掉事件，不落到主图；偏好改变即时生效。判定按落点是否在拖动区内，不依赖鼠标先悬停预热。
- 全屏无标题栏时不接管双击，留给主图；窗口失焦、进入全屏或指针离开顶边时拖动区必须收起。
- 需要常驻窗口按钮的平台按 `shell.titlebar.height`（48）排版：按钮 `shell.titlebar.button.width`（36）×`shell.titlebar.button.height`（32）、右侧内边距 `shell.titlebar.buttons.rightInset`（4）、标题左内边距 `shell.titlebar.title.leftInset`（12）；按钮区始终排除在拖动区外，caption 边界按实际按钮布局推导。
- 有系统 caption 的平台（Windows）由系统处理拖动与双击，壳不重复实现；布局未完成时允许用与按钮令牌同式的常量兜底 caption 边界，就绪后以实际布局为准。
- 系统窗口命中优先于内容：系统标题栏、交通灯、拖动区、缩放边缘与系统 resize 区域先于主图空态点击处理；壳不得用任意固定边缘像素猜测系统缩放区，主图只响应自身实际视口内未被这些区域占用的有效点击（INPUT-03、INPUT-10）。
- 触屏平台无窗口装饰与标题栏双击：iOS 隐藏状态栏，设置与栏位显隐由主图长按菜单承担；Android 用系统栏与 insets。若未来显示状态栏，布局按真实安全区自动让位，不写死隐藏。见 platforms.md（SHELL-02@ios、SHELL-02@android）。

## SHELL-03 全屏、窗口尺寸与最小尺寸 · 必须
- 桌面提供系统全屏（系统按钮、菜单或自绘全屏按钮）；进出全屏沿用当前布局与栏位显隐，不重建视图、不重载照片，不改变当前照片、缩放与列表位置；退出回到进入前的窗口帧，不落在最大化态。
- 桌面默认窗口 `shell.window.default.width`（1200）×`shell.window.default.height`（850），最小 `shell.window.min.width`（560）×`shell.window.min.height`（480）；最小尺寸按逻辑点，不随系统文字缩放放大（文字缩放只影响内容排版，溢出按 TOOLBAR-08 滚动）。最小尺寸下布局仍合法，主图不小于 1 点，栏位可继续隐藏。
- 触屏平台不设固定默认/最小窗口尺寸，由系统窗口、分屏或 Stage Manager 决定；不提供全屏入口，系统栏隐藏由平台负责；布局按实际尺寸计算，不套用桌面最小值。
- 最大化、还原、全屏、退出全屏往返后，栏位比例、当前照片、缩放与列表位置不变；最大化不是全屏，全屏不是最大化。
- 设置与工具窗口使用各自的窗口形态与最小尺寸，不受主窗口尺寸规则约束（见 SETTINGS、TOOLS）；主窗口关闭时先关闭这些窗口。

## SHELL-04 窗口与栏位状态持久化 · 应当
- 应当跨会话恢复：布局模式、桌面窗口位置与尺寸、全屏态、文件栏/控制栏显隐；恢复时把窗口帧夹到当前可用屏幕，屏幕移除、分辨率或缩放变化后不得落在屏幕外。
- 恢复顺序：先应用布局模式与栏位显隐，再恢复窗口帧，最后恢复全屏；避免启动后二次布局与可见闪烁。
- 不持久化：排序与星级筛选、当前照片、列表滚动位置、缩放与雾天增强开关（均为会话状态）。相似聚类面板展开状态属于设置，随设置持久化。
- 首次启动、存储损坏或越界值：回退默认尺寸与全显示，不阻塞启动、不覆盖用户设置、不写回损坏值。

| 状态 | 持久化 | 说明 |
|---|---|---|
| 布局模式 | 是 | 设置 JSON |
| 窗口帧 / 全屏 | 桌面应当 | 平台偏好存储 |
| 文件栏 / 控制栏显隐 | 是 | 平台偏好存储（四端） |
| 相似聚类面板展开 | 是 | 设置 JSON |
| 排序 / 星级筛选 | 否 | 会话状态 |
| 当前照片 / 列表滚动位置 | 否 | 会话状态 |
| 缩放 / 雾天增强开关 | 否 | 会话状态 |

- 四端都把文件栏/控制栏显隐写入平台偏好存储（键名沿用 `PhotoViewer.Native.ShowFilm` / `ShowControls`，不进设置 JSON）；分析栏仍为会话态。窗口帧：macOS 用 frame autosave，其余平台能恢复则恢复，不能则按上一条夹取后使用默认帧。见 platforms.md（SHELL-04@mac、SHELL-04@ios）。

## SHELL-05 跨屏与显示环境变化 · 应当
- 窗口移到不同缩放的显示器、系统缩放变化、旋转或分屏尺寸变化时，重算逻辑尺寸与物理倍率；按 IMAGE-03 保持同一图像点居中与同一相对倍率，不重读文件、不回到适应态。
- 显示色域或背光环境变化时按源色彩空间重新标记输出，不重新解码；观片环境保持深色（PRIN-09），不随系统亮/暗切换。本条只约束主窗口；设置与工具窗口的外观归 SETTINGS-03 / TOOLS-01。
- 跨屏或系统缩放引起的窗口尺寸变化属于普通 resize：胶片栏只把偏移约束到合法范围，不重新定位当前项（FILM-01）；主图按 IMAGE-03 重建，正在播放的定位/缩放动画按新视口收敛或取消，不让旧坐标继续推进。
- 平台无法提供真实物理倍率或广色域表面时如实降级并登记，不把逻辑点 100% 冒充物理 100%，也不宣称已管理色彩（SCOPE-02）。

## SHELL-06 窗口级输入边界 · 应当
- 自绘窗口按钮（最小化、最大化/还原、全屏、关闭）必须能用指针、触屏与键盘触发，并有悬停提示；拖动区只负责拖动窗口，不承载命令，也不截获窗口级按钮的点击。
- 布局切换、全屏切换与拖动区显隐本身不新增过渡动画；系统开启减少动态效果时同样直接到位，布局数学与命中区域不变。
- 触屏上用长按菜单承担窗口级入口，不要求用户点中隐藏热区；可点击的窗口级控件触控目标不小于 44 pt，纯展示的标题文本不参与命中。
- 窗口帧恢复失败不阻塞主流程：按 SHELL-04 把帧夹到当前可用屏幕并保持可用布局，不弹模态；不新增「全屏失败」提示（系统全屏接口无失败回报）。
