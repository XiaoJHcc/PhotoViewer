# 输入与快捷键（INPUT）

**意图**：同一条命令在键盘、鼠标、触控板、触屏上语义一致，并且都能由用户改绑；照片的全局快捷键只在用户真正操作照片时生效，输入文字或录制按键时绝不误触。

数值令牌：`image.swipe.*`、`image.keyRepeat.*`、`image.zoom.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#input)，验收状态见 [status.md](../status.md#input)。

## INPUT-01 快捷键沿用用户主/次绑定 · 必须

- 平台事件只解包成共享手势（键 + 修饰键，或鼠标动作），再查同一张用户主/次绑定表。壳内不维护第二份快捷键，不改写手势编码与设置 JSON 字段名。
- 每条命令有主、次两个槽位，可单独清空；空槽不动作。改绑后主窗口、控制栏 tooltip 与菜单立即生效，不要求重启。
- 平台只负责把原生键值解码为共享手势键，持久化的是手势标识而不是某平台的键码或显示文本；显示文本按平台本地化。
- 两条命令共用同一手势时，冲突必须在设置行内可见，但不阻止保存；派发按设置列表顺序取第一条命中，行为可预测。
- Apple 平台的修饰键映射（使用苹果键盘 / Cmd·Option·Ctrl 目标）是保留的设置项；其他平台按自身修饰键语义解码，持久化字段不变。无录制能力的平台差异见 platforms.md（INPUT-08@ios、INPUT-08@android）。

| 命令 | 默认主绑定 | 默认次绑定 | 控制栏默认显示 |
|---|---|---|---|
| 打开文件 | Ctrl+N | Ctrl+O | 否 |
| 上一张 | ← | 滚轮上 | 是 |
| 下一张 | → | 滚轮下 | 是 |
| 切换上一张 | Z | 中键 | 是 |
| 缩放适应 | Ctrl+0 | F | 是 |
| 放大（预设） | Ctrl++ | — | 是 |
| 缩小（预设） | Ctrl+− | — | 是 |
| 放大（比例） | Ctrl+滚轮上 | — | 否 |
| 缩小（比例） | Ctrl+滚轮下 | — | 否 |
| 分析栏展开/收纳 | — | — | 否 |
| 增强预览 | E | — | 是 |
| 评分 0–5 | ` / 1 / 2 / 3 / 4 / 5 | 小键盘 0–5 | 否 |

## INPUT-02 焦点抑制：文字输入、录制与模态 · 必须

INPUT-01 的"输入或录制控件获焦时不误触"细化为下表。抑制只作用于照片命令，不作用于系统级输入。

| 条件 | 行为 |
|---|---|
| 文本输入控件获焦（含输入法组合中） | 不派发照片命令；字母、数字、方向键只作用于输入 |
| 快捷键录制中 | 除 Esc / Delete / Backspace 外不派发任何命令，滚轮与中键也被吞掉（见 INPUT-08） |
| 模态展示（设置、工具、文档选择器、系统菜单提交页） | 不派发；收起后恢复 |
| 无编辑焦点且无模态 | 正常派发 |

- 恢复判据是"不存在编辑焦点且无模态"，不是"窗口重新获得焦点"：移动端模态收起、输入结束且无其他编辑框时，主图重新取得键盘焦点，快捷键立即恢复。
- 不得停留在"按钮看起来可用但按键无响应"的状态；恢复失败按缺陷处理。
- 桌面窗口在非前台时系统本就不派发，壳不得靠"是否 key window"代替上述判据。

## INPUT-03 手势到语义的映射 · 必须

| 输入 | 语义 | 边界 |
|---|---|---|
| 空态主图区单击/点按 | 打开文件选择器 | 提示文字点击穿透；细节预览定格时点按先解除定格（ANALYSIS） |
| 照片双击 | 适应 ⇄ 100%，以触点为锚 | 见 IMAGE-02 |
| 放大态拖动 / 双指滚动 | 平移照片 | 边缘钳制，不翻页 |
| 捏合 | 连续缩放，锚点在手势中心 | 允许短动画，尊重减少动态效果 |
| 精确滚动（触控板） | 平移并保留惯性 | 不当作连续翻页 |
| 离散滚轮 | 用户鼠标绑定（默认上一张/下一张） | 见 INPUT-04 |
| 适应态单指横滑 | 上一张 / 下一张 | 仅触屏，见 INPUT-06 |
| 长按 / 右键 / 辅助点按 | 上下文菜单 | 见 INPUT-07 |
| 修饰键 + 滚轮或按键 | 按绑定表执行（缩放等） | 优先于默认语义 |

同一手势不得承担两个语义；平台只能改变控件外观，不能以"原生习惯"改变手势含义。触控板与鼠标并存时按事件类型分流，不按设备名猜测。

## INPUT-04 离散滚轮与连续滚动 · 必须

- 判据是事件是否精确（precise / high-resolution），不是设备名：精确滚动平移照片，离散滚轮执行绑定命令。
- 离散滚轮按格计数，一格一次命令；同一次手势内不重复派发，也不把高频事件当成"每帧翻一张"。
- 带用户绑定的修饰键手势优先于默认语义（如 Ctrl+滚轮缩放而非翻页）。
- 横向胶片栏上的普通纵向滚轮滚动列表，不翻页（FILM-04）；触控板惯性保留。
- 精确与离散的判据四端同一实现：触控板两指滚动只平移，鼠标滚轮一格一次命令；离散事件累积到一格才派发。

## INPUT-05 按住按键的重复 · 应当

- 只对可连续执行的命令重复：上一张/下一张、预设缩放。评分、打开、切换上一张、栏位显隐、增强、适应按住只执行一次。
- 可重复命令由共享命令表标记（Repeatable），四端重复入口按同一标记设闸：不在清单内的命令按住只执行一次。
- 桌面跟随系统键盘重复速率；iOS 无公开速率接口，用 `image.keyRepeat.delay`（350 ms）与 `image.keyRepeat.interval`（60 ms）固定节奏。
- 每次重复重新查当前绑定；设置改变、按键抬起、进入抑制态（INPUT-02）立即停止。
- 窗口失活、焦点切换、弹出菜单时清空按住状态，不得在返回后补发积压的重复。
- 平台差异见 platforms.md（INPUT-05@ios）。

## INPUT-06 适应态轻扫翻页 · 应当

- 仅触屏直接操作照片时生效；只有适应态翻页，放大态横滑仍是平移。
- 单指；水平位移超过 `image.swipe.threshold`（24）且明显大于纵向位移。双指起手不翻页。
- 走共享上一张/下一张命令，因此同时发出显式定位请求（FILM-01）；端点不环绕、不发新请求。
- 与双击、捏合、导航图拖动互不抢占：先落定的手势胜出，另一次手指不改变已完成的手势结果。
- 系统减少动态效果不改变是否翻页，只让定位直接到终点（FILM-03）。
- 平台差异见 platforms.md（INPUT-06@ios）。

## INPUT-07 长按与右键的菜单入口 · 应当

- 桌面为右键（含触控板辅助点按），触屏为长按；两者打开同一菜单，项、顺序与勾选态读同一共享状态。
- 菜单锚在指针/手指处；弹出不移动、不缩放照片；卡片菜单保留系统抬升且不移动列表布局。
- 长按不触发单击语义（不打开文件、不切图）；菜单收起后焦点回到照片。
- 菜单内容与分组归 MENU，本条目只管触发与锚点。

## INPUT-08 快捷键录制 · 必须

- 入口是设置控制列表行的主/次绑定按钮；点击后进入录制态并显示"按下按键…"。
- 下一次完整手势即绑定：单键 + 修饰键、鼠标按键或滚轮。只按修饰键不提交，也不结束录制。
- Esc 取消并保留原绑定；Delete/Backspace 清空该槽位。
- 录制期间吞掉滚轮与中键（避免滚动页面或误触菜单），并在预览阶段标记空格与方向键为已处理，不让列表滚屏或移动焦点。
- 完成后只刷新该行，不重建整页；冲突按 INPUT-01 标在行内。
- 设置页关闭时放弃未完成的录制，不写入半个手势；窗口失活不静默提交。
- 平台差异见 platforms.md（INPUT-08@ios、INPUT-08@android）。

## INPUT-09 预设缩放与比例缩放 · 应当

- 放大/缩小（预设）：在设置里的缩放预设中，取比当前物理倍率大的最近一档或小的最近一档；到端点不环绕、不动作。
- 放大/缩小（比例）：×`image.zoom.step.in`（1.25）/ ×`image.zoom.step.out`（0.8），以视口中心为锚，不跟随指针。
- 物理倍率范围 `image.zoom.minScale`（0.01）–`image.zoom.maxScale`（16）；到界后命令无效但不报错。
- 放大到 100% 时按 IMAGE-01 请求全分辨率；缩放命令本身不改变照片身份。

## INPUT-10 无照片与不可用命令 · 应当

- 需要照片的命令在无照片时：控制栏按钮禁用但不隐藏，快捷键与菜单项不动作、不弹错误。
- 打开类命令始终可用（打开文件、打开文件夹）。
- 空态主图区左键/点按打开文件选择器；提示文字与遮罩必须点击穿透。细节预览定格时，该次点按先解除定格，不在同一次点按上再开选择器。
- 平台尚未实现的能力隐藏入口而不是"点了没反应"（SCOPE）。

## INPUT-11 系统输入优先 · 应当

- Esc 先关当前最上层浮层（菜单、录制、设置/工具页），没有浮层时不吞事件。
- 移动端返回先关浮层（设置/工具 sheet、菜单），再交给系统返回；不得直接退出应用。
- 顶部拖动区内的双击按 SHELL-02 处理，不进入照片快捷键；区外双击归主图。
- 未绑定到任何命令的按键原样放行，不得标记为已处理。
- 系统手势（多任务、通知中心、窗口全屏切换）不被照片手势拦截。

## INPUT-12 触屏等价入口与焦点 · 必须

- 翻页、评分、缩放适应、打开文件、栏位显隐、分析栏与增强预览至少各有一个非快捷键入口（控制栏按钮、主图菜单或卡片菜单）；不得只存在于硬件键盘。
- 低于平台建议触控尺寸的控件必须由菜单补足同一操作（卡片星级 14 点由卡片菜单评分承担，FILM-05）。
- 不能捏合或轻扫的用户可用命令按钮与菜单完成缩放、翻页（PRIN-05）。
- 键盘与辅助技术的焦点顺序沿可见分区（文件栏 → 主图 → 控制栏）；隐藏的栏位不占焦点顺序，焦点不落入不可见控件。
