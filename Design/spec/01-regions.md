# L1 分区

主窗口由下列分区组成。布局分两向：**行布局**（上下，竖向窗口）与**列布局**（左右，横向窗口），另有**自动**按窗口内容区宽高比在两者间切换（不依据照片横竖）。几何数值见 `tokens.json`，行为规则见各 L2 文件。

```text
列布局（左右）                                   行布局（上下）
┌────────┬──────────────────────┬────┐          ┌──────────────────────────────┐
│ 筛选条 │                      │控制│          │ 筛选条 │ 胶片栏 …   │相似面板│
│────────│                      │ 栏 │          ├──────────────────────────────┤
│ 胶片栏 │        主图          │EXIF│          │                              │
│        │                      │评分│          │            主图              │
│        │                      │命令│          ├──────────────────────────────┤
│ 相似面板│                      │    │          │           分析栏             │
│ (扩宽) ├──────────────────────┤    │          ├──────────────────────────────┤
│        │       分析栏(右侧)    │    │          │   EXIF · 评分 · 命令         │
└────────┴──────────────────────┴────┘          └──────────────────────────────┘
```

| 分区 | 职责 | 位置（列 / 行） | 显隐 | L2 |
|---|---|---|---|---|
| 窗口外壳 | 承载分区；隐藏式标题栏与窗口操作；拖入 | 全窗口 | — | [shell](shell.md) |
| 文件栏 | 筛选条 + 胶片栏的容器，整体可隐藏 | 左列 / 顶行 | 可隐藏，状态持久化 | [shell](shell.md) |
| 筛选条 | 排序、升降序、星级筛选、计数、相似聚类开关 | 文件栏顶部 / 文件栏左端 | 随文件栏 | [filter](filter.md) |
| 胶片栏 | 用列表快速定位照片、看状态、直接评分 | 筛选条下方 / 筛选条右侧 | 随文件栏 | [film](film.md) |
| 相似面板 | 当前照片的相似照片列表与提取入口 | 扩宽文件栏 / 胶片栏右侧切出 | 筛选条开关，持久化 | [similarity](similarity.md) |
| 主图 | 观片：适应/100%/缩放平移、代理到全分辨率、导航图、状态提示 | 中央 | 恒显示 | [image](image.md) · [state](state.md) |
| 分析栏 | 对焦点/中心细节、直方图、DINO 与 CV 诊断瓦片 | 主图右侧 / 主图下方 | 命令与菜单开关 | [analysis](analysis.md) |
| 控制栏 | EXIF 摘要、评分、用户启用的命令按钮 | 右列 / 底行 | 可隐藏，持久化 | [toolbar](toolbar.md) |
| 上下文菜单 | 主图菜单（窗口级入口）与卡片菜单 | 浮层 | — | [menu](menu.md) |
| 设置窗口 | 布局、快捷键、控制栏、EXIF、评分、文件格式、性能与 AI 设置 | 独立窗口 / 半屏 | — | [settings](settings.md) |
| 工具窗口 | EXIF 详情、DINO 诊断、照片数据统计 | 独立窗口 / 半屏 | — | [tools](tools.md) |

跨分区的输入、打开与功能边界规则分别见 [input](input.md)、[open](open.md)、[scope](scope.md)。
