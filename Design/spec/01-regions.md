# L1 分区

主窗口由下列分区组成。布局模式有四档（SETTINGS-08）：**行布局**（上下，竖向窗口）、**列布局**（左右，横向窗口）、**自动**按窗口内容区宽高比在两者间切换（不依据照片横竖），以及**手机**。行/列/自动是宽形态；手机形态另有竖屏、横屏两种排布（SHELL-07–SHELL-09），下面的宽形态示意与表描述 AI 版的完整分区，手机形态的结构见其后的小节。几何数值见 `tokens.json`，行为规则见各 L2 文件。下表描述 AI 版的完整分区；标准版不包含相似面板及 DINO 瓦片，诊断工具改为 CV 诊断，入口与实际占位按 [editions](editions.md) EDITION-02 收敛。

```text
列布局（左右）                                        行布局（上下）
┌────────┬────────┬─────────────────┬──────┬────┐   ┌──────────────────────────────┐
│ 筛选条 │        │                 │      │控制│   │     筛选条（整行居中）       │
│────────│ 相似   │                 │      │ 栏 │   ├────────────────────┬─────────┤
│ 胶片栏 │ 面板   │      主图       │分析栏│EXIF│   │ 胶片栏 …           │相似面板 │
│        │(扩宽)  │                 │      │评分│   ├────────────────────┴─────────┤
│        │        │                 │      │命令│   │            主图              │
│        │        │                 │      │    │   ├──────────────────────────────┤
│        │        │                 │      │    │   │           分析栏             │
│        │        │                 │      │    │   ├──────────────────────────────┤
│        │        │                 │      │    │   │   EXIF · 评分 · 命令         │
└────────┴────────┴─────────────────┴──────┴────┘   └──────────────────────────────┘
```

| 分区 | 职责 | 位置（列 / 行） | 显隐 | L2 |
|---|---|---|---|---|
| 窗口外壳 | 承载分区；桌面悬停标题栏与窄宽度常驻栏、窗口操作；拖入 | 全窗口 | 标题栏默认悬停显示，行布局窄宽度时常驻 | [shell](shell.md) |
| 文件栏 | 筛选条 + 胶片栏的容器，整体可隐藏 | 左列 / 顶行 | 可隐藏，状态持久化 | [shell](shell.md) |
| 筛选条 | 排序、升降序、星级筛选、计数、相似聚类开关 | 文件栏顶部纵排 / 文件栏顶部整行 | 随文件栏 | [filter](filter.md) |
| 胶片栏 | 用列表快速定位照片、看状态、直接评分 | 筛选条下方 / 筛选条下方整行 | 随文件栏 | [film](film.md) |
| 相似面板 | 当前照片的相似照片列表与提取入口 | 文件栏右侧扩宽、与胶片栏同顶 / 胶片栏右端切出 | 筛选条开关，持久化 | [similarity](similarity.md) |
| 主图 | 观片：适应/100%/缩放平移、代理到全分辨率、导航图、状态提示 | 中央 | 恒显示 | [image](image.md) · [state](state.md) |
| 分析栏 | 对焦点/中心细节、直方图、DINO 与 CV 诊断瓦片 | 主图右侧 / 主图下方 | 命令与菜单开关 | [analysis](analysis.md) |
| 控制栏 | EXIF 摘要、评分、用户启用的命令按钮 | 右列 / 底行 | 可隐藏，持久化 | [toolbar](toolbar.md) |
| 上下文菜单 | 主图菜单（窗口级入口）与「更多」按钮菜单 | 浮层 | — | [menu](menu.md) |
| 设置窗口 | 布局、快捷键、控制栏、EXIF、评分、文件格式、性能与 AI 设置 | 独立窗口 / 半屏 | — | [settings](settings.md) |
| 工具窗口 | EXIF 详情、DINO 诊断、照片数据统计 | 独立窗口 / 半屏 | — | [tools](tools.md) |

### 手机形态

手机形态的栏位是浮在满窗口主图之上的行与列（SHELL-11），分区结构如下；判定见 SHELL-07。

```text
手机竖屏                           手机横屏（刘海在左、下巴在右）
┌──────────────────────────────┐   ┌────────┬────────────────┬───────┬──────────┐
│ 筛选        EXIF        更多 │   │  筛选  │                │       │   EXIF   │
├──────────────────────────────┤   │ /更多  │                │       │          │
│            分析栏            │   │        │                │       │          │
├──────────────────────────────┤   ├────────┤                │       │          │
│             主图             │   │        │                │       │   星级   │
├──────────────────────────────┤   │  胶片  │      主图      │分析栏 │          │
│            胶片栏            │   │        │                │       │          │
├──────────────────────────────┤   ├────────┤                │       │适应/增强 │
│ 上下张  星级控件  适应/增强  │   │ 上下张 │                │       │          │
└──────────────────────────────┘   └────────┴────────────────┴───────┴──────────┘
```

| 形态 | 结构（自外向内） | 规则 |
|---|---|---|
| 手机竖屏 | 顶部行（筛选 · EXIF · 更多；EXIF 开关关闭时筛选与更多上移到灵动岛/刘海两旁的显示区）→ 分析栏（出现时）→ 主图 → 胶片栏（出现时）→ 底部行（上下张 · 星级控件 · 适应/增强） | [SHELL-08](shell.md) |
| 手机横屏 | 刘海侧列（筛选/更多 · 胶片栏 · 上下张；胶片栏关闭时筛选与更多分开落在刘海上下两旁的显示区）→ 主图 → 分析栏（出现时）→ 控制栏（EXIF 无衬底纵排 · 星级控件 · 适应/增强，自上而下） | [SHELL-09](shell.md) |

横屏最右一列即控制栏：EXIF、星级控件与适应/增强按钮自上而下同一中轴，除 EXIF 与按钮之外的长度全部给星级控件（SHELL-09、TOOLBAR-02）。筛选与更多在两种形态下都常驻，栏位开关只收起各自的栏。

栏位显隐、材质与图区避让见 [SHELL-11](shell.md)、[SHELL-12](shell.md)。

跨分区的输入、打开与功能边界规则分别见 [input](input.md)、[open](open.md)、[scope](scope.md)。
