# 备选合并稿（state 代理越界产出，待与各模块 spec 对账后删除）

# 主窗口交互与状态（SHELL · FILTER · IMAGE · TOOLBAR · ANALYSIS · SIM · MENU · INPUT · OPEN · STATE · SETTINGS · TOOLS · SCOPE）

**意图**：四端用同一套分区、命令与状态语义完成选片；规则只写可核对的行为，控件选型与验收记录分属 platforms.md 与 status.md。

数值令牌：`shell.*`、`filter.*`、`image.*`、`nav.*`、`toolbar.*`、`analysis.*`、`sim.*`、`status.*`、`exiftable.*`、`motion.*`（见 [tokens.json](../../tokens.json)）。平台差异见 [platforms.md](../../platforms.md)，验收状态见 [status.md](../../status.md)。

## SHELL-01 布局模式与分区显隐 · 必须
- 行布局（文件栏在上、控制栏在下）、列布局（文件栏在左、控制栏在右）、自动；自动只看窗口内容区宽高比（宽 > 高取列布局），不按照片横竖。改尺寸、旋转只重算布局，不重置栏位显隐、当前照片与列表位置。
- 分区固定为文件栏（筛选条 + 胶片栏 + 相似面板）、主图、分析栏、控制栏，之间 `shell.divider.thickness`（1）分隔；文件栏与控制栏分别可隐，分析栏由菜单/命令控制。
- 隐藏即主轴归零、空间全部还给主图，不留最小占位；主图恒显示；显隐不改变筛选、列表位置与缩放；方形元素（照片区、方形按钮、瓦片）不因原生化变形（PRIN-03）。

## SHELL-02 隐藏式标题栏、拖动区与标题栏双击 · 必须
- 桌面壳内容延伸到窗口顶边，没有独立占高的标题条；系统窗口能力（关闭、最小化、缩放、拖动、系统全屏）保留，标题文字只作窗口元数据。
- 顶边悬停显示拖动区，离开或失焦隐藏；拖动区不压筛选控件与标题栏按钮，不吞主图/胶片栏手势。热区：Windows `shell.titlebar.hotzone.height`（50），macOS 行 `shell.dragzone.row.height`（44）/ 列 `shell.dragzone.column.height`（24）。
- 拖动区内双击按系统偏好执行（缺省 = 最大化/缩放切换，或最小化，或不动作），执行后吞掉事件；全屏无标题栏时不接管。触屏平台无窗口装饰：iOS 隐藏状态栏、窗口级入口由主图菜单承担；Android 用系统栏与 insets。见 platforms.md。

## SHELL-03 全屏与窗口状态持久化 · 应当
- 只有桌面端提供全屏（系统按钮 + 显示菜单）；进入/退出沿用布局与显隐，不重建视图、不重载照片；退出恢复原窗口帧；移动端不提供入口。
- 默认窗口 `shell.window.default.width`（1200）×`shell.window.default.height`（850），最小 `shell.window.min.width`（560）×`shell.window.min.height`（480）。
- 持久化：布局模式（设置 JSON）、栏位显隐、窗口帧与全屏（平台偏好存储），恢复时约束到当前可用屏幕，跨屏按新物理倍率与色域重算。不持久化排序、星级筛选与当前照片。平台差异见 platforms.md（shell-03@android）。

## FILTER-01 排序、升降序、星级筛选、计数与相似聚类开关 · 必须
- 三下拉：排序方式（名称 / 拍摄时间 / 文件大小）、升降序、星级筛选（全部 / 无星级 / 一星…五星 / 一星以上…四星以上 / 星级冲突）。下拉用平台原生控件，勾选/键盘/取消由系统负责，控件几何不改。
- 任一变更只重建列表：不切当前照片、不主动定位、不抢列表位置；选择不被刷新、评分或切图重置。
- 计数显示筛选结果张数（「共 N 张」），随筛选、评分与刷新同步，空结果为 0 且保留条件；相似聚类开关读写同一持久化状态并立即展开/收起，不显示时不占位、显示时参与整组居中。

## FILTER-02 排序键与回退 · 必须
- 名称按文件名（同名合并取代表文件）；拍摄时间取共享照片日期，缺失回退文件时间，仍缺失按 `DateTimeOffset.MinValue` 比较（升序最前、降序最后）；大小按字节数。
- 同键等值保持筛选后的原始相对顺序（稳定排序）；排序只改顺序，不改变当前照片身份与计数。

## FILTER-03 筛选条几何 · 必须
- 行布局：三下拉各 `filter.control.width`（90）×`filter.control.height`（32）、间距 `filter.gap`（5），连同自然宽计数与开关整组横向居中；列布局在 `shell.filebar.content.width`（116）栏内纵向居中。
- 开关 `filter.toggle.width`（90）×`filter.toggle.height`（27）紧随计数之后/之下；计数槽高 `filter.count.height`（17）；外观可原生，占位与居中不变。
- 窄屏用 `filter.compact.control.width`（84）/`filter.compact.toggle.width`（76）；无窗口装饰的平台行布局从内容前导边起排，不留交通灯空带。见 platforms.md（filter-03@ios / @android）。

## IMAGE-01 主图显示、100% 口径与代理→Full · 必须
- 切图先显示代理（长边 = 视口物理像素 × overscan 2.0），Full 就绪同变换热替换；100% 及以上永远用 Full 源（PRIN-01）。
- 100% = 1 源像素对 1 屏幕物理像素（Retina 2× 不铺成 2×2）；其他倍率按同一口径显示百分比。
- 代理→Full 只换纹理：缩放、平移、朝向、导航帧与导航图可见框都不变。
- 快速翻图时新图未命中立即清旧图，代际闸作废在途加载，不把上一张当占位继续显示。
- 放大到 100%、分析栏可见（细节预览要全分辨率源）触发 Full；内存压力下的编码降级不改变几何。

## IMAGE-02 双击、Fit 命令与切图保持缩放 · 必须
- 双击 = 以触点为不动点在适应 ⇄ 物理 100% 间切换，已放大回适应；Fit 命令（按钮/热键）在适应态优先以 Sony 对焦点为中心放大到物理 100%，无对焦点取视口中心，已放大回适应。
- 放大态切图保持倍率：跟随对焦时居中到新照片对焦点，否则保持同一归一化中心点；适应态切图仍适应，不沿用上次放大。
- 素材物理像素不大于视口时没有向上余量，目标倍率不高于适应倍率即夹回适应（移动端 RAW 内嵌预览同口径）。
- 窗口尺寸或物理倍率变化按「同一图像点留在视口中心 + 同一相对缩放」重建；代理→Full 不动视口。
- 打开文件或文件夹是新的观察会话，视口回到适应态；只有列表内切图保持缩放。

## IMAGE-03 缩放/平移锚点与边界 · 必须
- 捏合、Ctrl+滚轮、双击与细节预览定位都以手指/指针下的图像点为不动点，不把内容原点当锚点；无锚点的命令才用视口中心。
- 平移钳制在照片边界内：小于视口的轴居中，照片不被拖出视口、不出现大片空白；放大态拖动只平移。
- 缩放上限 `image.zoom.max-scale`（16，物理倍率），下限为适应倍率；平台未声明上限时按同一值对齐。
- 用户每次移动/缩放后按 5% 归一化容差重估「是否跟随对焦」，程序化缩放与重建不清除刚作出的跟随决定；空图或手势起点在主图外时不缩放。

## IMAGE-04 导航图（缩放指示器） · 应当
- 非适应态且设置「缩放时显示指示器」开启时显示在主图区右下角（安全区内，避让控制栏、分析栏与提示条），适应态与无图时隐藏。
- 长边 `nav.long-edge`（150）按显示朝向比例；圆角 `nav.corner-radius`（6）、白框 `nav.frame.thickness`（1）、外边距 `nav.margin`（12）；百分比为物理倍率。
- 可见框与共享视口几何一致并随缩放/平移更新；缩略图用小目标渲染，不重画全分辨率；切图、增强、代理→Full 时随主图更新。
- 触屏可点按/拖动把该点移到视口中心；桌面只展示。见 platforms.md（image-04@ios / @android）。

## IMAGE-05 增强预览 · 应当
- 控制栏命令/菜单开关，会话级状态跨切图持续；关闭立即还原原图，不改缩放、平移与导航帧。
- 计算期间在主图底部居中显示「计算中…」药丸（`image.busy.width` 96 × `image.busy.height` 28，圆角 `image.busy.corner-radius` 11，距底 `image.busy.bottom-offset` 24），不遮挡导航图与控件、不拦手势。
- 计算失败或取消时不呈现半增强画面：保留原图并给出可读提示（STATE-03）；被内存压力关闭（Warning 起）时撤销开关并回原图；增强不改方向、源尺寸与 EXIF。

## TOOLBAR-01 三分组、顺序与用户配置 · 必须
- 固定三组、按顺序：EXIF 摘要 → 评分（`ShowRating` 开启时）→ 命令（`IsDisplay` 与用户顺序）。
- 空间不足整组换行/换列，组内不拆散，每行/列居中，同一行的组交叉轴拉伸、组内控件居中；不摊平成长列。
- 评分横排 0→5、竖排 5→0，评分组隐藏后不留空组；显隐、顺序、主/次绑定变化立即反映，tooltip = 命令名 + 实际快捷键，显示的评分命令能辨别星数。
- 点击 EXIF 信息块整组打开工具窗口 EXIF 详情，无照片或无 EXIF 块时没有命中区域；无照片时评分组仍显示并降透明（约 0.1），点击不写回。

## TOOLBAR-02 分组几何 · 必须
- 外四周 `toolbar.padding`（10），组间距 `toolbar.group.spacing`（10）。
- EXIF 块 `toolbar.exif.block.width`（50）×`toolbar.exif.block.height`（40），每块主轴两端各 `toolbar.exif.inset`（4）、块间另隔 `toolbar.exif.spacing`（4）；评分按钮 `toolbar.rating.button.size`（30）、组两端 `toolbar.rating.group.inset`（8）；命令按钮 `toolbar.command.button.size`（40）、间隔 `toolbar.command.spacing`（8）。
- 方形点击区不因图标或文字拉宽，图标居中且视觉尺寸相近；字号 10 / 12 / 16 / 18（`toolbar.exif.label.font-size` 等）。四项 EXIF / 六命令参考长度：横排 244 / 196 / 280，竖排 204 / 196 / 280。
- 图标用平台原生符号集，同一命令在四端保持可识别含义。

## TOOLBAR-03 EXIF 摘要信息 · 必须
- 每块显示标签与强调值，两者必须可区分；值缺失显示「--」，不隐藏块、不缩成零宽。
- 值用共享转换器格式化（光圈、快门、ISO、焦距、拍摄时间、曝光补偿等），不各自另造格式。
- 完整值可查看：桌面 tooltip，触屏由工具窗口 EXIF 详情承担（TOOLS-02）；换图或 EXIF 异步到达只刷新值，不重建分组、不跳版。

## ANALYSIS-01 入口、编排与就绪状态 · 必须
- 入口：主图菜单「分析栏」勾选项与命令 `ToggleAnalysisView`（控制栏按钮按设置显隐），勾选态与可见性同源。
- 只在可见时工作：不可见时不读库、不解码、不推理，切图不隐式推理（SCOPE-01）；可见时主图升 Full。编排走共享 presenter，平台壳只做位图格式适配。
- 快路径（EXIF 已加载 + 缓存命中）同步换瓦片；慢路径异步读库，期间保留旧图或占位，不阻塞主图。
- 库与缓存都没有结果时诊断瓦片显示「未提取」；开启「即时计算 DINO/CV」后改「计算中…」，延迟 `motion.analysis.fallback.delay`（500）后、主图与缩略图通道空闲时现算，延迟内翻页即取消。
- 增强图就绪且开启即时计算时，直方图/细节跟随增强图、四张诊断瓦片对增强图重算；关闭增强或开关回落到只读库。批量提取写库后当前照片诊断瓦片自行出图（不需切图），清库后同样失效重算。

> 退役：原 ANL-01「原生路径不得运行旧壳 `AnalysisViewModel`」是旧实现约束，已并入本条「编排走共享 presenter」，不再单独设 ID。

## ANALYSIS-02 瓦片内容、圆角与比例 · 必须
- 内容不带自己的圆角：外框圆角 `analysis.tile.corner-radius`（6）单层裁切，不叠加内层圆角。
- 内容按照片原比例居中留边，不拉满方形；直方图瓦片保持 1:1；诊断位图长边 `analysis.diagnostic.long-edge`（512），直方图采样长边 `analysis.histogram.sample-long-edge`（1024）。
- 底色/描边/占位色用 `color.analysis.tile.background`、`color.analysis.tile.border`、`color.analysis.placeholder`，角标字号 `analysis.caption.font-size`（12）。

## ANALYSIS-03 等边长由布局系统给出 · 必须
- 全部瓦片等边长，边长在测量/排列阶段一次算出并落 frame，不得「读实际宽度再回写子项尺寸」。
- 首开、换向、窗口缩放、栏位显隐后仍等边长、上沿对齐；单张未就绪或失败不改变边长。

## ANALYSIS-04 主图绿框的显示条件 · 必须
- 绿框（`analysis.highlight.thickness` 3，`color.analysis.highlight`）只在指针悬停细节预览瓦片时显示，离开即消失。
- 换图、代理→Full、瓦片尺寸变化等重建裁剪图的行为不得自动点亮绿框。
- 触屏用点按「定格/解除」代替悬停：定格后离开不消失，再点或点主图空白解除。见 platforms.md（analysis-04@ios / @android）。

## ANALYSIS-05 瓦片顺序、几何、准星与细节预览 · 必须
- 顺序：对焦点（仅有 Sony 对焦数据时）/ 中心 / 直方图 / DINO PCA / Cosine x,y / 锐度 / 抖动拖影；无对焦数据时该瓦片不占位，其余顺序不变。
- 边长 = `analysis.tile.size`（派生：floor((可用主轴 − `analysis.panel.padding`(10)×2 − `analysis.tile.spacing`(8)×(n−1)) / n)，最小 1），交叉轴 = 边长 + 内边距×2；行布局在主图下方、列布局在右侧，从内边距 10 起排，零头留末端。
- 角标为左上药丸（`color.analysis.badge.background`，内边距 8/4，圆角 5）；准星白色 1 点、臂长 `analysis.crosshair.arm`（12）。
- 点击任一诊断瓦片落准星，并把该点（映射到 32×32 patch 网格）设为 cosine 参考点，cosine 瓦片重算并更新坐标标签，点同一格不重算；准星与参考点在同一分析栏内共享，点击不改变当前照片与缩放。
- 参考点初值为网格中心；细节预览（对焦点/中心）裁剪自当前展示图（增强图优先），双击定位主图到该裁剪中心并放大到物理 100%（IMAGE-02 同一视口语义）。

## SIM-01 面板语义、三态与双高亮 · 必须
- 由筛选条开关显隐并持久化；只在面板展开且文件栏可见时按锚点重算，收起取消在途计算，重新展开按当前图重算一次。
- 三态互斥：无列表且有未提取 →「尚未提取特征」+ 动作区；无列表且全部已入库 →「无相似照片」；有列表 → 卡片列表（有未提取时另带动作区）。
- 动作按钮「提取全部」/「补齐全部」随列表变化；提取中显示进度（总数未知为不定态），失败显示可读错误、不伪造完成；本期不可取消。
- 卡片 = 胶片栏卡片 + 第二行相似度百分比与柱条（`sim.score.lower-bound` 75% 起），按分数降序，最多 `SimilarityMaxResults` 项，阈值以下不出现。
- 点选卡片切主图但保留原锚点：面板卡片按主图身份高亮、胶片栏锚点卡片继续高亮（双高亮），不重排相似列表、不滚动胶片栏；卡片星级只改评分，不切主图。
- 阈值/最多数量变化后防抖重算（约 150ms），只改列表不改当前照片。

## SIM-02 面板几何与让位 · 必须
- 列布局扩宽文件栏、行布局从胶片栏右侧切出；最小 `sim.panel.min-width`（106）×`sim.panel.min-height`（154）。
- 列布局宽 `sim.panel.width`（110 = 卡片 96 + 内边距 8 + 4 + 描边 2）；行布局宽 = min(max(106, 卡片数×96 + 8 + 2), 可用宽度/2) + `sim.panel.margin`（4）；列表内边距 `sim.list.padding`（8），交叉轴 `sim.list.cross`（161）。
- 卡片几何与胶片栏一致，背景/描边/圆角按 token；收起后文件栏/主图几何逐项还原，不残留占位，开合不改变当前照片与列表位置。

## MENU-01 主图上下文菜单 · 必须
- 触发：桌面右键（主图与窗口空白处同一菜单）；触屏长按或辅助点按，与双击、捏合、平移同时可识别，只有长按才弹；弹出不改变当前照片。
- 顺序与分组：打开文件夹…（桌面另有「打开文件…」）｜胶片栏 / 分析栏 / 控制栏（勾选）｜增强预览（勾选）｜工具… / 设置…；分隔线按分组，不逐项加。
- 勾选态每次弹出读共享状态，菜单动作与按钮/快捷键走同一命令入口；延期或平台专属功能不生成菜单项。
- 触屏菜单锚在触点、照片不抬升不缩小；超出屏幕时夹取并可滚动，返回键/点外部先关菜单。

## MENU-02 卡片上下文菜单 · 必须
- 桌面用 tooltip 显示完整文件名与拍摄时间；触屏长按卡片弹菜单，标题 = 完整文件名 + 拍摄时间（`yyyy-MM-dd HH:mm:ss zzz`）。
- 内容只有评分 0–5，勾选当前星级；写回走共享评分路径，不改变当前主图，暂留语义由列表负责（FILM-06）；卡片星级按钮几何不因触屏放大，触控目标由菜单补足（可以）。

## INPUT-01 快捷键绑定与输入焦点 · 必须
- 高频命令都有可自定义的主/次绑定；各平台先把原生事件解包成共享手势，再查同一张命令表；持久化字段不改名、不新建第二张表。
- 输入控件获焦、快捷键录制、设置/工具/文档选择器等模态展示期间，不派发照片快捷键（数字、方向键、空格都不落到照片）。
- 未映射或本平台不可达的命令不消费事件，保留系统行为；苹果修饰键映射按设置生效，Windows/Android 按各自修饰键习惯解码，手势名共用。

## INPUT-02 指针与触控手势映射 · 必须
- 双击主图 = 适应⇄100%（IMAGE-02），落在顶部拖动区的双击归窗口动作（SHELL-02）；放大态拖动 = 平移，捏合 = 连续缩放且锚点在手指，双指起手不翻页。
- 适应态单指横向轻扫 = 上一张/下一张：水平位移超过 `image.swipe.threshold`（24）且明显大于纵向，走共享 Previous/Next 并显式定位，端点不环绕；放大态横滑仍是平移。
- 触控板连续滚动 = 主图平移并保留惯性；离散鼠标滚轮 = 用户鼠标绑定命令（默认上下轮翻页），不驱动平移；横向胶片栏上的纵向滚轮滚动列表（FILM-04）。

## INPUT-03 按键重复、中断与前后台 · 应当
- 按住键重复：桌面用系统节奏，无公开重复接口的平台用固定节奏（350ms 延迟 / 60ms 间隔），每次走同一命令。
- 新动作打断进行中的定位/缩放动画与排队请求，最后一次生效、不回跳；窗口失焦、切后台、弹模态或菜单时释放按住状态并停止重复，恢复后不补发。
- 长按与拖动/捏合互斥：判定为拖动后不再弹菜单。

## OPEN-01 打开文件/文件夹 · 必须
- 桌面提供打开文件与打开文件夹两个入口（文件菜单、空首屏、控制栏「打开」命令）；触屏用系统选择器，只提供「打开文件夹」。
- 打开文件夹先只显示目标图（调用方指定时），再枚举补齐列表，列表立即可交互、可滚动，不等全部 EXIF 与缩略图。
- 未指定目标时当前照片 = 筛选结果首项（同名合并取代表文件），不是枚举顺序首项；筛选为空时取枚举首项。
- 取消选择、权限拒绝或打开失败不改变当前状态，失败必须留痕（日志或提示），不静默；打开完成后触发一次显式定位，调用方声明不定位除外（FILM-01）。
- 目标已在当前列表时直接切换，保留列表、筛选、排序与滚动位置；再次打开同一文件夹不重建列表；目标被同名合并隐藏时映射到代表文件。

## OPEN-02 外部打开与拖入 · 必须
- 系统「打开方式」、文件管理器/Dock 拖入、命令行参数、Android VIEW/SEND、iOS 文件 App 拖入，统一进入外部打开服务；UI 未就绪时排队，就绪后执行。
- 单文件先尝试进入父文件夹；父目录不可访问时回退单图模式（列表只有该图、文件夹名 = 文件名），至少让用户看到该图。
- 多文件取第一个可识别图片为当前照片，同文件夹的其余文件由文件夹枚举进入列表，不另拼列表。
- 拖入接受文件与文件夹，走同一路径与同一目标选择规则，拖入过程不改变主图状态；外部打开默认定位到目标。

## STATE-01 加载提示与延迟 · 必须
- 无照片：主图区居中显示短标题（桌面「点击打开文件 或 拖拽图片到此处」，触屏「点击打开文件夹」）与可选副提示；标题 `image.hint.title.font-size`（16）、副文 `image.hint.detail.font-size`（11）、最大宽 `image.hint.max-width`（500）、间距 `image.hint.detail.gap`（28），提示层不挡空态点击与拖入。
- 有照片但展示图未就绪：立即清旧图，加载提示延迟出现、图一到即撤下，避免快速翻页闪烁（延迟记作 `status.loading.delay`，当前实现无延迟）。
- 代理→Full、增强计算等后台工作不用阻塞式加载；缩略图、EXIF、缓存状态异步补齐，不阻塞列表与主图。

## STATE-02 空、失败与不可解码 · 必须
- 解码失败：主图显示标题与详情（文件名或解码器原因），不显示伪造或残留图像；该卡片仍可选中、可评分。
- 空筛选结果：胶片栏给简短空状态（「无匹配照片」），筛选控件与条件保留、不自动放宽；主图保持原照片，没有原照片时给空提示。
- 空文件夹显示文件夹名与空列表；无 EXIF/无评分显示「--」占位，不隐藏控件、不弹错误；错误不升级为模态，模态只用于二次确认。

## STATE-03 操作结果提示条 · 必须
- 操作结果（评分写回失败等）用主图区底部提示条：单行或自动换行，最大宽 `status.toast.max-width`（500），距底 `status.toast.bottom-margin`（24），字号 `status.toast.font-size`（12），内边距 12/6，圆角 6。
- `motion.status.toast.duration`（4000）后自动消失，新提示替换旧提示并重置计时，不抢焦点、不阻断手势。
- 失败不显示虚假成功：星级保持原值（FILM-06），文案含操作对象与原因要点。平台差异见 platforms.md（state-03@mac / @ios）。

## STATE-04 模型、推理与数据库不可用 · 应当
- DINO 模型缺失或推理失败：不做隐式计算、不弹全局错误；相似聚类在面板内显示可读失败文案，DINO 诊断页显示状态文本与空瓦片。
- 清库需二次确认，执行后徽标、分析栏、相似面板立即失效并在下次可见时重算；存储/权限/写回错误走同一提示路径（STATE-03），可继续的浏览与评分不被阻断。
- 单张失败不阻断整批：批量提取跳过失败组继续，结束时报告失败。

## SETTINGS-01 控制列表行结构 · 必须
- 每行 = 显隐勾选 + 名称 + 主快捷键 + 次快捷键 + 行尾拖拽把手，四者同一行；无老式表头、无内嵌嵌套滚动，整表作为一张卡片平铺。
- 拖拽排序整行可拖、行高一致，拖后立即回写顺序；没有常驻把手元素的平台整行拖、行尾把手只作视觉锚点。
- 勾选、重排、重绑后控制栏按钮与 tooltip 立即刷新，不需重开窗口。

## SETTINGS-02 分类、项目与工作副本 · 必须

| 分类 | 项目 |
|---|---|
| 文件 | 支持格式启用与顺序、同名合并、缓存数量/内存上限、预载数量与延时、解码线程数 |
| 预览 | 缩放指示器开关、缩放预设增删改与排序 |
| 控制 | 布局模式、控制功能显隐/顺序/主次绑定、苹果键盘映射（Apple 平台） |
| EXIF | EXIF 项显隐/顺序、显示评分、安全写回 |
| AI | 相似阈值（75–95%）、最多数量（1–32）、即时计算 DINO/CV、清除特征数据库 |

- 工作副本：打开时快照，编辑期只改副本、不写盘、不改主屏；关闭窗口一次校验并应用，无「保存」按钮，重复关闭只回写一次。
- 不改 JSON 字段名、默认值与共享语义；清库等即时命令独立执行，不进工作副本；数值控件在回车/失焦后校验，不按每次按键重载；关闭回写后布局、栏位、控制栏、快捷键、EXIF/评分、格式筛选立即在主屏生效。

## SETTINGS-03 设置视觉为平台原生 · 应当
- macOS 的系统设置样式（侧栏 + 分组表单 + 前进/后退）只是该平台的视觉约束，不是共同规则；iOS/Android/Windows 各按自身原生规范（半屏 sheet / Material 3 / Win11 设置页）。
- 视觉可以原生，分类、项目、行为与持久化必须一致（SETTINGS-02）。

## SETTINGS-04 快捷键录制与冲突 · 必须
- 录制态显示「按下按键…」；Esc 取消、Delete/Backspace 清空、修饰键单独按不结束录制。
- 录制期间吞掉滚轮、中键、空格与方向键，避免页面滚动、焦点移动与误触主屏命令；主屏快捷键不派发（INPUT-01）。
- 冲突行以警告色标出但不清空绑定，结束录制后重算全部冲突；录制完成只刷新该行，不重建整页。

## TOOLS-01 入口与窗口结构 · 必须
- 入口两处且同一命令：主图菜单「工具…」与控制栏 EXIF 信息块点击。
- 桌面为独立工具窗口（单例，已打开则前置，主窗口关闭一并释放）；触屏为 sheet/半屏浮层，列表首页 → 子页可返回。
- 工具列表只有 EXIF 详情与 DINO 诊断；照片数据统计只在具备该能力的平台出现（TOOLS-03）；打开期间切图只更新内容，尽量保留子页与滚动位置。

## TOOLS-02 EXIF 详情 · 必须
- 7 列：Tag ID `exiftable.id.width`（60）+ 名称/中文名/值按 `exiftable.column.ratio`（2:2:3）+ 三条 `exiftable.divider.thickness`（1）分隔线；单元格内边距 10/8。
- 值列最多 `exiftable.value.max-lines`（3）行，超出尾部截断，不因长值改变列宽或行高。
- 同一张照片的伴侣格式可切换（RAW 优先并默认选中，无 RAW 取第一项），切换只换数据、不替换页面、不重置滚动。
- 无 EXIF 的照片不进入 EXIF 详情，不显示空白表格；按分组呈现（相机、曝光、镜头、图像等），分组标题与行同宽。

## TOOLS-03 DINO 诊断与照片数据统计 · 应当
- DINO 诊断 5 张瓦片固定顺序：原图缩略图 / PCA-RGB / Cosine / 锐度 / 抖动拖影，按 3+2 同宽排布、两排上沿齐平、第六格留空，下接全宽刚体拟合文本。
- 点击瓦片落准星并以该点为 cosine 参考（32×32），与分析栏同语义；数据与推理全部来自共享 presenter，工具壳不自建缓存或推理；模型缺失或未提取时显示状态文本与空瓦片。
- 照片数据统计（可以，平台专属）：多文件夹 + 通配符 + 递归扫描 + CSV 导出；导出中可取消，状态文本显示进行中/完成/失败；无此能力的平台不建入口。

## SCOPE-01 隐式计算边界 · 必须
- DINO/CV 推理与特征提取只在对应面板可见或用户显式请求（提取全部/补齐全部、工具页诊断）时进行，切图不隐式推理。
- 相似聚类只在面板展开且文件栏可见时计算，收起取消在途任务；分析栏只在可见时读库/解码；抖动徽标只读库，不把未知当正常。
- 分析诊断的即时计算受设置开关控制（默认关）：关闭时只读库并显示「未提取」，不做未提取回退；清库、重算、增强等重操作只在显式命令下发生，不做后台预热。

## SCOPE-02 功能边界与入口可见性 · 必须
- 延期功能保留配置与已入库数据，原生壳不显示不可用入口——菜单项与按钮都不出现，不做禁用占位；功能落地后按同一 ID 恢复入口。
- 平台专属功能（照片数据统计）只在具备该能力的平台建立入口，其他平台不显示、不用禁用项占位。
- 功能不可用不静默降级、不改变共享语义，必须给出可读状态（STATE-04）或直接不提供入口；跨端差异先登记 `ID@平台`，不在实现里悄悄偏离。
