# L0 产品原则

PhotoViewer 是摄影师拍摄后快速选片的工具：随时随地打开一批照片，快速浏览、对比、标星，把结果写回原文件。下列原则约束所有 L1–L4 决策；原则之间冲突时按序号靠前者优先。

| ID | 原则 | 含义与推论 |
|---|---|---|
| PRIN-01 | 画质与色彩不打折 | 100% 放大必须是全分辨率源像素（1 源像素对 1 屏幕物理像素）；不接受肉眼可见的降分辨率；色彩按源色彩空间正确管理。性能优化只能在不违反本条的前提下进行 |
| PRIN-02 | 选片进度不丢失 | 评分不切图；当前照片因改星落出筛选时暂留；写回失败必须可见、不显示虚假成功；排序、筛选、刷新不抢走用户的列表位置 |
| PRIN-03 | 照片优先占据空间 | 主图占最大区域；其余区域只放精简信息与高频操作；隐藏的栏位把空间全部还给主图；业务上的方形元素不因控件原生化而变形 |
| PRIN-04 | 操作即时响应 | 切图立即显示（先代理后全分辨率），不等动画、不等后台任务；列表滚动不等解码；动画随时可被用户打断 |
| PRIN-05 | 键盘优先，各输入方式均可达 | 所有高频命令都有可自定义的主/次快捷键；触屏、触控板、鼠标各有等价入口；输入或录制控件获焦时不误触照片快捷键 |
| PRIN-06 | 同一照片的多格式是同一身份 | RAW + JPG/HEIF 同名文件合并为一张卡片，评分同步写入；EXIF 与详情可在格式间切换 |
| PRIN-07 | 不做用户没要求的计算 | AI 推理、特征提取只在对应面板可见或用户显式请求时进行；切图不隐式推理 |
| PRIN-08 | 业务布局一致，通用控件原生 | 主窗口分区、几何、动效、语义色与主屏图标在四端一致；下拉、菜单、tooltip、滚动条、设置与工具窗口采用平台原生控件与规范，无原生控件时按旧壳自绘外观 |
| PRIN-09 | 尊重系统环境 | 遵循系统减少动态效果、安全区、显示缩放与色域；观片环境固定深色 |
