# 工具窗口（TOOLS）

**意图**：在选片流程旁开一扇只读的“取证窗”——完整元数据、诊断瓦片与数据统计放在独立窗口或浮层里细看，看的时候不打断选片、不改照片，也不因为“在看”而额外推理。

数值令牌：`exiftable.*`、`analysis.tile.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#tools)，验收状态见 [status.md](../status.md#tools)。

## TOOLS-01 入口、单例与只读边界 · 必须

- 入口只有两处：主图上下文菜单「工具…」（桌面右键 / 触屏长按；macOS 按系统惯例显示为「工具」）与控制栏 EXIF 信息块（整组可点，不要求点中某一块）。
- 控制栏入口随 EXIF 分组存在：设置里隐藏全部 EXIF 项后该入口自然消失、空间还给主图；菜单入口保留。无当前照片时仍可打开工具窗口，内容进入空状态，EXIF 详情不可用。
- 同一前端只有一个工具窗口/浮层：重复请求只前置已存在的实例，不创建第二个；已打开时只前置，不替用户切换正在看的工具页。
- 桌面为独立非模态窗口，打开后主窗口仍可切图、评分、筛选；移动端为覆盖式浮层（sheet），覆盖期间主窗口不接收输入。
- 当前照片变化时工具内容跟随刷新（TOOLS-04、TOOLS-06），但不回首页、不重置滚动位置、不抢焦点。
- 关闭工具窗口不改变当前照片、评分、筛选与设置；桌面主窗口关闭时一并关闭工具窗口。
- 工具窗口获焦期间照片快捷键不派发，在工具页里按方向键或数字键不得翻图、改星（见 [input](input.md)）。
- 工具页只读：不提供改星级、改 EXIF、改筛选的入口；所有写回只在主窗口与胶片栏发生。
- 工具窗口固定深色外观（PRIN-09），标题「工具」；窗口位置与当前工具页不持久化。

## TOOLS-02 工具外壳、落点与空状态 · 应当

| 外壳 | 端 | 结构 |
|---|---|---|
| 列表 + 子页 | macOS / iPadOS / Android | 首页等宽纵向列出可用工具；进入子页后显示返回（Android 返回键先回首页、再关闭浮层） |
| 常驻分类 | Windows | 分类常驻侧栏，没有首页：EXIF 详情、DINO 诊断、照片数据统计各自直接是页 |

- 工具顺序：EXIF 详情、DINO 诊断、照片数据统计（TOOLS-07）。
- 平台专属工具不建入口、不占位：非 Windows 不显示「照片数据统计」，不是置灰项（SCOPE-01）。
- 从主窗口入口打开时回到首页；Windows 的默认分类是 EXIF 详情，无可用 EXIF 时落到照片数据统计。窗口已开着时只前置并保留当前页。
- 返回首页不销毁子页已加载的数据，再次进入先显示已有内容，不重走推理（见 TOOLS-06）。
- 无障碍：入口、分类与返回使用标准控件语义，读屏可读出当前页与可用性；瓦片说明文字同时作为“点击落参考点”操作的无障碍标签。

| 状态 | 呈现 |
|---|---|
| 无当前照片 | 工具首页可打开；EXIF 详情禁用；DINO 诊断可进入，状态「未加载」 |
| 照片无 EXIF | EXIF 详情禁用；已在该页时回到首页，不显示空白表格 |
| 子页加载中 | 页面保留，显示加载状态，不退回首页 |

## TOOLS-03 EXIF 详情：表格与文本 · 必须

- 头部：不含扩展名的文件名居中；多格式时紧随其后是格式选择器（TOOLS-04），单格式只显示扩展名标签，不做可点控件。
- 按元数据分组：组标题 + 圆角卡片，卡片内一行一条标签，行间与卡片边缘用 `exiftable.divider.thickness`（1）分隔线；组与组之间留白。分组顺序沿用解析来源的顺序，同一照片每次打开一致。
- 行固定 7 列：Tag ID（`exiftable.id.width`（60））、名称、中文名、值，加三条 `exiftable.divider.thickness`（1）分隔线；三个文本列按 `exiftable.column.ratio`（2:2:3）分配，单元格内边距 `exiftable.cell.paddingX`（10）/ `exiftable.cell.paddingY`（8）。
- 值列最多 `exiftable.value.maxLines`（3）行，超出尾部截断（不裁掉开头）；行高取三列换行后的最大高度再加内边距。
- 横向不滚动；窗口变窄时文本列收窄、换行增多，ID 列宽不变。Tag ID 用等宽字体。
- 文本可选中复制（触屏长按选择），便于把机型、序列号、拍摄参数粘到别处。
- 加载中显示「加载中…」；读取失败或格式无数据时显示空表与失败状态，不得显示上一张照片或上一格式的残留内容，也不伪造数值。
- 平台差异见 platforms.md（TOOLS-03@android）：手机宽度用 4 个内容列承载同一比例，不铺 7 列网格。

## TOOLS-04 EXIF 详情：同一照片的格式切换 · 必须

- 格式集合 = 当前显示文件 + 同名伴侣文件（RAW、JPG、HEIF 属同一照片身份，PRIN-06）；标签取扩展名大写；RAW 固定排第一，其余按扩展名字母序。默认选中 RAW，没有 RAW 时选第一个。
- 只有一个格式时不出现选择器，也不制造“可切换”的假象。
- 切换格式只换元数据来源：不切当前照片、不改评分与筛选、不移动胶片栏、不改变主图显示；EXIF 是文件的只读副本。
- 伴侣格式的 EXIF 按需加载：切换后先显示加载状态，完成再填入；已加载的格式留在内存，切回即时显示。同一时刻只有最新一次加载结果生效，迟到的旧结果丢弃。
- 切换照片时保留当前格式标签（新照片有该格式），否则回退到 RAW 优先的默认；内容整体换新，滚动位置不重置。

## TOOLS-05 DINO 诊断：瓦片与准星 · 必须

- 五张瓦片固定顺序：原图缩略图、PCA-RGB、Cosine、锐度、抖动拖影。每张带说明文字，Cosine 的说明含当前参考点坐标（x, y，网格 0–31）。
- 瓦片为方形，内容按照片原比例居中留边、不拉伸；网格位图最近邻放大（不插值）；圆角与描边只由外框产生（`analysis.tile.cornerRadius`（6）、`analysis.tile.border.width`（1）），内容不再叠第二层圆角。
- 抖动拖影瓦片以压暗原图为底，叠加 32×32 矢量线，颜色取与抖动判定同一配色函数（见 [analysis](analysis.md)）。
- 点击任意瓦片：在该归一化位置落准星，并把该点作为 cosine 参考 patch 重算 Cosine 瓦片；准星在五张瓦片上同时显示（`analysis.crosshair.arm`（12））。
- 点击瓦片之间的空白或页面背景清除准星；切换照片后准星清空、参考点回到网格中心。
- 五张瓦片等宽，两行三列排布，瓦片间距 `analysis.tile.spacing`（8），两排上沿齐平，说明文字长短只影响本瓦片底边；刚体拟合文本单独成块，不挤进瓦片格（平台差异见 platforms.md，TOOLS-05@win）。
- 刚体拟合文本固定字段：样本格数与占比、Σw、|T|（px 与占对角线百分比）、|ω|、残差、R_global 与 R_local p10、判定标签；判定与缩略图“抖”徽标同源。

## TOOLS-06 DINO 诊断：计算时机、状态与中断 · 必须

- 只在 DINO 诊断页可见时工作：进入页面为当前照片启动一次；页面可见期间切图取消在途任务，只保留最后一次请求的结果；离开页面或关闭窗口即取消，不在后台续算（PRIN-07、SCOPE-01）。
- 先读库：patch token 与 CV 网格命中即跳过推理与 CV 计算，缺失再现算。诊断页不回写数据库、不写文件、不改评分与筛选。
- 状态：无照片「未加载」；计算中「计算中…」+ 文件名；解码失败「无法解码图片」；其他失败显示「失败：原因」。失败时清空瓦片与文本，不把上一张的结果挂在新文件名下。
- 缺数据的瓦片显示「未提取」占位，不用空白或零值冒充。
- 计算在后台完成，UI 线程只贴图；计算期间页面仍可滚动、可返回，返回后到达的结果作废。
- 同一工具窗口生命周期内复用同一诊断编排与页面对象，重新进入页面不重建控件；重算只由照片变化或上次失败触发。

## TOOLS-07 照片数据统计 · 可以

平台专属功能：仅 Windows 提供，其他平台不建入口（SCOPE-01），本条的规则只约束该平台。

- 文件夹列表：通过系统文件夹选择器添加（可多选），同一路径不重复添加（不区分大小写）；选中项可移除。通配符一行文本，默认 `*.HIF,*.JPG`，逗号或分号分隔，留空时按 `*.*`；扫描递归覆盖所有选中文件夹并去重文件。
- 导出 CSV：由系统保存对话框选目标，列固定为「文件名,等效焦距(mm),星级」，UTF-8 带 BOM；单文件读取失败时该行字段留空或 0，不中断整批。
- 导出只读：不修改照片、XMP、评分或数据库。
- 进度与状态：扫描中、处理中 n / 总数、完成条数、未找到匹配文件、已取消、导出失败；无文件夹或正在导出时导出按钮不可用，运行中可取消。
- 文件与保存选择器挂在工具窗口自身的宿主上，对话框不得落到主窗口或窗口背后。
