# 设置窗口（SETTINGS）

**意图**：在一个按平台原生规范组织的窗口里集中编辑影响主窗口的全部选项；编辑只动工作副本、不打扰当前选片，关闭即一次提交并立即生效，设置文档是唯一的持久化契约。

数值令牌：本模块没有设计令牌；设置项的取值范围与默认值属于设置模型，见 `SettingsModel` 与 `PhotoViewer/ViewModels/Settings/*`。提示与动效取 `status.*`、`motion.*`。平台实现与差异见 [platforms.md](../platforms.md#settings)，验收状态见 [status.md](../status.md#settings)。

## SETTINGS-01 控制列表行结构 · 必须

控制栏功能表的每一行包含：显隐勾选、命令名、行尾排序把手；主/次绑定与冲突控件按 INPUT-13 的外设条件显示。没有表头、没有内嵌滚动，整表作为一张卡片平铺在页面滚动里。

| 元素 | 规则 |
|---|---|
| 勾选 | 只决定该命令是否出现在控制栏；不解除快捷键、菜单与触屏手势（TOOLBAR-01） |
| 命令名 | 单行，超长截断；触摸平台可用副标题或详情承载完整名 |
| 主 / 次绑定 | 显示时给出当前手势文本，点击进入录制（SETTINGS-11）；未绑定显示"未设置"，不显示空白 |
| 顺序 | 行序即控制栏命令顺序（TOOLBAR-01），不是字母序 |
| 把手 | 排序入口的视觉锚点；拖动载体见 SETTINGS-15 |
| 冲突 | 主/次绑定冲突在对应绑定上标记（SETTINGS-11），不隐藏命令行 |

平台实现：桌面端始终显示完整主/次绑定、录制、清空与冲突。触控优先设备连接硬件键盘、鼠标或触控板任一即完整显示，不因只连接某一种而裁减另一类绑定；仅直接触控时隐藏绑定文本、录制、清空与冲突等全部键鼠相关控件，但保留名称、勾选、顺序与已持久化绑定配置，不把隐藏当成清空。

## SETTINGS-02 分类、分组与工作副本 · 必须

- 五个分类、顺序固定：文件 / 预览 / 控制 / EXIF / AI。不得按平台增删分类；分类内项目可平台化（SETTINGS-08、SETTINGS-10）。
- 分组集合固定，不得缺组：文件＝同名合并 / 支持的文件格式 / 缓存与预加载；预览＝缩放指示器 / 缩放比例预设；控制＝布局模式 / 控制栏功能（+ 仅 Apple 的键盘映射）；EXIF＝EXIF 显示 / 评分与写回；AI＝相似聚类 / 分析诊断 / 特征数据库（末组为开发者入口，可用平台见 SETTINGS-10）。组内排列顺序可按平台表单惯例。
- 控件按平台原生选型（开关、步进器、拉条、数值框、预设行、可排序表），但语义与取值范围四端一致（SETTINGS-06–10）。
- 分类导航形态属平台视觉（SETTINGS-03）；分类、分组、项目与文案语义不因导航形态变化。
- 编辑只写工作副本；关闭时一次性回写源设置并落盘。没有"保存/取消"按钮，关闭即应用（SETTINGS-04）。
- 不改设置文档的字段名、默认值语义与命令表；不得为某平台另立一份设置模型或第二张命令表。

## SETTINGS-03 平台外观 · 可以

本条是 macOS 专属视觉，不是四端共同规则：macOS 26 系统设置样式（`NavigationSplitView` 系统侧栏、彩色圆角图标底板、工具栏前进/后退与分页标题、`Form(.grouped)` 分组表单），不要求其他平台照搬。iOS/iPadOS 用半屏 sheet，Windows 用 Win11 设置结构（Mica + `TitleBar` + `NavigationView` + `SettingsCard`），Android 用 Material 3 底部浮层；设置窗口不必复刻主窗口的隐藏标题栏。设置页四端固定深色、不随系统亮/暗切换（iOS 对设置展示控制器设 `OverrideUserInterfaceStyle = Dark`），本条其余外观仍为“可以”。控件与材质细节见 platforms.md（`SETTINGS-03@mac|win|ios|android`）。

## SETTINGS-04 入口、形态与关闭 · 必须

- 入口：主图上下文菜单末项「设置…」；所有平台都必须有这一入口，不得只在控制栏或快捷键里提供。桌面端另可提供应用菜单/系统快捷键（macOS `⌘,`）。
- 单例：已打开时再次调用只前置/激活，不新建第二份工作副本、不丢失未提交编辑。
- 桌面端为独立窗口，不阻塞主窗口浏览；移动端为半屏 sheet，展示期间主屏快捷键与照片手势不派发（INPUT-01）。
- 打开与关闭设置不改变当前照片、筛选条件、排序与胶片栏位置（PRIN-02）；设置窗口不写照片文件。
- 关闭路径统一提交：关闭按钮、系统下拉、返回键、宿主退出；主窗口关闭时先关设置窗口，保证回写。
- 关闭后再次打开显示已提交的最新值；提交后不要求重启应用，也不重载当前文件夹。

## SETTINGS-05 编辑隔离与生效时机 · 必须

- 编辑期不改运行时：缓存上限、解码并发、键盘映射、布局、控制栏、筛选都不随编辑即时变化；工作副本不产生磁盘写入。
- 关闭提交后立即在主屏生效，无需重启：布局模式、控制栏显隐与顺序、快捷键绑定、EXIF 显示项、星级显隐与写回策略、文件格式与同名合并、相似聚类参数、缩放预设与指示器。
- 提交是幂等的：重复关闭只回写一次；主窗口还活着时按提交重建，不丢失当前选择与列表位置。
- 即时命令不属于工作副本：清空特征数据库在确认后立即执行（SETTINGS-10），不等待关闭，也不能靠关闭撤销。
- 持久化失败不得清空或破坏既有设置文档；下次打开沿用上次成功保存的值，界面不宣称未发生的成功。

## SETTINGS-06 文件页 · 必须

| 项目 | 控件语义 | 范围 / 默认 |
|---|---|---|
| 同名文件视为同一张图片 | 开关，带一行说明 | 默认开；关闭即拆散合并身份 |
| 支持的文件格式 | 可勾选可排序表（SETTINGS-15） | 见下表 |
| 原生解码线程 | 步进器 | 1–设备上限 |
| 软件解码线程 | 步进器 | 1–设备上限 |
| 缓存内存上限 | 拉条 + 数值 | 512–32768 MB（`SettingsViewModel.BitmapCache`） |
| 缓存数量上限 | 拉条/数值 | 1–400 张（`SettingsViewModel.BitmapCache`） |
| 上一张 / 下一张 / 列表滚动预载 | 步进器 | 0–缓存数量 ÷ 3，即 0–33.3333%（`SettingsViewModel.BitmapCache`）；默认值按缓存张数换算，30 张及以上为 10 / 5 / 5，更少时按同比例收敛且不超过该上限 |
| 滚动预载延时 | 拉条 | 100–5000 ms（`SettingsViewModel.BitmapCache`） |

| 格式 | 扩展名 | 默认 |
|---|---|---|
| JPG | .jpg .jpeg | 开 |
| HEIF | .heif .heic .avif .hif | 开 |
| PNG | .png | 开 |
| WebP | .webp | 开 |
| RAW | .cr2 .cr3 .nef .arw .dng .raf .orf .rw2 .srw | 开 |
| TIFF | .tiff .tif | 关 |
| BMP | .bmp | 关 |
| GIF | .gif | 关 |

- 默认格式顺序为 JPG → HEIF → PNG → TIFF → WebP → RAW → BMP → GIF。顺序决定同名文件合并时的代表格式：越靠前越优先成为代表，其余进入隐藏列表但保留各自星级（PRIN-06）。
- 关闭某格式后，该扩展名不参与扫描、筛选与同名合并；允许全部关闭，列表显示空状态，不自动替用户勾选。
- 格式勾选/顺序或同名开关提交后立即重算列表，但不抢当前照片身份与列表位置（FILM-01）；当前照片仍存在时保持主图不变。
- 实际缓存容量取「用户缓存上限」与「按运行时实测内存预算推导的上限」中的较小者；由系统实测预算自动管理缓存的平台不显示「缓存内存上限 / 缓存数量上限」两项（SETTINGS-06@ios / @android），模型字段保留不改。
- 预算提示两行：第一行为设备能力（CPU 核数 / 内存上限，内存上限取运行时实测预算）；第二行按实际缓存容量换算可缓存的照片张数（按当前屏幕的代理尺寸、2400 万像素照片估算），并与"前后预载数 + 当前 + 对比"所需张数比较：够用为正常级，不够但不少于 3 张为警告级，少于 3 张为错误级。缓存内存超设备上限为错误级、超过上限 51% 为警告级（只在显示缓存上限的平台判定）。级别与文本同时表达，不只靠颜色。
- 收到系统内存告警时，在提示行追加一次快照（缓存大小、项数、时间），不修改用户设置。

## SETTINGS-07 预览页 · 必须

- 缩放指示器开关（默认开）：只控制放大态导航图是否显示（IMAGE 导航图），不影响缩放、平移与快捷键；关闭后再次打开设置仍显示原值。
- 缩放比例预设：默认列表 12.5 / 25 / 33.333 / 50 / 75 / 100 / 200 / 400（%，`SettingsViewModel.ImagePreview`）；`+` 新增一项默认 100%，`−` 删除当前项；列表按数值升序，重复值允许存在、不去重。
- 每项只有一个数值输入框：右侧固定 `%`，数字在输入框内居中，不拆成多段输入，也不使用步进器。输入框与 `%` 作为一组在整行宽度内水平居中，行尾删除按钮不挤偏这个中心。
- `−` 删除当前项、`+` 新增一项 100%，都不是把当前值加减 100。两者是行尾同一列的无边框圆形图标（删除红、新增绿，取平台系统色），`+` 独占列表末行；图标保持平台正常尺寸与点击区。
- 预设是放大/缩小命令的挡位表：按当前倍率找下一挡/上一挡并缩放到该挡，首尾之外不动作（不环绕、不夹到任意倍率）。
- 校验与提交：Enter/Done、点击空白处或输入框失焦、切换分类、关闭设置都先校验并写入工作副本；输入必须 > 0 且 ≤ 1600%（四端同一上限），非法输入不写入，给一次可见提示并恢复原值；显示最多 3 位小数（33.333%）。
- 提交只更新当前项与列表顺序：不吞掉同一次操作中的其他点击，不销毁仍在编辑的控件、不夺走焦点、不重新弹出软键盘。仍在编辑时焦点对应同一逻辑项；用户主动结束编辑或移焦后不得抢回焦点。落盘只在关闭设置时按 SETTINGS-05 一次完成。
- 删到只剩一项时删除无效（入口禁用），不允许进入空表；旧文档中的空表仍补回默认列表：预设缩放命令不能变成死键，也不得隐式跳到任意倍率。
- 重排后把同一逻辑项落回列表，不丢焦、不回滚其他行。

## SETTINGS-08 控制页 · 必须

- 布局模式三选一：上下（行布局）/ 左右（列布局）/ 自动（默认），显示当前项的说明；提交后按 SHELL-01 重排，当前照片与列表位置不变。不得只给移动端两档。
- 控制栏功能使用 SETTINGS-01 的行；勾选与顺序直接决定控制栏按钮，隐藏命令只从控制栏消失，快捷键、菜单与触屏手势仍可用。
- 平台不具备的能力（如移动端清库入口）按 SCOPE-01：保留配置与绑定，不显示入口；能力可用后同一份配置直接生效，不要求用户重新设置。
- Apple 键盘映射（`使用苹果键盘` + Command / Option / Control 三项映射）只在 Apple 平台显示，且与快捷键控件使用同一外设可见条件（INPUT-13：连接硬件键盘、鼠标或触控板任一即显示）；其他平台保留字段但不展示、不生效。映射改变后主窗口按键解释立即按新映射。
- 设置页不提供栏位显隐开关；胶片栏/分析栏/控制栏显隐属于主窗口视图状态（SHELL-01），不得复制进设置页。

## SETTINGS-09 EXIF 页 · 必须

- EXIF 显示表 11 个字段：光圈 / 快门 / ISO / 等效焦距 / 实际焦距 / 相机型号 / 镜头型号 / 拍摄时间 / 曝光补偿 / 白平衡 / 闪光灯。默认只开前四项。
- 勾选＝出现在控制栏 EXIF 分组，顺序＝显示顺序（TOOLBAR-01）；全部关闭时控制栏不留空分组，也不伪造占位。
- 表格行只显示字段名与勾选；不得在行内编辑 EXIF 值（值编辑不是设置）。
- 显示星级评分（默认开）：关闭后控制栏评分组与胶片栏卡片星级同时隐藏；评分快捷键仍可改星，不丢评分能力（PRIN-02）。
- 安全修改文件星级（默认开）：写回前校验文件字节变化，命中变化则放弃写入并给出失败提示，星级保持原值，不显示虚假成功（STATE）。
- EXIF 详情工具窗口的 7 列展示是另一功能（TOOLS-01），不由此页的显示项控制。

## SETTINGS-10 AI 页 · 必须

- 相似度阈值：默认 0.85，范围 0.75–0.95（`SettingsModel`、`SettingsViewModel.AI`）；决定相似面板显示门槛（SIM-01），以百分比呈现。
- 最多数量：默认 8，范围 1–32（`SettingsModel`、`SettingsViewModel.AI`）；滑条按指数分布使 1/2/4/8/16/32 附近分辨率更高，数值框/步进器按整数直接取值。
- 即时计算 DINO/CV（默认关）：开启后分析栏对库内未提取照片现算，关闭后回到"未提取"占位（ANALYSIS）。它不能绕开 SCOPE-01：切图仍不隐式推理，面板不可见时不计算。
- 清空特征数据库为开发者入口：一次系统确认即执行，不得使用对用户不可见的 arm 态；没有系统确认控件的壳才保留可见的二次确认（3000 ms 内再次点击，`SettingsViewModel.AI`）。执行期间按钮禁用，状态按"清除中… / 已清除 / 失败:…"显示，不显示虚假成功。执行后照片库特征表与进程内缓存失效，不重启应用；相似面板下次展开重新统计未提取数。
- 阈值与数量变更在相似面板可见时按新参数重算；面板收起时不做计算，也不后台补算。
- 清库入口的可用平台见 platforms.md（`SETTINGS-10@ios`、`SETTINGS-10@android`），移动端长期不提供。

## SETTINGS-11 快捷键录制与冲突 · 必须

- 有键盘/鼠标/触控板外设时，点击主/次绑定按钮进入录制态，按钮显示"按下按键…"；同一时间只有一行在录制，切换到其他分类或关闭窗口即退出录制且不写入。
- 捕获键盘与鼠标手势（滚轮、中键、侧键）。录制态吞掉滚轮、中键、方向键与 Space，不滚动页面、不移焦点、不触发主屏命令。
- `Esc` 取消并保留原绑定；`Delete`/`Backspace` 清空为"未设置"；允许保存未设置项。
- 冲突不阻止保存：任两条目的主/次绑定相同即同时标记双方（键盘/鼠标同类比较；平台键位等价由输入映射定义），冲突只是警示，派发按命令表顺序取第一条匹配。
- 录制与冲突检测都作用于工作副本，关闭后随提交生效；冲突行在重新打开设置后仍可见（直到用户改绑）。
- 手势文本遵循平台修饰键命名（Apple 平台用 ⌘⌥⌃，其余用 Ctrl/Alt/Win）；鼠标手势显示为"滚轮上/中键"等语义名，不显示键码。
- 全部键鼠相关控件的可见性按 INPUT-13：连接硬件键盘、鼠标或触控板任一即完整显示绑定、录制、清空与冲突；仅直接触控时全部隐藏，绑定配置在模型中保留。动态连接不丢未提交草稿、不重置行或关闭页面、不弹软键盘；断开最后一个外设时取消未完成录制并保留原绑定。

## SETTINGS-12 数值输入、校验与提示 · 应当

- 所有数值在输入时按范围夹取，不产生越界持久化值；同一项的步进器、拉条、数值文本显示同一值。
- 百分比预设非法（≤0、无法解析、超上限）时不写入，给一次可见提示并恢复原值；不静默接受错误。
- 清库失败、内存告警、预算超限等状态用与级别对应的语义色，并同时有文本；不得只靠颜色表达状态。
- 说明文字只描述影响，不写实现细节；没有对应动作时不出现"保存成功"之类提示。
- 设置文档缺失时以默认值启动并保持可编辑，不崩溃、不阻塞主屏；损坏时按 SETTINGS-14 先备份原文件再以默认值启动。

## SETTINGS-13 键盘与显示缩放 · 应当

- 桌面端设置窗口的全部操作可用键盘完成：Tab 顺序等于视觉顺序，空格切换勾选/开关，方向键调滑条与步进器，回车提交数值输入。
- `Esc` 只退出录制或关闭弹层，不误关整个设置窗口；录制态不劫持 Tab 导航。
- 跟随系统文字大小与显示缩放：行高与文本容器随字号增长，不截断关键内容；移动端尊重安全区与动态字体。
- 排序必须有非拖拽等价入口（行内菜单的“上移/下移”命令），键盘可达；该等价入口不占用常驻按钮。

## SETTINGS-14 持久化、默认与迁移 · 必须

- 设置存为单一 JSON 文档，字段名与结构沿用现有契约；载体由平台决定（桌面为设置文件，Apple 偏好与 Android SharedPreferences 存同一份 JSON），不得按平台改名、嵌套或拆分。
- 读取旧文档时补齐缺失列表（格式 / EXIF / 快捷键 / 预设）与新增命令的默认项，按命令 id 去重，已存在的用户自定义值不覆盖；历史命令 id 在读取时迁移（`ToggleDetailView` → `ToggleAnalysisView`）并写回。
- 快捷键只持久化命令 id、顺序、显隐与主/次绑定；命令名、提示和图标是程序内命令目录的派生元数据，不进入设置文档。读取含这些历史展示字段的旧文档时忽略字段并按命令 id 取当前元数据，不为文案迁移保留映射表。
- 数值越界按范围夹取；未知字段忽略；缺失顶层字段用默认值，不因单个坏值丢弃整份设置。
- 提交后延迟 400 ms 合并落盘（`SettingsViewModel.Persistence`）；文件载体用临时文件替换，避免半写文件，落盘前崩溃不产生截断文档。
- 读取失败（JSON 损坏）时先把原文件改名备份为 `settings.json.corrupt-<时间戳>`，再按默认值启动；保存或读取失败在设置页顶部显示一行可见状态，不静默覆盖用户配置。
- 行为设置与视图状态分开：栏位显隐等主窗口视图状态按平台偏好保存，不写进设置页；相似面板展开态可随设置文档持久化，但同样不出现在设置页。

## SETTINGS-15 三张可勾选可排序表 · 必须

- 支持的文件格式、控制栏功能、EXIF 显示三张表共用同一行语义：勾选、主文本、可选副文本（扩展名）、排序入口；表高＝行数，不出现内嵌滚动条，滚动交给页面。
- 顺序即业务顺序：格式顺序决定同名代表格式，命令顺序决定控制栏按钮顺序，EXIF 顺序决定控制栏 EXIF 顺序。一次重排立即写入工作副本，序列不重复、不丢失。
- 重排载体统一为拖拽：桌面指针拖拽（可整行拖），移动端用原生拖拽（Android `ItemTouchHelper` + 行尾把手）；上下按钮不是可接受替代；结果必须与一次集合移动等义，不得只改显示顺序而不改业务集合。
- 勾选命中区独立于排序：拖动行或把手不改变勾选状态，轻点复选框才切换；触屏整行轻点切换时不得误触发拖动。
- 超长表只由页面滚动，表自身不滚动；行高不随内容换行跳动，行数变化时表高按行数重算。
