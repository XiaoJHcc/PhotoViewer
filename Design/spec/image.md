# 主图（IMAGE）

**意图**：主图是观片的地方——照片在最大区域里按显示朝向完整呈现，放大到 100% 时每个源像素落在屏幕物理像素上，缩放与切图都不打扰用户正在看的位置。

数值令牌：`image.*`、`nav.*`、`motion.image.*`、`color.viewer.*`、`color.nav.*`（见 [tokens.json](../tokens.json)）。平台实现与差异见 [platforms.md](../platforms.md#image)，验收状态见 [status.md](../status.md#image)。

## IMAGE-01 显示与画质不变量 · 必须

主图区恒显示当前照片，底色 `color.viewer.background`（#000000）；照片按显示朝向完整适应、不拉伸、不裁切、不加内边距。

| 不变量 | 要求 |
|---|---|
| 100% 口径 | 1 源像素对 1 屏幕物理像素；100% 及更高必须使用全分辨率源，代理图不得放大冒充 |
| 代理 → Full 热替换 | 只换纹理：倍率、位置、显示朝向、导航图可见框与百分比都不跳变 |
| 几何基准 | 恒为全分辨率源尺寸（含方向换轴）；源尺寸元数据缺失时允许在 Full 到达时纠正一次 |
| 缩放/平移锚点 | 按住指针或手指下的图像点；不得把视口拽向内容原点 |
| 叠加层 | 增强、细节绿框、导航图、提示都不得改变照片方向、源尺寸或视口变换 |

- 代理覆盖不足时请求 Full；Full 就绪前不宣称已具备全分辨率细节。
- 同一缩放档在代理与 Full 之间只允许锐度变化，不允许位置、朝向或倍率变化。

## IMAGE-02 适应 ⇄ 100% 与切图保持 · 必须

| 入口 | 适应态 | 已放大 |
|---|---|---|
| 双击照片 | 以双击点为锚点放大到物理 100% | 回适应 |
| Fit 命令（按钮、快捷键、菜单） | 有对焦点：以对焦点为中心到 100% 并进入跟随；无对焦点：视口中心 | 回适应 |
| 切图（胶片栏、上一张/下一张、相似面板点选、交换上一张） | 保持适应 | 保持同一物理倍率：跟随对焦时居中到新照片对焦点，否则保持同一归一化中心点；新照片无对焦点时停止跟随 |
| 代理 → Full | — | 不改变倍率与位置（IMAGE-01） |

- 本条的“100%”一律指物理 100%（1 源像素对 1 屏幕物理像素，口径见 IMAGE-01）；百分比显示见 IMAGE-04。
- 对焦点取当前照片 EXIF（Sony MakerNote）；EXIF 异步到达后下一次命令即用新值；无对焦数据视为无对焦点，回退视口中心。
- 跟随对焦判定：视口中心与对焦点两轴归一化偏差均小于 `image.focus.followTolerance`（0.05）；用户拖动或缩放离开后自动退出跟随。
- 照片物理 100% 不高于适应倍率（小图、RAW 内嵌预览）时保持适应，不把照片缩到比适应更小。
- 放大态切图不得重置为适应；适应态切图不得沿用上一张的倍率。
- 四端共用同一适应/100% 与切图保持判定（共享视口）：平台只改控件与手势，不改对焦点优先、跟随退出与切图保持规则。

## IMAGE-03 代理先行与 Full 升级 · 必须

- 先上屏代理：代理目标长边 = 视口长边物理像素 × `image.proxy.overscan`（2.0）；切换照片不等 Full 解码。
- Full 升级条件（满足其一）：非适应态且物理倍率达到 100%；非适应态且当前倍率超出代理可支撑的放大；分析栏可见（细节预览需要全分辨率源）。适应态且分析栏不可见时不主动升 Full（小图的适应倍率可能已高于 100%，同样不升）。
- 升级幂等、绑定照片代际：切图后旧升级结果丢弃，不得覆盖新照片；放大态切图可直接请求 Full。
- 升级不阻塞浏览：不切占位、不等升级完成才能缩放或翻页，也不改写当前缩放与平移状态。
- 代理解码失败时解码器可直接回退解码 Full，两者都失败才按 STATE-02 报「无法打开该图片」。
- 升级失败保持已上屏的代理，不黑屏、不伪造成功，等待下一次触发；屏上有代理时不得报「无法打开该图片」，改为非阻塞提示「无法载入全分辨率」（STATE-03）。
- 四端按同一判定（物理倍率与纹理覆盖）得出相同的升级时机，各端不一致即为缺口。

## IMAGE-04 缩放档位与百分比 · 必须

- 百分比 = 物理倍率 × 100，最多两位小数、去掉尾零；四端同口径，不得用逻辑点比例（Retina 上会显示成一半）。
- 预设缩放取设置中的百分比档：放大/缩小取当前值之上/之下最近的一档，不越档；没有更远档时不动作。锚点为视口中心。
- 比例缩放每步 ×1.25 / ×0.8，同样以指针点或视口中心为锚点。
- 缩放范围 `image.zoom.minScale`（0.01）到 `image.zoom.maxScale`（16，即 1600%）。
- **应当**：触屏以适应倍率为最小档（缩不下去就不缩）；桌面允许低于适应，此时照片居中、边界留黑。平台差异见 platforms.md（`IMAGE-04@ios`、`IMAGE-04@android`）。
- 程序化缩放动画 `motion.image.zoom.duration`（250ms）只影响过程，不改变终值；系统减少动态效果时直接到终点（应当）。
- 缩放命令只作用于主图，不改变当前照片、评分或筛选。

## IMAGE-05 平移与边界 · 必须

- 只有放大态可平移；适应态拖动不移动照片，照片小于视口的轴始终居中。
- 平移钳制按“显示尺寸 − 视口尺寸”的一半计算：照片边缘最多到达视口边缘，不得拖出空白；小于视口的轴居中。
- 视口尺寸变化（窗口、栏位显隐、布局切换、旋转、分屏）：放大态保持物理倍率与视口中心对应的图像点，再按新视口钳制；适应态按新视口重新适应。
- 尺寸变化只约束偏移，不改变倍率、不重置为适应、不改变照片身份。
- 缩小回适应后平移归零。
- 减少动态效果或动画被打断时，位置停在当前帧，不回跳到旧起点。

## IMAGE-06 导航图（缩放指示器） · 必须

显示条件：设置开启、非适应态、有当前照片，三者同时成立；任一条不成立即隐藏（切图回适应、无图、设置关闭）。桌面缩到低于适应倍率时同样显示，可见框为整幅缩略图。

| 元素 | 规则 |
|---|---|
| 位置 | 主图区右下角，距右/底 `nav.margin`（12）；触屏叠加安全区让位，并避让控制栏与分析栏 |
| 宿主 | 圆角 `nav.cornerRadius`（6）、内边距 `nav.padding`（8）、底色 `color.nav.background`（#222222）不透明度 `color.nav.background.alpha`（0.6） |
| 缩略图 | 长边 `nav.longEdge`（150），按显示朝向比例；取当前展示产物（含增强预览），不二次解码文件；只在产物或方向变化时重出，不重画全分辨率图 |
| 可见框 | 白色 `color.nav.frame`、厚 `nav.frame.thickness`（1）；比例与位置与视口一致，随每帧同步 |
| 百分比 | 与 IMAGE-04 同口径；`nav.percent.fontSize`（12）半粗，行高 `nav.label.height`（15），上间距 `nav.percent.topGap`（8），下余量 `nav.percent.bottomGap`（2） |
| 缩略图不可得 | 不得沿用上一张的缩略图；不得以整幅图或无意义的占位冒充当前位置 |

- **应当**：触屏点按/拖动导航图把该归一化点移到视口中心；桌面只展示、不接受指针。平台差异见 platforms.md（`IMAGE-06@mac`、`IMAGE-06@ios`、`IMAGE-06@win`）。
- 导航图不参与窗口拖动、翻页与照片缩放手势；触屏上的点按/拖动只用于上一条的定位。

## IMAGE-07 增强预览 · 必须

- 入口：控制栏命令（默认绑定 E）与主图菜单勾选项（菜单条目见 [menu](menu.md)）；开启后跨切图、跨代理→Full 持续生效，本次会话内保持，重启不保留。
- 开启时主图显示增强版本；计算期间继续显示原片，不得黑屏或切占位；就绪后原地替换；关闭立即还原原片。
- 只改显示：不写文件、不入库、不改 EXIF、源尺寸、方向与导航图几何；分析栏瓦片按增强图重算（见 [analysis](analysis.md)）。
- 新产物（切图、代理→Full）到达后自动重算；期间保持“计算中”直到新增强图就绪，避免提示闪烁。
- **必须**：计算持续超过 `image.busy.delay`（500ms）才在主图区底部显示 `计算中…` 药丸，结束即收起；不足 500ms 不显示，避免闪烁。药丸 `image.busy.width`（96）×`image.busy.height`（28）、圆角 `image.busy.cornerRadius`（11）、距底 `image.busy.bottomOffset`（24），主图分区已排除底部安全区，不重复扣减。四端同一门槛。
- 内存压力到 Warning 时自动关闭并还原原片（不得静默保持开启却显示原片），同时按 STATE-03 给一次性提示「内存不足，已关闭增强预览」；失败或取消时收起提示、保持原片、不自动重试。

## IMAGE-08 方向与显示朝向 · 必须

- EXIF/HEIF 方向只作用于显示变换（GPU/UV），不旋转源像素、不改源尺寸；方向码到显示朝向的映射取共享方向表。
- 适应、100%、导航图长宽、细节裁剪、直方图与绿框都按显示朝向计算；方向 ≥5 时宽高换轴。
- 8 个方向码都必须正确；切图、代理→Full、增强都不得改变朝向。
- 方向元数据缺失按未旋转（1）处理；不做“看起来更顺”的自动纠正。

## IMAGE-09 定位到指定图像点 · 必须

- 外部定位请求（分析栏细节预览双击）以显示朝向的归一化点为中心、直接放大到物理 100%，并退出跟随对焦。
- 目标点受 IMAGE-05 边界钳制；照片物理 100% 不高于适应倍率时保持适应。
- 定位后导航图、百分比与后续手势都从新状态继续：不得出现“画面显示与手势基准不一致”（下一次拖动跳回旧位置）。
- 定位不改变当前照片身份，不触发筛选或列表定位。

## IMAGE-10 主图区状态 · 必须

| 状态 | 表现 |
|---|---|
| 无当前照片 | 主图区居中显示引导（打开文件/文件夹、拖入）；标题 `image.hint.title.fontSize`（16）、详情 `image.hint.detail.fontSize`（11）、最大宽 `image.hint.maxWidth`（500）、详情相对标题顶边下移 `image.hint.detail.gap`（28） |
| 有照片未上屏 | 切图即清旧图，不显示上一张冒充当前照片；加载提示延迟 `status.loading.delay`（300ms）出现，图一到即撤下（形式见 [state](state.md)） |
| 解码失败 | 主图区可见的失败提示，不伪造图像；胶片栏仍可继续选别的照片，当前身份与评分不变 |
| 增强/分析计算中 | 主图区底部药丸（IMAGE-07），不遮挡主图主体，结束后不残留 |

- 提示文案、延迟与停留时长归 [state](state.md)；本模块只约束主图区内的位置、不变量与“不显示旧图冒充”。
- 空态下点击主图区可打开文件/文件夹选择器（入口见 [open](open.md)）。

## IMAGE-11 缩放状态的会话作用域 · 必须

- 缩放、平移、适应态与跟随对焦只在本次会话内保持；不写入设置，重启后首张从适应态开始。
- 所有切图入口共用 IMAGE-02 的保持规则，不因入口不同重置或额外缩放。
- 布局切换、栏位显隐、窗口尺寸变化只按 IMAGE-05 保持中心与相对缩放，不改倍率。
- 导航图显示开关与缩放预设的持久化归 [settings](settings.md)；增强开关不持久化。
- 主图缓存标记（胶片栏细边）只表示已缓存全分辨率，与当前缩放无关。
