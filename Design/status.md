# 四端实现状态

本文件按设计 ID 记录四端实现与验收状态；规则正文不写状态。状态词取自 [README §7](README.md#7-验收状态)：`代码核对`、`程序化通过`、`作者手验通过`、`待核验`、`缺口`、`延期`、`不适用`。

**证据规则**：每个格子只写"状态 + 日期 + 一句短语"，完整 OS、设备、素材与证据路径见对应计划文档；程序化通过不等于作者手验，不能把一个平台的结果复制给另一个平台。未登记的 ID 一律写 `待核验`。平台实现入口见 [platforms.md](platforms.md)。

证据文档：[macOS P3](../Plans/native-rebuild-phase-3.md) · [iPad](../Plans/native-rebuild-phase-ipad.md) · [Windows P2](../Plans/native-rebuild-windows-p2.md) · [Windows 主屏控件](../Plans/windows-main-screen-controls.md) · [Android](../Plans/native-rebuild-phase-android.md) · [Web 参考壳差分台账](../Plans/web-shell-gaps.md)（Web 只作规范检验，不设状态列） · [原生输入与设置/工具界面收口](../Plans/native-input-ui-refinement.md)（本轮运行证据与剩余项）。
