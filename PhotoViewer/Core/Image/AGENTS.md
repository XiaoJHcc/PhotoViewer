# Core/Image — 图片解码与文件模型

> 模块内手册。图片加载 pipeline(切图触发 → 解码 → 显示 → 预取)的端到端流程见 [架构文档](../../../Design/architecture.md) §5 关键流程。

`namespace PhotoViewer.Core.Image`

P2 原生新增：`IPresentationImageDecoder`（平台主图解码注入口）+ `IPresentationEncodingPolicy`（展示编码协商，I2 起；按尺寸档与压力返回编码，Core 内不含平台判断）；`PhotoLoadSession` 只持展示租约与代际/代理/Full 加载状态，视口变换由原生层负责。原生端到端流程见[架构文档](../../../Design/architecture.md) §5.6（macOS）、§5.7（iOS）、§5.8（Windows）与 §5.9（Android）。`IDisplayLoadSignal` 让压测驱动器（`PhotoViewer/StressFlipDriver.cs`）对"当前上屏状态"计时。

`SkiaImageCodec.DecodeToWidth/DecodeToLongEdge` 从 codec 原始尺寸填充 `SourceWidth/SourceHeight`，`ScaleToLongEdge` 继续保留这两项；无 EXIF 尺寸的照片也不能把代理尺寸当成 Full 几何。像素缩放算法和模型输入字节口径不变。

`DecodedImage` P2 扩展：保留 Bgra32/Rgb24，新增 RgbaF16 与 **Rgba8**（I2 起 8 位展示编码，RGBA 字节序，色彩空间由 `ImageColorSpace` 声明）；`PresentationFidelity` 给出展示编码保真度序（F16 可覆盖 8 位请求，反之不可）。色彩标签（Core/Color）、源尺寸、待应用方向与可选 ICC 均显式携带。缓存大小按 `ByteCount` 实际池化分配记账；原生启动期注入后 Thumb 仍是 sRGB8，小图缺少内嵌来源时允许原生子采样，不回退原图全解码。PhotoLoadSession 保持同代际代理覆盖单调增长，不让慢的小代理覆盖大代理/Full；放大态切图直接请求 Full。代理在途原请求取消而新调用仍有效时重发代理，取消不当作解码错误回退 Full；当前代际被外部取消时复位状态并给出可见错误，不再静默黑屏。并发入库用原子更新保留更大代理与缓存租约。

| [ImageEnhancer.cs](ImageEnhancer.cs) | 主图增强 | 只接受 8 位编码（Bgra32/Rgb24/Rgba8；误传 F16 等显式抛出不按字节误算）。 确定性"信息归一化"增强预览：全局**限对比直方图均衡（CLHE）**——亮度直方图按 `ClipFactor` 裁剪封顶 + 均匀回填（防断层 / 防大面积同色尖峰独吞输出范围）→ cdfMin 归一化 LUT → **保色度重建** `ch' = Y' + s·(ch − Y)`（YCbCr 恒定色度，`s = SaturationScale`）。该式结果亮度恒等于 `LUT[Y]` → 亮暗关系严格单调、色相不变；`s=1` 保**绝对**彩度，暗部彩度不随亮度塌缩发灰（取代旧的 `(newY+ε)/(oldY+ε)` 等比增益——那只保**相对**饱和度，暗部彩度仍随亮度趋零而发灰，且加性重建无除法故 ε 取消）。极端亮/暗处绝对彩度越界时逐像素把 s 收到"恰好不越界"，物理最小去饱和、无硬钳位。手感参数 `ClipFactor`（保守↔激进，默认 2.0）+ `SaturationScale`（默认 1.0）。纯算法、不改原文件、不入库；统一由 `PhotoLoadSession` 调用（算法只在 8 位 sRGB 口径上有定义，F16 表面经 sRGB 往返一次）。**两遍逐像素阶段按行并行、直方图分区统计后整数合并**（合并结果与串行完全一致）；`Enhance(source)` 拷贝后处理，`EnhanceInPlace(image)` 直接在调用方独占的 8 位缓冲上处理（省一次整图拷贝，输出逐字节等同）。输入输出均为 `DecodedImage`。设计意图 / 选型理由见 plan-3-1 §1.2。 |
| [HistogramRenderer.cs](HistogramRenderer.cs) | 直方图渲染 | 8 位档按存储通道计数（Bgra32/Rgb24/Rgba8；Rgba8 已是 Display P3 编码值，与 F16 档"线性→sRGB 编码后量化"同一显示参考口径），其余编码显式抛出。 把 `DecodedImage` 渲成 RGB 256 级直方图图像（透明底 + 三通道纯原色叠加填充曲线，重叠取 max → 三色重叠恰为白）。纯算法；分析栏"直方图"瓦片用它从当前主图（原片或增强图）现算，透明底让 DiagnosticTile 的 #222 透出。P2 起直接支持原生 F16 线性表面（按线性→sRGB 编码后量化，与 8 位口径可比），避免为直方图把整幅大图转成 8 位。**统计阶段按行分区并行、每分区独立 int[256]×3 后整数合并**（与串行逐字节一致）；F16 档用 65536 项 Half 位模式→sRGB 查表替代逐像素幂运算；`Render` 接受可选取消令牌，分区内每 64 行检查一次。 |
