# Core/AI — DINOv3 特征 + CV 网格 + 相似聚类

> 模块内手册。跨模块联动(批量索引被谁触发、抖动徽标怎么回填到 UI、清库按钮如何级联)写在根 `AGENTS.md` §5 关键流程。

`namespace PhotoViewer.Core.AI`

P2 原生索引适配：FolderFeatureIndexer 从主缓存取得 RgbaF16 时，调用 Core/Color/ColorEngine.ToAnalysisSrgb8 得到已应用方向的 BGRA8 后再跑 CV，并用转换后尺寸入库。DINO 仍使用原缩略图/模型输入口径；算法版本、指纹与 schema 不改。

> 二期持久化收尾已落地,见 [Plans/dinov3-photo-ranking-plan-2-3-persistence.md](../../../Plans/dinov3-photo-ranking-plan-2-3-persistence.md);上游 CV 抖动算法 v5 r3 见 [Plans/dinov3-photo-ranking-plan-2-2-shake-v5.md](../../../Plans/dinov3-photo-ranking-plan-2-2-shake-v5.md);更上游:[Plans/dinov3-photo-ranking-plan-1.md](../../../Plans/dinov3-photo-ranking-plan-1.md) · [Plans/dinov3-photo-ranking-plan-2-0.md](../../../Plans/dinov3-photo-ranking-plan-2-0.md) · [Plans/dinov3-photo-ranking-plan-2-1-wrapup.md](../../../Plans/dinov3-photo-ranking-plan-2-1-wrapup.md)(含标量/诊断图公式、14 张样本验收 checklist、废弃方案墓碑)。

| File | 模块 | Responsibility |
|---|---|---|
| [DinoModelResources.cs](DinoModelResources.cs) | 模型资源常量 | ONNX 资源 URI、输入规格(518/ImageNet mean-std)、I/O 端口名、`PatchSize`/`PatchGrid`/`PatchTokenCount`、`ModelId`(当前 `dinov3_vits16_f32_518_v2`，含显示朝向/解码版本变化)。改动此处需同步两个 Python 工具。 |
| [DinoFeatureExtractor.cs](DinoFeatureExtractor.cs) | DINOv3 推理门面 | ONNX Runtime 静态门面;`ConfigureSession(Action<SessionOptions>)` 接受平台注入的 GPU EP(Windows DirectML / macOS+iOS CoreML / Android NNAPI),未注入时 fallback CPU;延迟建 session + `EnsureDualOutputSchema` 早失败;**输入边长按 ONNX 元数据自适应(`DetectInputSize`,产品 518 默认,升级梯 1024 免改代码)**;`ExtractAsync` 只取 L2 归一化的 CLS 向量;`ExtractDualAsync(..., includePatches)` 同时返回 patch token(网格随输入边长),供诊断工具页与 indexer 消费。`UsesGpuExecutionProvider` 暴露当前会话是否成功注册 GPU EP(注册失败/回退 CPU 后为 false),供验收钩子与诊断读取。 |
| [DinoFeatureCache.cs](DinoFeatureCache.cs) | CLS 向量缓存 | 指纹索引 + 进程内存缓存 + `Lazy` 闸门(同指纹并发只推一次)。`GetOrComputeAsync` miss 走 `PhotoDatabase.WriteFeatureAsync` 后台写纵表;`TryReadAsync` 只读不触发推理;`InvalidateAll` 给"清除特征数据库"按钮调用。 |
| [FolderFeatureIndexer.cs](FolderFeatureIndexer.cs) | 全文件夹批量索引 | 实例化调度器:`GroupByFingerprintAsync` 按指纹聚合 → `EvaluateMissingPartsAsync` 评估三路缺失(CLS / patch / CV grid)→ 一轮扫描同时落 DINO CLS+patch+CV,单事务 `WriteIndexedAsync` 顺手带 `ExifSnapshot`(Plan-2-4:实际焦距/光圈/快门/CMOS 倍率 + rating 快照,等效焦距由训练脚本现算)。桌面端 `ProcessorCount/2` 解码并发 + 单线程 ONNX 推理;移动端单线程。进度按"指纹组"推进,完成后 `PutMemoryCache` 同步进程缓存。 |
| [SimilarityService.cs](SimilarityService.cs) | 相似聚类 | 基于 DINOv3 [CLS] cosine 的相似聚类(阈值与最多数量由 `SettingsViewModel.SimilarityThreshold` / `SimilarityMaxResults` 提供:阈值 75%~95% 默认 85%,数量 1~32 默认 8;硬上限 64 项),拍摄时间差作 tiebreaker。锚点必算、池内只读缓存 — 避免一次切图触发成百上千次推理。**调用时机由 `SimilarityPanelViewModel` 门控:面板展开且文件栏可见才随切图/筛选池/阈值重算,收起即取消在途计算(SCOPE-01)。** |
| [CvGridResult.cs](CvGridResult.cs) | CV 网格结果 POCO | 32×32 格 × **7 标量** × 1 层 = **7168 float**;标量 `edge_count` / `edge_width_p20` / `edge_width_median` / `drag_width` / `drag_direction` / `anisotropy` / **`block_contrast`**;`Version`(当前 **`cv_grid_v5_contrast`**)+ 小端 BLOB Encode/Decode。块尺寸自适应 `clamp(短边/32, 64, 192)`。**v5 升级**:`block_contrast` 升标量入库,UI 看图 ≡ DB 重画图。 |
| [CvGridExtractor.cs](CvGridExtractor.cs) | CV v5 标量提取 | 纯托管,无 native 依赖;每格 Sobel + 块级累结构张量 (Sxx,Syy,Sxy) → `θ_st` / `anisotropy`;边种子按自适应 τ_edge + NMS,Marziliano 单边步进算边宽;`drag_bucket` = 离 (θ_st+π/2) 最近的有效 bucket(测拖影线方向);`MaxHalfWidth` 按对角线 0.8% 自适应;同时累 luma 64-bin 直方图算 `block_contrast = p98-p2`(v5 写进 result.Data 第 7 标量);`Parallel.For` 跨格并行。`ExtractAsync(DecodedImage)` 返回 CvGridResult(单一入口),`ExtractFromLuma(luma,w,h)` 给 CvDebugTool 用。 |
| [CvHeatmap.cs](CvHeatmap.cs) | CV 诊断图 + 判定(纯函数) | `BuildSharpness(result)` 边宽对数热力图 × `ContrastFactor`(从 result 第 7 标量读);`BuildShakeField(result, diagonal)` 输出 32×32 `Direction` / `Width` / `Mask` / `LocalConsistency`(5×5 邻域 2θ 圆形均值)/ `Contrast` + 图像对角线 D,对比度软门控让低对比格不进 mask;`FitRigidMotion` 加权 LS + 迭代符号对齐,weight 乘 c_factor,输出 `\|T\|` / `\|ω\|` / `R_global` / `R_local p10` / `MaskRatio`;`ColorForShake(drag_r, R_local, c_factor)` 是 View/CvDebugTool 共用的唯一权威配色函数;判定阈值常量集中在文件顶部,改一处必同步 14 张样本回归。**所有 contrast 都从 result 读,阈值不入库**。 |
| [ShakeClassifier.cs](ShakeClassifier.cs) | 抖动分类(纯函数) | 把 `RigidMotionResult` + diagonal 映射到 `ShakeVerdict` 枚举(信息不足/静止/强旋转抖动/旋转抖动/平移抖动/混乱/弱信号);`IsShake(verdict)` 判定三类"算抖"(平移/旋转/强旋转);`FormatLabel` 给文本面板与潜在 ToolTip 共用。判定阈值常量仍集中在 `CvHeatmap`,本文件只做规则编排 — 缩略图徽标与 DINO 诊断页文本面板从同一份判定出发,改阈值两端同步。 |
| [ShakeFlagService.cs](ShakeFlagService.cs) | 抖动徽标服务 | 静态门面,按指纹分组读 `photos.cv_grid` + `cv_image_width/height` → `BuildShakeField` + `FitRigidMotion` + `ShakeClassifier.Classify` → 回填 `ImageFile.IsShake`。完全不触发图像解码或 ONNX 推理;进程内按指纹缓存。`EvaluateAsync` 由 `MainViewModel` 在 `FolderVM.AllFilesChanged` 时调用,以及 `SimilarityPanelViewModel` 在批量索引完成后调用;`InvalidateAll` + `RecheckRequested` 让 AI 设置页"清除特征数据库"按钮能让徽标即时消失。 |
| [PatchHeatmap.cs](PatchHeatmap.cs) | DINO patch 诊断图(纯函数) | 消费 1024×384 patch token:`ComputePcaRgb` 经济型 SVD 取前 3 主成分 → 32×32×3;`ComputeRefCosine` 参考点 cosine 映射到 [0,1]。PCA 用 `MathNet.Numerics`。 |
| [AnalysisTile.cs](AnalysisTile.cs) | 平台中立的瓦片状态 | 分析栏与 DINO 诊断工具页共用的瓦片描述(类型/角标/说明/占位/位图/矢量场/细节裁剪中心与对焦框)。位图归 cache、presenter 或平台展示层所有,消费者只读不释放。 |
| [IAnalysisHost.cs](IAnalysisHost.cs) | 分析栏宿主契约 | 平台展示层上报可见性、即时计算开关、当前图与展示位图;`HostChanged` 驱动 presenter 重路由。旧壳由 `AnalysisViewModel` 实现,macOS 原生由 `MacAnalysisHost` 实现。 |
| [AnalysisPresenter.cs](AnalysisPresenter.cs) | 分析栏状态机(中性) | 从旧壳 `AnalysisViewModel` 抽出的全部编排:只读库快路径、增强联动实时重算、未提取回退(延迟+让位)、直方图现算、准星与 cosine 参考点、瓦片占位与清理。**新旧两条展示层共用同一份逻辑**,各自只做位图格式适配。后台读取展示图前先取租约,避免宿主释放导致 use-after-release。 |
| [DinoDiagnosticPresenter.cs](DinoDiagnosticPresenter.cs) | DINO 诊断页状态机(中性) | 工具窗口"DINO 诊断"页的数据来源:读库快路径 + CV/DINO 两路解码与推理 → 锐度图 / 抖动矢量场 / 刚体拟合文本 / PCA-RGB / 参考点 cosine。旧壳 `DinoDebugViewModel` 与 macOS 原生工具窗口共用;诊断页不回写库。 |
| [HeatmapBitmapBuilder.cs](HeatmapBitmapBuilder.cs) | 诊断图渲染 | 把 [0,1] 平面或 RGB 数组渲成 `DecodedImage`(viridis / grayscale / raw RGB);输出 1:1 原尺寸,放大交给 XAML 端 `BitmapInterpolationMode=None`(经 `DecodedImageToBitmapConverter` 上屏)。 |
| [AnalysisDataReader.cs](AnalysisDataReader.cs) | 分析栏只读门面 | 静态门面,两步:`ComputeFingerprintAsync` 单独算指纹(给 cache 命中检查用);`ReadByFingerprintAsync` 给定指纹时 `Task.WhenAll(ReadPatchesAsync, ReadCvGridAsync)` 并行读 → 反序列化为 `(patches, cv, cvImageWidth, cvImageHeight)`。`TryReadAsync` 是两步合一的旧路径。**完全不触发图像解码 / ONNX 推理 / CV 重算**;指纹缺失或 schema 不匹配视为该项缺失。 |
| [AnalysisComputer.cs](AnalysisComputer.cs) | 派生层现算器 | 纯函数 `Compute(Result)`:消费 `AnalysisDataReader.Result` → PCA-RGB / 默认中心 cosine / 锐度图 / `BuildShakeField` + `FitRigidMotion` + 判定文字 → 装进 `AnalysisResultCache.Entry`。给 `AnalysisPresenter` 与 `BitmapPrefetcher` 两条调用路径复用。PCA SVD 是 ~几十 ms 主因,sink 进 cache 后切图变纯 UI swap。 |
| [AnalysisResultCache.cs](AnalysisResultCache.cs) | 分析栏 LRU 缓存 | 指纹 → 派生数据(4 张位图 + ShakeField + 判定文字 + patch tokens + aspect)的 LRU 缓存(容量 32 项 ≈ 50 MB)。命中即可让展示层直接 UI swap;两条填充路径:presenter 切图 miss 后落 cache、`BitmapPrefetcher` 预取邻居位图时顺手预热。`InvalidateAll` 给 AI 设置页清库按钮调用。**淘汰不主动 Dispose 位图** — 体量小且 GC 兜底,换取 TryGet/Put 无 use-after-dispose 的简单语义。 |
