# Android 原生壳作者验收清单

> 对象：Android 原生壳（A1–A5；Debug/Release 均直接进入原生壳）的**人工验收**。
> 执行清单与逐里程碑状态见 [native-rebuild-phase-android.md](native-rebuild-phase-android.md)。
> 契约 ID 对应 [Design/spec/](../Design/spec/)（按模块分文件），验收状态回填 [Design/status.md](../Design/status.md)。测试只写自有素材副本，不修改用户照片。
>
> **设备前提（2026-10-18）**：作者**有安卓手机**（主力机型，本清单的真机项默认落在它上面），**没有平板**。因此：
> - §1–§5：可在模拟器或作者手机上执行。
> - §6–§8：**必须真机**，在作者手机上执行；其中**多 ROM / 多系统版本**（第 27、30 项）只能在借到其他机型时补，未覆盖的机型保持未关闭。
> - 平板不做专项适配（沿用两向布局），不列入验收。

## 0. 当前结论

**进展（2026-10-19 更新）**：Android 原生壳 A1b–A5 已落地并在 API 35 arm64 模拟器上通过 `pv-check` 五模式程序化检查（main/analysis/similarity/settings/tools = 14/18/15/16/16）；本清单仍是**待作者手验**状态，真机门与矩阵未跑。完成一轮后在文末"签署"表记录日期、设备、系统版本与结论；未通过项保持未关闭，不以模拟器结果代替真机项，也不以其他平台结果代替。

## 1. 启动与入口（模拟器）

1. 执行 **Debug Android**，确认进入原生主屏、启动日志有 `shell: native (Views)`、无 Avalonia 残留窗口。
2. 原生启动过程不构造任何 Avalonia 对象（`AndroidApp` 未被实例化）。
3. 冷启动到首图可见的时间可接受（体感 < 2s；不与 Mac/iPad 对比，只记数值）。

## 2. 主屏布局与栏位（模拟器）

4. 手机纵向：文件栏在上、主图居中、控制栏在下；横向切换为列布局（文件栏在左），几何随之重算（[SHELL-01](../Design/spec/shell.md#shell-01-布局模式分区与栏位显隐--必须)）。
5. 依次隐藏胶片栏、控制栏、分析栏：空间让给主图；重新显示后原状态与当前项位置正确。
6. 栏位背景铺到屏幕边缘、内容收进安全区；**手势导航条与刘海/挖孔**不遮挡内容（纵向与横向各确认一次）。
7. 系统字体缩放 1.0 与 **1.3** 两档下：控制栏不截断、胶片栏卡片文字不溢出、设置 sheet 行高自适应。

## 3. 胶片栏与筛选条（模拟器）

8. 12 张以上照片：卡片 96×144 外框、90×138 占位、80 方形照片；当前项高亮、Full 缓存细边、文件名尾部截断、第二行拍摄时间、星级与抖动徽标含义正确（[FILM-05](../Design/spec/film.md#film-05-卡片内容与命中区域--必须)）。
9. 点选卡片：主图立即切换、卡片高亮，列表**不**主动居中（[FILM-01](../Design/spec/film.md#film-01-选中与定位分离--必须)）。
10. 上一张/下一张（按钮、键盘、适应态轻扫）：主图立即切换，约 350ms 内完成居中；首尾不环绕（[FILM-02](../Design/spec/film.md#film-02-定位几何与动效--必须)）。
11. 定位动画进行中点选或拖动列表：用户接管，动画立即停止；连续换向只执行最后一次（[FILM-03](../Design/spec/film.md#film-03-用户接管与减少动态效果--必须)）。
12. 在"开发者选项 → 动画时长缩放"设为"关闭"后重复第 10 步：直达终点无动画。
13. 排序/升降序/星级筛选：列表与计数正确、当前项暂留规则符合 [FILM-06](../Design/spec/film.md#film-06-评分与筛选的连续性--必须)。
14. 卡片长按菜单：标题为完整文件名 + 拍摄时间；"评分 0–5"写回后卡片星级更新、**主图不切换**；卡片小星级点按不选中父卡片。

## 4. 主图与手势（模拟器 + 真机手感见 §7）

15. 双指捏合缩放、拖动平移、松手回弹自然；双击在适应与 100% 间切换且以点按位置为锚点（[IMAGE-01](../Design/spec/image.md#image-01-显示与画质不变量--必须)）。
16. 放大到 100% 后切图再切回：位置/朝向/缩放不跳变；缩回适应不残留全分辨率纹理。
17. 适应态单指横向轻扫翻页；放大态横向拖动只平移；起手双指捏合不翻页。
18. 八方向 EXIF 素材：主图方向、导航图方向、细节预览方向三者一致。
19. 色彩：sRGB / Display P3 素材各一张，与系统"照片"应用对拍无明显偏色；**不支持广色域的模拟器上确认走 sRGB 回退且画面正常**。
20. 返回手势：主图态下返回退出应用前有明确预期（不意外退出）；分析栏/相似面板/设置 sheet 打开时，返回先关面板。

## 5. 控制栏、工具与设置（模拟器）

21. 控制栏三分组顺序与显隐符合设置，按空间换行且居中；横排评分 0→5、竖排 5→0（[TOOLBAR-01](../Design/spec/toolbar.md#toolbar-01-三个分组完整顺序固定--必须)）。
22. 控制栏 EXIF 信息块点击进入工具页；工具页只有"EXIF 详情 / DINO 诊断"（无照片数据统计）；EXIF 页 7 列、多格式可切换。
23. 设置从底部浮起、默认半屏、可上拖全屏；顶部圆角与拖拽把手正常；下拉关闭与返回关闭**都**回写（[SETTINGS-01/02](../Design/spec/settings.md#settings-01-控制列表行结构--必须)）。
24. 设置五分类全部可进入；改布局模式、栏位显隐、控制栏命令显隐/顺序、快捷键、文件格式筛选后关闭，主屏立即生效。
25. 设置内拖拽排序（控制栏命令）可拖动并保存顺序。
26. 分析栏、相似聚类、增强预览入口与 [ANALYSIS-01](../Design/spec/analysis.md#analysis-01-入口显隐与内容构成--必须) / SIM-01 同语义；"提取全部"后当前照片诊断瓦片立即出图。

## 6. 真机：ROM 一致性（作者手机可执行；多机型项需借机）

27. **中文字形**：先记录作者本机字体（ROM 品牌与系统字体名）；字体替换后布局不跑版。小米（MiSans）、OPPO/vivo（OPPO Sans）、华为/荣耀（HarmonyOS Sans）**各一台为理想覆盖**，只能在借机时逐台补，未覆盖机型保持未关闭；记录字体差异是否可接受（若不可接受，另立"内嵌 CJK 子集"，见执行清单 §1.4）。
28. **主题配色**：确认 Material You 动态取色**未生效**（换壁纸后应用配色不变）；深色主题下所有 Material 组件颜色与设计一致。此项作者手机即可关闭，不必等借机。
29. **手势导航 vs 三键导航**：两种模式各确认一次，安全区与返回手势行为正确。
30. **系统版本跨度**：作者手机为其实际版本；Android 8/9（API 26/28）、Android 12（31）、Android 15（35）等低/高版本覆盖需借机或用模拟器补（模拟器只覆盖边到边几何，不覆盖 ROM 定制），未覆盖版本保持未关闭。
31. **厂商省电策略**：应用切后台再回来，照片与位置状态保留；外部打开（从"文件"App 打开照片）能回到前台并定位目标。

## 7. 真机：手感与色彩（**必须真机，当前无设备**）

32. 缩放手势跟手度、惯性、回弹；双击到 100% 的过渡是否自然（对照 iPad 手感）。
33. 胶片栏滚动的惯性、贴边、快速滑动时的卡片复用无错位/闪烁。
34. 真实 P3 面板上的色彩：P3 与 Adobe RGB 素材与系统"照片"对拍；超出 P3 立方体的原色按 sRGB 编码时的表现记录为已知边界。
35. 屏幕高刷新率（90/120Hz）下滚动与动画的帧节奏。

## 8. 真机：存储与外部打开（**必须真机，当前无设备**）

36. SAF 选择文件夹后，重启应用再进入：授权仍在（persisted permission），可继续翻页。
37. 从第三方文件管理器（Google 文件 / 小米文件管理 / ES）以"用其他应用打开"进入：目标照片被选中、胶片栏定位。
38. 评分写回：在 SD 卡/共享存储目录下的 JPG 与 HEIF 上各改一次星级，用第三方 EXIF 查看器确认文件已更新。
39. RAW 文件：确认 Android 的 libheif / 系统解码链路对 Sony ARW 的实际表现，记录是否只有内嵌预览（与 iOS 同类问题）。
