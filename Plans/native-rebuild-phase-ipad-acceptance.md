# iPad 原生壳作者验收清单

> 对象：iPad 原生壳（I1–I5，Debug 默认 UIKit；Release 用 `--native`）的**作者真机手验**。
> 程序化验收（模拟器两机型 + 真机 `--pv-native-*-check`）已完成，证据与逐里程碑状态见 [执行清单 §7](native-rebuild-phase-ipad.md) 和 [handoff §3](native-rebuild-handoff.md)；本清单只列**必须由作者亲手确认**的项，程序化结果不代替。
> 契约 ID 对应 [Design/ui-contract.md](../Design/ui-contract.md)。测试只写自有素材副本，不修改用户照片。

## 0. 当前结论

**待作者执行（2026-10-17）**：程序化项全 PASS，手验项尚无结论。完成一轮后请在文末"签署"表记录日期、设备、系统版本与结论；未通过项保持未关闭，不以模拟器结果代替。

## 1. 启动与外部打开

1. 执行 **Debug iOS (Native)**（或 **Debug iOS** 后以 `--native` 启动），确认进入原生主屏、无 Avalonia 残留（启动日志有 `shell: native (UIKit)`）。
2. 执行 **Debug iOS Simulator (Legacy)** 或真机 `--legacy-ui`，确认旧壳仍可启动；再切回原生，确认窗口正常（scene 会话恢复不串壳）。
3. 在"文件"App 中长按一张照片/一个文件夹 →"用 PhotoViewer 打开"；确认进入原生壳、目标被选中、胶片栏定位；文件夹被授权后可正常翻页。
4. 从"文件"App 拖入文件/文件夹到主屏；确认与第 3 步同一条打开路径（同 [FILM-01](../Design/ui-contract.md#film-01选中状态与定位请求分离) 定位语义）。

## 2. 主屏布局与栏位

5. 上下（行）/左右（列）/自动三种布局：文件栏、主图、控制栏、分析栏位置正确；切换"自动"后随窗口方向变化（[SHELL-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
6. 依次隐藏胶片栏、控制栏、分析栏：空间让给主图，重新显示后原状态与当前项位置正确；栏位背景铺到屏幕边缘、内容在安全区内（隐藏状态栏时顶边不吃内容）。
7. 旋转设备，以及 Split View / Stage Manager 拖动改变窗口尺寸：几何随尺寸重算，主图不变形、控制栏按空间换行/换列；普通尺寸变化不抢胶片栏滚动位置（[FILM-04](../Design/ui-contract.md#film-04布局显隐与平台差异)）。
8. 隐藏胶片栏后重新显示、切换行/列方向：当前项被显式定位（350ms 缓出），随后普通 resize 不再居中（FILM-03/04）。

## 3. 胶片栏与筛选条

9. 12 张以上照片：横向/纵向胶片栏滚动流畅，卡片 90×138（含 3 点占位）、照片区 80 方形；当前项蓝框、Full 缓存细边、文件名尾部截断、第二行拍摄时间、星级与抖动徽标含义正确（[FILM-05](../Design/ui-contract.md#film-05卡片视觉与点击区域)）。
10. 点选任意卡片：主图立即切换、卡片高亮，列表**不**主动居中（[FILM-01](../Design/ui-contract.md#film-01选中状态与定位请求分离)）。
11. 上一张/下一张（按钮、键盘、适应态轻扫、鼠标滚轮）：主图立即切换，约 350ms 内完成居中；首尾不环绕、短列表无额外空白（[FILM-02](../Design/ui-contract.md#film-02定位的几何与动效)）。
12. 定位动画进行中点选卡片或拖动列表：用户接管，动画立即停止；连续快速换向只执行最后一次请求（[FILM-03](../Design/ui-contract.md#film-03中断与系统无障碍)）。
13. 开启系统"减弱动态效果"后重复第 11 步：直接到终点、无动画；点选仍不居中。
14. 排序/升降序/星级筛选菜单：选择后列表与计数正确、当前项暂留规则符合 [FILM-06](../Design/ui-contract.md#film-06评分与筛选的连续性)；相似聚类 toggle 90×27 紧随计数并参与整组居中（[FILTER-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
15. 卡片长按菜单：标题为完整文件名 + 拍摄时间；选择"评分 0–5"后文件写回、卡片星级更新、**主图不切换**（FILM-05/06）。卡片上的小星级按钮点按不选中父卡片。

## 4. 主图与手势

16. 双指捏合缩放、拖动平移、松手回弹与惯性自然；双击在适应与 100% 间切换且以点按位置为锚点；三指及以上不触发翻页（[IMAGE-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
17. 放大到 100% 后切图再切回：Full 自动接续、位置/朝向/缩放不跳变；缩回适应不残留全分辨率纹理。
18. 适应态单指横向轻扫：上一张/下一张并触发显式定位；放大态横向拖动只平移不翻页；起手双指捏合不翻页。
19. 打开 Sony ARW：当前 iOS ImageIO 只给内嵌预览（约 1.7MP），放大到 100% 的清晰度以此为准——**已登记平台限制（`SCOPE-04@ios`），不计为缺陷**；`CIRAWFilter` 全分辨率解码作者 2026-10-18 定暂缓，并入性能专项。
20. 浅色/深色外观、sRGB/P3/Adobe RGB 素材：P3 与 Adobe RGB 素材在屏幕上无明显偏色；超出 P3 立方体的原色（如 Adobe RGB 红）在 8 位 Full 档钳到 P3 边界属已知边界；用系统"预览"对拍，不以帧导出代替（色彩门）。
21. 连接外接显示器或跨屏拖动窗口：物理像素尺寸与代理/Full 档随屏刷新，不重载、不跳变。

## 5. 控制栏与工具页

22. 控制栏三分组顺序与显隐符合设置，按空间换行/换列且居中；横排评分 0→5、竖排 5→0（[TOOLBAR-01](../Design/ui-contract.md#toolbar-01本轮工具栏对拍2026-10-15)）。
23. EXIF 信息块点击进入工具页；列表页只有"EXIF 详情 / DINO 诊断"（无照片数据统计）；EXIF 页 7 列、多格式可切换、值最多 3 行尾部截断。
24. DINO 诊断页 5 张瓦片正常出图（非全黑）、点击落准星、空白处清除；返回与关闭后可重开（[ANALYSIS-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。

## 6. 输入

25. 硬件键盘：方向键翻页、数字键评分、用户主/次绑定全部生效；按住方向键连续翻页的节奏可接受（350ms 首次、60ms 重复；iOS 无系统速率接口，[INPUT-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
26. 在设置页文本输入框获焦、或文档选择器/工具页等模态展示时，键盘快捷键不误触主图。
27. 鼠标/触控板：离散滚轮按"鼠标绑定"翻页；触控板双指连续滚动平移主图、捏合缩放；辅助点按（右键）弹出与 Mac 同序的主图菜单。
28. 从主图长按菜单逐项检查：打开文件夹…、胶片栏/分析栏/控制栏（勾选）、增强（勾选）、工具…、设置…；勾选态与实际状态一致，I5 起无死项。
29. 设置页下拉关闭与关闭按钮都能回写；重新进入后布局模式、栏位显隐、控制栏命令显隐/顺序、快捷键、EXIF/评分分组、文件格式筛选均已在主屏生效。
30. 拖入文件时主屏有合理的接收反馈；拖入文件夹后列表被替换并定位首项。

## 7. P3 功能

31. 分析栏经主图菜单/控制栏命令打开：行布局在主图下方、列布局在右侧；瓦片为正方形、间距一致；打开时主图升 Full（[ANALYSIS-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
32. 细节预览：触控板悬停联动主图绿框；手指点按**定格**绿框，再点一次或点主图空白解除；双击把主图定位到裁剪中心并放大。
33. 未提取照片：显示"未提取"；开启"即时计算 DINO/CV"后改为"计算中…"并自行出图；点"提取全部"后当前照片的诊断瓦片立即出图，无需切图。
34. 相似聚类 toggle：展开后行布局从胶片栏右侧切出、列布局扩宽文件栏；空态/列表态/进度/未提取计数与文案正确；真实"提取全部"后卡片出现百分比与 75% 起柱状条；点卡片切主图并双高亮（卡片取主图身份、胶片栏锚点保留），星级只改评分（[SIM-01](../Design/ui-contract.md#3-其他设计要求与对拍参考)）。
35. 增强预览：开关跨切图持续生效；压力告警时自动关闭；增强态下分析栏直方图/细节预览跟随增强图。
36. 面板收起时快速翻页：不触发 DINO 推理（控制台无 `[DinoFeatureCache]` 日志）；重新展开按当前图重算一次。

## 8. 内存、压力与稳定性

37. 500 连翻（HEIC + ARW 混合）：无闪退、无 jetsam、压力级别正常或可恢复；`stress-flip.jsonl` 有逐张记录。
38. 分析栏可见 + 连续翻页：允许偶发超时，但无崩溃；关注 p95 约 2.6s 的卡顿是否可接受（待性能专项）。
39. 触发系统内存告警（模拟器 Debug > Simulate Memory Warning，或真机高负载）：代理档降为 8 位 P3、预取暂停，Normal 后约 30s 才恢复预取。
