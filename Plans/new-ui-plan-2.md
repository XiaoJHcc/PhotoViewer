# 移动端适应的 UI 重构 · Plan 2 · U2/U3 组件设计

> 依据：[new-ui-plan-0.md](new-ui-plan-0.md)（需求 1–10）、[new-ui-plan-1.md](new-ui-plan-1.md)（U2、U3 完成契约与已定决策）。本文件只写 U2/U3 的组件设计与暂行取值，G2/G3 作者门复核后再把定稿值升格进 `Design/`。阶段号只用于本计划与提交标题。

## 1. 星级控件（U2）

### 1.1 两种状态与几何

| 项 | 展开态 | 紧凑态 |
|---|---|---|
| 外形 | 玻璃胶囊，交叉轴 44（`shell.glass.button.size`），内含 0–5 六格 | 玻璃胶囊（交互式玻璃），铺满槽位主轴，不短于 `rating.compact.minLength` |
| 主轴长度 | 固有长度 = 6 × `rating.control.slot`(36) + 2 × `rating.control.endInset`(4) = 224，沿槽位主轴居中 | 槽位长度（宽形态控制栏里取最短长度） |
| 内容 | 横排 0→5 自左向右，竖排 5→0 自上而下；0 号为清零叉，冲突时为红色警示三角 | 五颗星叠压成一簇（字号 `rating.compact.glyph.fontSize`、中心距 `rating.compact.step`），点亮的金色实心在前、未点亮的描边星在后；冲突时簇前加红色警示三角 |
| 切换 | 槽位主轴 ≥ 224 用展开态，否则紧凑态；阈值就是固有长度，不压缩星距 | — |

实测槽位（iPhone 17）：竖屏底行显示上下张时 165 → 紧凑；关闭上下张时 261 → 展开；横屏控制列 261 → 展开。iPad 宽形态控制栏一律展开。

### 1.2 交互

- **展开态**：按下即预览按下格的值，沿星排拖动预览跟随，抬手提交；手指在交叉轴越出控件 `rating.gesture.cancelSlop`(44) 进入取消区，预览回到原值，抬手不写。越过两端夹到 0 / 5。点按就是"按下—抬起"同一格。
- **紧凑态**：按下立即朝主图内侧弹出星级弹窗；手指越过 `rating.gesture.tapSlop`(8) 之前不预览，之后按手指在弹窗星排主轴上的投影取值（手指不必移进弹窗）；抬手提交并在写回成功后收起。没有越过 tapSlop 就抬手视为点按：弹窗保持打开，再点弹窗里的星提交。交叉轴越出"弹窗远端到胶囊远端"一带外加 cancelSlop 即取消区，抬手不写并收起弹窗。
- **一次手势最多写一次**：预览不落盘；预览等于原值不写；取消、系统打断不写。冲突时（`forceCommit`）落在任何星上都写，因为同值写入也会消解冲突。
- **冲突**：展开态 0 号是警示三角，抬手落在三角上不写值、打开来源弹窗；落在 1–5 照常整组写入。紧凑态冲突时点按打开来源弹窗，不支持滑动选择。
- **写回期间**：提交后控件把提交值显示为"待确认"（点亮星降到半透明），写回成功由模型真值接管；失败回到真值并由 STATE-03 提示条说明，不静默回滚。
- **触感**：预览每跨一档一次选择触感（`UISelectionFeedbackGenerator`），提交一次轻冲击（`UIImpactFeedbackGenerator` Light）。力度候选留 G2。
- **动效**：被按住的格放大 `motion.rating.press.scale`(1.25) 弹簧回弹；减少动态效果时不缩放。
- **指针**：展开态逐格系统指针高亮（`UIPointerInteraction` 分格区域 + 高亮效果），紧凑态整胶囊高亮；鼠标/触控板点击与手指同一套跟踪。
- **读屏**：可调节语义，值为"N 星 / 无星级 / 星级冲突"，增减各写回一次；紧凑态激活即打开弹窗。
- **禁用**：无当前照片时禁用，几何与命中区不变，内容降到 `color.toolbar.disabled.content.alpha`。
- **显示评分关闭**：宽形态整组移除（TOOLBAR-03）；手机形态槽位保留空位、控件隐藏（暂行决定）。

### 1.3 星级弹窗

- **承载**：窗口内玻璃面板（`UIGlassEffect`，圆角 `rating.popup.cornerRadius`），不用系统浮窗——紧凑态与卡片长按要把同一次触摸从入口延续到弹窗星排（S3 的预设退路，直接采用）。面板下方铺一层全窗透明拦截层，点按外部即关闭并吞掉该次触摸。
- **方向（一律朝主图内侧）**：

| 入口 | 手机竖屏 | 手机横屏 | 宽形态行布局 | 宽形态列布局 |
|---|---|---|---|---|
| 星级控件 | 上 | 刘海在左向左，刘海在右向右 | 上 | 左 |
| 卡片 | 上 | 刘海在左向右，刘海在右向左 | 下 | 右 |

- **落位**：面板沿入口主轴居中，与入口相距 `rating.popup.gap`(8)，整体夹进"窗口安全区内缩 `popup.ratingSources.edgeMargin`"。
- **非冲突（单条目）**：首行文件名（中间省略），放得下时行尾右对齐附拍摄时间 `MM-dd HH:mm`，放不下就不显示时间；下方星排 6 × `rating.popup.slot`(44)。竖排弹窗（竖排控件）宽 `rating.popup.columnWidth`，文件名一行、时间一行，下方竖排星列（5→0 自上而下）。
- **冲突（来源条目）**：按来源逐条纵排、分隔线分隔，条目排版沿 RATING-04（文件名放不下与标签/状态同排时独占首行），星排同为 44 格，任一条目点值整组写入。
- **星排步长**：可用主轴不足时按 6 格收窄，不小于 `rating.popup.minSlot`(28)。
- **数据与关闭**：两种内容都由共享 `RatingSourcesViewModel` 驱动（打开即 `ShowRatingSources`，写入走 `RatingSources.SetRatingAsync`，成功且冲突解除时该 VM 关闭，弹窗随之收起；失败保留并显示刷新后的真值）。另在以下情况关闭：切图或当前照片因筛选重算改变、入口被隐藏/移除/移动（布局重排、旋转、列表重载、卡片入口所在列表滚动）、Esc、点按外部。
- **动效**：打开从入口一侧弹簧放大淡入 `motion.rating.popup.open`(280)，关闭淡出 `motion.rating.popup.close`(160)；减少动态效果时只淡入淡出。

### 1.4 接线

- 三个槽位用同一个 `iOSRatingControl`：手机竖屏底行、手机横屏控制列、宽形态控制栏评分组。控件实例常驻，评分变化只刷新显示值，不重建控制栏。
- 宽形态控制栏改为新类型 `iOSToolbarView`（删除 `iOSControlBar`）：分组流式排布取新共享 `ToolbarFlowLayout`（整组换行、行内居中），评分组按星级控件固有长度占位，命令换 44 圆形玻璃按钮（`GlassButtonConfiguration`），EXIF 小块暂沿旧样式（U3 换新块）。
- 卡片冲突三角（指针点按）打开来源弹窗，锚点为整张卡片；卡片长按在 U3 接入。
- 删除 `iOSRatingSourcesPopover`、`iOSNativeRatingPopoverProbe` 与手机星级占位视图；旧 layout 检查里的来源浮窗段落删除，覆盖面迁到新的 `--pv-native-rating-control-check`。

### 1.5 共享层（`PhotoViewer.Shared`，纯函数，进 CoreContractCheck）

- `RatingControlGeometry`：状态判定、控件在槽位内的矩形、格子矩形与"主轴坐标 → 值"映射（横排/竖排、可变步长）、紧凑星簇偏移、弹窗方向表与落位夹取。
- `RatingGesture`：一次手势的状态机（起手、移动、抬起、取消；延迟预览、强制提交、0 号开弹窗三个开关），保证每次手势最多一次提交。
- `RatingPopupLayout`：弹窗步长、单条目（横/竖）与来源条目排版、面板尺寸。
- `ToolbarFlowLayout`：宽形态控制栏的分组尺寸（EXIF / 星级 / 圆按钮命令）、整组换行、行长与文档尺寸。

## 2. 信息组件（U3）

### 2.1 胶片卡片两档

| 档 | 外框 | 内容 |
|---|---|---|
| 大档 | 96 × 144（`film.card.*`，几何不变） | 80 方形照片区、文件名、拍摄时间、六格星级、抖动徽标 |
| 小档 | 64 × 76（`film.card.small.*`） | 54 方形照片区、文件名一行；照片区右下角星级角标（金星 + 数字，0 星不显示，冲突时角标前加红色三角），右上角 8 点圆形抖动点 |

- 两档共用同一套外观：占位面内缩、深色底、圆角 7、当前项 2 点蓝框、主图已缓存时照片区 1 点淡色细边、占位与加载态。
- **选档**：胶片条主轴能放下 5 张大档（扣掉主轴两端内边距）用大档，否则小档。手机竖屏 402 宽 → 小档；iPad 宽形态 → 大档；iPad 手机模式全屏 → 大档。
- **最少 5 张**：可见容量按胶片条整条主轴长度 ÷ 卡片步长计（手机胶片条贯穿屏幕、卡片可滚到按钮下方）；iPhone 17e 横屏 390 ÷ 76 = 5.1。例外：iPad mini 1/3 分屏 248 宽只有 3 张，待作者裁定。
- **带厚**：小档横排 76 + 2 × 8 = 92，竖排 64 + 2 × 8 = 80（交叉轴内边距 8 与 `shell.phone.rowInset` 同值，横屏卡片右缘与按钮列缘对齐）；大档沿用 159 / 116。
- 宽形态打开相似面板时胶片栏固定大档。
- **输入分流**：大档星排是纯显示视图，挂一个只收间接指针（`AllowedTouchTypes = IndirectPointer`）且只在星排矩形内接收的点按识别器：指针点星写值、不选中卡片；手指落在星排上落到整卡选择按钮，只选中、不写值。指针点冲突三角打开来源弹窗。小档没有逐星目标。
- **长按**（两档，提前自 U4）：长按 `motion.rating.longPress`(350) 打开星级弹窗（非冲突单条目 / 冲突来源条目），可以不抬手直接滑动选择，规则同紧凑态；指针辅助点按卡片同样打开弹窗。卡片上下文菜单删除。
- 共享新类型 `FilmCardGeometry` 给出两档尺寸、内边距、带厚、选档、可见容量与列表几何；大档逐位等于旧 `FilmstripGeometry`（Mac/Windows/Android 继续用旧类型）。相似面板（宽形态）沿用大档。

### 2.2 EXIF 块

- 一个深色模糊圆角矩形（系统深色薄材质，圆角 `toolbar.exif.cornerRadius`(12)），块内按设置顺序排 EXIF 项：每项上标签（`toolbar.exif.label.fontSize` 次要色）下数值（`toolbar.exif.value.fontSize` 半粗主色），居中、尾部截断。
- 横排：每项宽 `toolbar.exif.item.width`(52)、项距 `toolbar.exif.item.spacing`(2)、两端内边距 `toolbar.exif.padding`(6)，高 44；竖排：宽 52 + 2 × 6、每项高 `toolbar.exif.item.height`(36)。
- 三处同一组件：宽形态控制栏 EXIF 组（行布局横排、列布局竖排）、手机竖屏顶行中间、手机横屏 EXIF 列（竖排）。整块一个点按目标，直达 EXIF 详情（TOOLBAR-06）。
- 共享新类型 `ExifBlockGeometry`；`ToolbarFlowLayout` 的 EXIF 组改用它。

### 2.3 宽形态筛选控件

- **三合体**（行布局）：一个交互式玻璃胶囊内三段原生弹出按钮（排序 / 方向 / 星级），每段显示当前值并带系统弹出指示，各自弹出单选菜单，选中即应用并关闭；段宽按内容自然宽度，整组在文件栏内容区内居中，AI 版相似聚类开关隔 `shell.glass.group.gap` 紧随其后。
- **单胶囊**（列布局，以及行布局整组放不下时）：列布局宽度等于胶片卡片列宽（大档 96 / 小档 64），系统玻璃按钮（筛选图标 + 星级筛选当前值），弹出与手机相同的三分组菜单（点选不关闭、失焦关闭）；AI 版相似聚类开关在其下方同宽。
- 相似聚类开关：关闭为玻璃按钮配置，打开为强调玻璃配置。
- 高度一律 44；行布局筛选条主轴 = 44 + 2 × `filter.margin`。计数在 U5 收入，本阶段不显示。
- 新类型 `iOSFilterControl` 取代 `iOSFilterBar`；几何取共享 `WideFilterLayout`。

## 4. 暂行决定（G2/G3 一并过目）

- 弹窗用窗口内玻璃面板而非系统浮窗（为了触摸连续）。
- 展开态步长 36（命中区高 44、宽 36，靠拖动修正精度），弹窗步长 44。
- 紧凑星簇点亮为金色实心星、未点亮为三级标签色描边星（实测叠压后仍可辨），字号 18、中心距 11。
- 写回期间显示"待确认"半透明星，而不是先回到旧值再跳到新值。
- 手机形态关闭"显示评分"时星级控件隐藏、槽位留空。
- 卡片长按与指针辅助点按提前到 U3 接入（U2 的弹窗已就绪，避免留一个只有标题的卡片菜单过渡态）。
- 小档 64 × 76 是为了让 iPhone 17e 横屏也放下 5 张；照片区因此只有 54。
